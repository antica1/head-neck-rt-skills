## ⚠️ 影像+内镜依赖声明

> **本 Skill 中的 GTV 定义依赖术前 MRI/CT **和**内镜检查所见范围**。AI 无法读片也无法看内镜图像——报告中边界须以"建议 + 依据 + 请确认"格式输出。** 若术前影像未提供肿瘤具体范围→CTV 外放 **+5mm**。若内镜报告中仅提及"可见肿瘤"而无具体边界描述→按解剖默认值处理，标注为推断。

## 根治性 RT 与术后 PORT 的根本差异

| | 术后 PORT | 根治性 RT |
|---|---|---|
| **靶区基础** | 手术床 + 吻合口 + 重建 + 病理 | **GTV（影像+内镜）** |
| **剂量方案** | 序贯（60/54 Gy + 缩野），**不用 SIB** | **SIB（70/63/56 Gy）** |
| **GTV 定义** | 依据病理 | **内镜所见范围是必要组成部分——CT/MRI 均低估** |
| **关键风险** | 吻合口遗漏 | **RP 未纳入或上界不足（最常见地理遗漏）** |

## 一、下咽的解剖基础

| 亚部位 | 边界 | 淋巴引流 |
|--------|------|---------|
| **梨状窝** | 咽侧壁（外）·杓会厌皱襞（内）·环后区（下） | Ⅱ-Ⅲ-Ⅳ → RP → Ⅵ |
| **环后区** | 杓状软骨→环状软骨后板→食管入口 | 双侧 RP → 双侧 Ⅵ |
| **咽后壁** | 舌骨水平（上）→环咽肌（下）·椎前筋膜（后） | 双侧 RP |

### 与喉的交界

> 梨状窝内侧壁与喉（杓状软骨/声门旁间隙）相邻——**肿瘤向喉方向侵犯时参考 `larynx-rt-targets` 的声门旁间隙规则**。环后区上方与环状软骨后板延续。声门上癌（尤其会厌谷）跨入下咽→RP 规则生效。

## 二、GTV 勾画——根治性 RT 的核心

### 2.0 诱导化疗前定位流程（2025 国家癌症中心指南）

> 🔥 **MDT 决定先诱导化疗时**：
> 1. **诱导化疗前先做放疗定位**（CT 模拟定位）
> 2. 诱导化疗后**重新定位**
> 3. **两次定位图像融合**——评估肿瘤大小和位置改变对靶区确定的影响
> 4. **放疗需在诱导化疗后 3-4 周内开始**

### 2.1 GTV 定义的特殊规则

| 模态 | 看什么 | 局限性 |
|------|--------|--------|
| **CT** | 软骨侵犯（骨窗必需）、椎前筋膜 | GTV-CT 平均比手术标本小 15%（Daisne 2004） |
| **MRI** | 软骨侵犯、声门旁间隙、食管入口 | GTV-MRI 比 CT 大 10%，敏感性 89% |
| **FDG-PET** | 淋巴结、远处转移 | 最准确但**所有模态均漏掉黏膜浅表扩散** |
| **内镜** | **黏膜表面范围** | **不可替代——是 GTV 定义的必要组成部分** |

### 2.2 GTV→CTV 外放（下咽）

| 亚部位 | 外放 | 理由 |
|--------|------|------|
| **梨状窝** | 1.5-2 cm | 同声门上，黏膜下扩散 |
| **环后** | 2-3 cm（上下） | 沿食管入口的黏膜下扩散 |
| **咽后壁** | 2-3 cm（纵向） | 沿椎前筋膜的纵向扩散 |
| **软骨侵犯区** | **全层软骨纳入** | 软骨内无真正的外科平面 |

> **DAHANCA 5mm 验证**（Hansen 2024）：5mm 是最低安全外放——但**不是所有亚部位都够**（环后 2-3cm，咽后壁 2-3cm）。

> **2025 国家癌症中心指南（易俊林通信，下咽癌）**：考虑下咽癌黏膜下浸润特点，**GTVp 基础上建议外扩 1.2cm**，按解剖屏障（骨性结构、空腔、肌肉筋膜）修回——比 DAHANCA 5mm 更宽，作为下咽癌 CTV1 的基准外放。

### 2.3 PTV 外扩（2025 国家癌症中心指南）

- **下咽癌**：GTVp 外扩 **3-8mm**——**向前及向上方向可适度扩大**（除原发咽后壁肿瘤）；GTVnd 和 CTV 外扩 3mm
- 放疗前验证推荐**锥形线束 CT（CBCT）引导**
- PRV：脊髓等串联器官外扩 **5mm**（下咽）；晶状体/耳蜗等小结构也建议 PRV

## 三、根治性 RT——按亚部位

### 3.1 梨状窝癌

**SIB 剂量**：
- GTV-P：70 Gy/35 fx
- CTV-H：63 Gy/35 fx
- CTV-I（ENI：同侧 Ⅱ-Ⅲ-Ⅳ-RP ± 同侧 Ⅵ）：56 Gy/35 fx
- 对侧 Ⅱ-Ⅲ（T3+ 或 N2+）：50-54 Gy

**GTV→CTV**：
- 外侧壁→向后至椎前筋膜
- 内侧壁→杓状软骨→声门旁间隙（喉方向——参考 `larynx-rt-targets`）
- 梨状窝尖→颈段食管 1-2 cm
- RP：同侧**必照**（54-60 Gy）
- Ⅵ 区：梨状窝尖受累→同侧

### 3.2 环后癌

- 环状软骨后板全层
- 颈段食管 2-3 cm
- **双侧 RP 必照**
- **双侧 Ⅵ 区必照**
- 气管膜部纳入
- 双侧 Ⅱ-Ⅲ-Ⅳ 预防

### 3.3 咽后壁癌

- 后界：椎前筋膜——穿透=T4
- 纵向 2-3 cm 外放
- **双侧 RP 必照**
- T4 穿透椎前筋膜→椎前肌纳入 CTV

## 四、PORT——按术式

### 4.1 下咽切除+重建术后

| 重建方式 | CTV 要点 |
|---------|---------|
| **游离空肠** | 吻合口上下各 2-3 cm。移植物-组织界面全层纳入 |
| **Gastric pull-up** | 胸腔胃上端吻合口→含吻合口上下+各 3 cm。气管后壁纳入 |
| **胸大肌皮瓣** | 组织床全照 |

> **术后GTV勾画铁律**：无论术后病理显示治疗后改变甚至完全缓解，GTV勾画必须参考**化免前/术前**的影像学范围。化免前的原发灶侵犯区域必须纳入CTV1（高危区），不能因术后病理显示「治疗后改变」而缩小靶区。

### 4.2 全喉咽切除术后 CTV

```
CTV-60（高危）：
├── 咽吻合口各向 1.5-2 cm
├── Stoma 全层（皮肤+气管环周 1-2 cm）
├── 舌根（若肿瘤曾贴邻→同侧舌根 1 cm）
├── 原发灶术床（按术前 MRI/内镜还原）
├── 原阳性 LN 站+直接下游一站
└── RP（同侧必照；环后/近中线→双侧）

CTV-54（预防）：
├── 同侧 Ib-II-III-IV（T3+ 或 N2+）
├── 双侧 RP（下咽必照——上界 C1）
├── 同侧/双侧 VI（梨状窝尖/环后/食管受累）
└── 对侧 II-III（近中线/环后+N2+）
```

## 五、PORT 亚部位 CTV

### 5.1 梨状窝癌 PORT

| CTV 要点 | 范围 |
|---------|------|
| **咽侧壁** | 梨状窝外侧壁→向后至椎前筋膜 |
| **喉侵犯途径** | 内侧壁→杓状软骨→声门旁间隙（参考 `larynx-rt-targets`） |
| **食管入口** | 梨状窝尖→颈段食管 1-2 cm |
| **RP** | 同侧 RP **必照**（54-60 Gy）——转移率 20-40% |
| **Ⅵ 区** | 梨状窝尖受累→同侧 Ⅵ 区 |
| **对侧** | 对侧 RP+颈→仅近中线或环后受累时照 |

### 5.2 环后癌 PORT

全在中线，双侧引流，与食管入口直接延续。

| CTV 要点 | 范围 |
|---------|------|
| **环状软骨后板** | 全层——环后癌的"地板" |
| **食管入口** | 颈段食管 2-3 cm |
| **双侧 RP** | 中线位置→**双侧 RP 必照** |
| **双侧 Ⅵ 区** | 环后→双侧气管旁 |
| **气管膜部** | 环后→食管前壁→气管后壁→纳入 CTV |
| **对侧颈** | 双侧 Ⅱ-Ⅲ-Ⅳ 预防 |

### 5.3 咽后壁癌 PORT

| CTV 要点 | 范围 |
|---------|------|
| **后界** | 椎前筋膜——是否穿透是分期关键（T2 vs T4） |
| **上下扩展** | 纵向 2-3 cm 外放（比梨状窝更宽） |
| **双侧 RP** | 咽后壁中线→双侧 RP |
| **椎前肌** | T4 穿透椎前筋膜→椎前肌纳入 CTV |

## 六、淋巴结预防——RP 与 Ⅵ 区（下咽两大必照区）

> **下咽癌是头颈鳞癌中预后最差的亚区——RP 和 Ⅵ 区是两个"必照区"。**

### 6.1 淋巴结站区对比（下咽）

| 分区 | 梨状窝 | 环后 | 咽后壁 |
|:--:|:--:|:--:|:--:|
| **II/III** | ✅ | ✅ | ✅ |
| **IV** | T3+/N2+ | ✅ | T3+/N2+ |
| **V** | N2b+ | N2b+ | N2b+ |
| **VI** | ✅ 同侧/双侧 | ✅ 双侧 | 视下界 |
| **VII(RP)** | ✅ **必照** | ✅ **双侧必照** | ✅ **双侧必照** |

> **V区豁免循证** — Looman et al. *Radiother Oncol* 2026：390例多中心研究。II/III阴性时V区转移率降至**1%**。V区转移为II/III区受累后的序贯事件 → II/III 阴性时 V 区可安全豁免。

> **口诀**：Ⅰ口ⅡⅢⅣ通链，Ⅴ颈后Ⅵ气管Ⅶ咽后。下咽ⅥⅦ必包。

### 6.2 Ⅵ 区（气管旁/气管食管沟）

```
上界：环状软骨下缘
下界：胸骨切迹
外侧界：颈总动脉内侧缘
```

| 条件 | 同侧 Ⅵ | 双侧 Ⅵ |
|------|:--:|:--:|
| 声门下癌（交界） | ✅ | ✅ |
| 梨状窝尖受累 | ✅ | ❌（除非近中线） |
| 环后癌 | ✅ | ✅ |
| 颈段食管受累 | ✅ | ✅ |
| Stoma 切缘阳性/近 | ✅ | ✅ |

### 6.3 RP（咽后淋巴结）——下咽癌必照

```
上界：颅底（C1 横突水平——下咽癌不能用"舌骨水平"做上界）
```

| 条件 | 同侧 RP | 双侧 RP |
|------|:--:|:--:|
| **所有下咽癌** | ✅ 必照 | 环后/咽后壁/近中线→双侧 |
| 声门上 T3+（紧邻下咽交界区） | 可选 | ❌ |

> **RP转移与下咽亚部位的关系**：
> - 下咽后壁 / 外侧壁 / 梨状窝外侧壁 → **高RP风险**（必照，上界C1）
> - 环后区 → **低RP风险**（MRI阴性时可考虑豁免同侧RP）
> - 咽后壁癌 → 双侧RP必照（中线位置）

### 6.4 淋巴结触发规则（2025 国家癌症中心下咽癌指南——表2 注释）

> 🔥 **下咽癌颈部 CTV 分层触发条件**（比"按 T/N 分期"更精细）：

| 触发情形 | 需要照射 |
|---------|---------|
| **Ib 区有阳性淋巴结** | Ib 区 |
| **IIa 区 >3cm 淋巴结或淋巴结破膜（ENE）** | Ib 区 |
| **II 或 III 区淋巴结巨大，侵犯颌下腺或颈部皮肤** | Ib 区 |
| **颈部因淋巴结转移接受了不规则手术** | Ib 区 |
| **肿瘤侵犯以 Ib 区为淋巴引流首站的解剖结构** | Ib 区 |
| **IIIb 区淋巴结转移 或 II 区淋巴结转移** | VIb 区 |
| **咽后淋巴结转移 或 咽后壁受侵** | VIIa 区 |
| **VI 区淋巴结转移 或 梨状窝尖部/环后区/甲状腺/气管/颈段食管受侵** | VI 区 |
| **Ia、IX、X 区不常规照射** | 除非该区域已有转移淋巴结 |

## 七、剂量策略

### 根治性 RT——SIB

| 剂量层级 | 范围 | 处方 |
|---------|------|------|
| **GTV-P** | 影像（CT+MRI+PET 融合）+ **内镜所见**原发灶 | 70 Gy/35 fx |
| **GTV-N** | 阳性淋巴结 | 70 Gy/35 fx |
| **CTV-H** | GTV-P + 5-10 mm（按亚部位；下咽基准 1.2cm） | 63 Gy/35 fx |
| **CTV-I** | ENI——按亚部位和 N 分期 | 56 Gy/35 fx |
| **CTV-L** | 低危预防区（对侧颈预防等） | 50.4-54 Gy/28-30 fx |

> **下咽根治性 RT 适合 SIB**——GTV 通常在软组织/软骨内。

### PORT——序贯（不用 SIB）

| PTV 层级 | 剂量 | 适应证 |
|---------|------|--------|
| **PTV-66-70** | 66-70 Gy/33-35 fx | R1/R2（吻合口阳性）、ENE+ |
| **PTV-60** | 60 Gy/30 fx | 手术床（Stoma 必含）、原阳性 LN 站+下游一站 |
| **PTV-54** | 54 Gy/30 fx | 预防区（同侧未受累颈、RP、双侧 Ⅵ 预防） |
| **PTV-50** | 50 Gy/25-30 fx | 低风险预防（对侧颈Ⅱ-Ⅲ） |

## 八、OAR 约束

| OAR | 限量 | 下咽特有挑战 |
|-----|------|------------|
| 脊髓 | Dmax ≤45 Gy | **下咽→RP→脊髓紧邻→需缩野** |
| 脑干 | Dmax ≤54 Gy | **RP 上界近颅底** |
| 咽缩肌 | Dmean ≤54 Gy | 吞咽关键 |
| **气管** | V50 < 50% | Ⅵ 照射→晚期气管软化 |
| 甲状腺 | V50 < 50% | 甲减率 40-60% |
| **颈动脉** | Dmax < 50 Gy | **下咽癌颈动脉紧邻** |
| **臂丛** | Dmax ≤60 Gy | 下颈部/上纵隔 |
| 腮腺 | Dmean ≤26 Gy | 双侧颈预防→双侧腮腺挑战 |
| **颈段食管** | Dmax < 60 Gy | **CTV 含食管但约束需权衡** |

## 九、化免新辅助后降级（参考 `neoadjuvant-deescalation`）

| | 下咽癌 |
|---|---|
| **降级优先** | **降剂量 > 降范围** |
| **理由** | **RP+Ⅵ 基线风险太高，不能缩野** |
| **根治性降级** | 仅影像 CR 且病理确认（未手术则不可信）→ 才可考虑 60 Gy 下限 |
| **PORT 降级** | pCR+切缘≥5mm+RP 影像阴性→可考虑 CTV-60→54 |

> 喉癌的降级策略（降范围 > 降剂量）见 `larynx-rt-targets`——**两部位降级优先级相反，切勿混用**。

## 十、勾画流程

### 根治性 RT 六步法

| 步 | 操作 |
|----|------|
| 1 | 获取诊断 MRI/CT + **内镜检查报告+图像**（不可替代） |
| 2 | 内镜所见范围定义 GTV——CT/MRI 辅助判断深部边界 |
| 3 | GTV→CTV 外放按亚部位（第三节）+ 软骨侵犯→全层纳入 |
| 4 | 按 N 分期和亚部位决定 ENI（**RP 上界 C1、Ⅵ 区触发**，第六节） |
| 5 | SIB 剂量分配（第七节） |
| 6 | 检查 OAR（第八节）——颈动脉 Dmax、颈段食管权衡 |

### PORT 十步法

| 步 | 操作 |
|----|------|
| 1 | 获取术前 MRI/CT + 内镜检查报告 + 内镜图像 |

## 十一、失败模式

| 失败位置 | 根本原因 | 预防规则 |
|---------|---------|---------|
| **RP 复发（最常见地理遗漏）** | RP 未纳入 ENI 或上界不足 | 下咽癌→同侧 RP 必照，上界至 C1 |
| Ⅵ区/气管旁复发 | 梨状窝尖引流→气管旁遗漏 | 梨状窝尖→同侧Ⅵ区 |
| 食管方向纵向失败 | CTV 未含足够颈段食管 | 环后癌→颈段食管 2-3 cm |
| 咽吻合口失败 | CTV-P 边缘不足 | 吻合口各向 1.5-2 cm |
| 对侧颈区域失败 | 仅照同侧→环后双侧引流遗漏 | 环后/近中线→双侧预防 |
| 第二原发漏诊 | 未做胃镜+碘染色 | 下咽癌→食管第二原发约 30%→内镜必查 |
