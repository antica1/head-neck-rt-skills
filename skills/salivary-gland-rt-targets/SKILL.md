# 唾液腺癌放疗靶区勾画

> **本节为九院朱国培团队基于 ESTRO/DHANCA/CSCO 指南、国际唾液腺癌靶区勾画共识、RTOG 1008 及九院临床实践的唾液腺癌放疗靶区勾画体系。** ACC（腺样囊性癌）另有独立 Skill，本节覆盖 ACC 以外的唾液腺癌亚型——黏液表皮样癌、腺泡细胞癌、唾液腺导管癌、淋巴上皮癌、腺癌 NOS、 carcinoma ex pleomorphic adenoma 等。

---

## 为什么唾液腺必须独立成 Skill

| 维度 | 口腔/口咽 SCC | 唾液腺癌 |
|------|-------------|---------|
| **病理多样性** | 鳞癌为主 | **20+ 亚型**——低级别（腺泡细胞）到高级别（唾液腺导管癌）跨度极大 |
| **PORT 指征** | pT3+/N+/切缘近 | 取决于**病理分级 + 分期**——低级别 pT1-2 N0 可不做 PORT |
| **颈部预防** | 按亚部位和 N 分期 | 按**病理类型 + 腺体位置**——腮腺低级别可不照颈 |
| **面神经** | 不涉及（口腔） | MB中心病灶——**必须评估面神经径路** |
| **特殊亚型** | 无 | **淋巴上皮癌**→EBV 相关，可根治性 CRT 不手术（类似 NPC） |
| **手术方式** | 广泛切除 | 腮腺切除术——面神经保留是核心 |
| **AJCC 分期** | T1-4 通用逻辑 | 唾液腺独立分期——T3/T4 以腺体外侵犯和命名神经为关键 |

## 一、唾液腺癌病理分型 → RT 决策

### 1.1 按风险分级

| 风险 | 病理类型 | PORT 指征 | 颈部预防 |
|------|---------|:--:|:--:|
| **低级别** | 腺泡细胞癌、低级别黏液表皮样癌、基底细胞腺癌 | pT1-2 N0→**不做** PORT | 不做 |
| **中级别** | 中级别黏液表皮样癌、腺癌 NOS、上皮-肌上皮癌 | pT3+/切缘近→PORT | 按腺体位置决定 |
| **高级别** | 唾液腺导管癌、高级别黏液表皮样癌、carcinoma ex pleomorphic adenoma、**淋巴上皮癌**（未分化型） | **几乎都做** PORT | 必做 |
| **特殊** | ACC（见独立 Skill）、淋巴上皮癌（考虑根治性 CRT） | 按各自 Skill | 见下文 |

### 1.2 淋巴上皮癌——特殊的"NPC 样"唾液腺癌

```
淋巴上皮癌（Lymphoepithelial Carcinoma）
         │
    ┌────┴────┐
    │         │
  术前活检   术后病理才
  已证实      发现
    │         │
    │    ┌────┴────┐
    │    │         │
    │  早期pT1-2   晚期
    │  N0，切净   pT3-4/N+
    │    │         │
    │    │    ┌────┴────┐
    │    │    │         │
    │   PORT   可手术    不可手术
    │    │         │
    └────┼─────────┘
         │
    □ 根治性 CRT（不手术）
    □ 晚期→诱导化疗/化免 → CCRT
    □ 与 NPC 处理原则一致——EBV DNA 监测
```

> **核心原则**：淋巴上皮癌是唾液腺癌中唯一可以在术前活检确诊后**不手术、直接根治性放化疗**的亚型。其余亚型仍以手术+PORT 为金标准。

## 二、AJCC 第 9 版唾液腺癌分期

### 2.1 T 分期

| T | 大唾液腺（腮腺/颌下腺/舌下腺） |
|----|---------------------------|
| T1 | ≤2 cm，无腺体外侵犯 |
| T2 | >2 cm 但 ≤4 cm，无腺体外侵犯 |
| T3 | >4 cm，或**大体腺体外侵犯**（侵犯邻近软组织/黏膜，未累及其他结构） |
| T4a | 侵犯皮肤、骨、软骨、实质器官、气管、食管、**命名神经** |
| T4b | 包绕颈动脉、颅底、脊柱、颅内、眶尖、椎前间隙、纵隔、咀嚼肌间隙 |

> **关键**：腺体外侵犯 = 临床或肉眼可见的侵犯，仅为显微镜下不足以构成 T3。

### 2.2 N 分期（第 9 版简化）

| N | 标准 |
|----|------|
| N0 | 无淋巴结转移 |
| N1 | **1-3 个同侧 LN**，无影像学/临床 ENE |
| N2 | **>3 个 LN**，或任何 LN 伴影像学/临床 ENE |

### 2.3 分期分组

| 分期 | T | N | M |
|------|----|----|----|
| 0 | Tis | N0 | M0 |
| I | T1 | N0 | M0 |
| II | T2 | N0 | M0 |
| IIIA | T3, T4 | N0 | M0 |
| IIIA | T1, T2 | N1 | M0 |
| IIIB | T1, T2 | N2 | M0 |
| IIIB | T3, T4 | N1, N2 | M0 |
| IV | 任何 T | 任何 N | M1 |

## 三、PORT 指征

### 3.1 术后放疗的明确指征

| 指征 | 证据等级 |
|------|:--:|
| **高级别病理**（唾液腺导管癌/高级别 MEC/未分化癌/鳞癌/嗜酸细胞癌/恶性多形性腺瘤） | 强 |
| **pT3-T4**（局部晚期） | 强 |
| **N+**（>1 枚 LN+ 或软组织侵犯） | 强 |
| **R1/R2 切缘** 或 **切缘 <5 mm** | 强 |
| **PNI+**（命名神经侵犯） | 强 |
| **LVI+** 或 **ENE+** | 强 |
| **骨/软骨侵犯** | 强 |
| **大血管及周围侵犯** | 强 |
| **术前已发生神经麻痹**（面神经/舌神经/舌下神经） | 强 |
| **腮腺深叶受侵** | 强 |
| **术后局部复发再手术后** | 强 |
| **术中肿瘤破裂/怀疑残留/仅剜除** | 强 |
| **carcinoma ex pleomorphic adenoma**（侵袭性成分） | 强 |

### 3.2 可选择性不做 PORT

| 条件 | 理由 |
|------|------|
| pT1-2 N0 + 低级别病理 + 切缘阴性 | 局控率 >90%——手术足够 |
| 腺泡细胞癌 pT1-2 N0 R0 | 低级别，极少复发 |

### 3.3 非标准 PORT 指征——当教科书"不放"但临床该放

> 以下三种场景不满足传统 PORT 指征（pT1-2 N0 低级别，切缘阴性），但九院经验认为仍需放疗。**这些情况在教科书中找不到——但它们决定了病人是否会复发。**

#### 场景 A：当良性开的手术——切除范围不足

```
临床表现：腮腺"良性肿瘤"行浅叶切除或剜除术
         术后病理回报：低级别黏液表皮样癌 / 腺泡细胞癌

问题：手术范围按良性肿瘤设计——无颈清扫、切缘仅 1-2 mm、
      深叶未处理、包膜可能术中破裂

放疗指征：
  ✅ 即使病理报"切缘阴性"——但手术并非按恶性肿瘤标准操作
  ✅ 术后 MRI 可见残留腺体组织——原肿瘤床未被完全切除
  ✅ 无法确定肿瘤是整块切除还是分块取出
  → 推荐 PORT：CTV 覆盖全腮腺床，54-60 Gy

例外：如果外科医生口头确认"当时虽然当良性开，但我切得范围够——完整切除+包膜完整+各方向都有安全边界+没有任何不放心的地方"，可考虑不做 PORT。关键不是"手术叫什么名字"，而是"手术实际上做得够不够"。```

#### 场景 B：面神经粘连——为保功能而保守切除

```
临床表现：腮腺深叶肿瘤与面神经主干/分支紧密粘连
         术中发现难以分离→为保留面神经功能而紧贴肿瘤切除
         手术记录可能未明确描述"切缘不足"

放疗指征：
  ✅ 术前谈话中医生口头告知"肿瘤和面神经粘得很紧"
  ✅ 术后 MRI 面神经径路周围有可疑软组织影
  ✅ 即使病理报"切缘阴性"——神经-肿瘤界面无法获得安全边界
  → 推荐 PORT：CTV 含面神经径路，54-60 Gy（保护面神经≤54 Gy）

关键：必须与手术医生口头沟通——手术记录常不写"我为了保神经切得不够"
     但口头交流中医生会坦白哪些地方不放心
```

#### 场景 C：多次复发的低级别肿瘤

```
临床表现：腺泡细胞癌 / 低级别 MEC，已行 2-3 次局部切除
         每次病理均为低级别、切缘阴性→但反复复发

问题：多次手术后解剖层次紊乱、瘢痕种植可能
      单纯再次手术的局控率递减

放疗指征：
  ✅ ≥2 次局部复发——即使每次都是 R0 切除
  ✅ 多次手术后手术床内有瘢痕——肿瘤细胞可能被"埋"在瘢痕里
  → 推荐 PORT：CTV 覆盖全腮腺床+历次手术瘢痕，60 Gy
```

### 3.4 处理流程——当病人说"医生当良性开的"

```
病人："医生当良性开的，开完说是恶性的"

第一步：复查术后 MRI（增强）
  ├── 有明确残留 → 直接 PORT（按 R2 处理）
  └── 无明确残留 → 进入第二步

第二步：与手术医生口头沟通（打电话/当面，不只看病历）
  ├── "肿块是整块切除还是分块取出？"
  ├── "术中包膜破了吗？"
  ├── "和面神经粘得紧吗？哪个分支？"
  └── "你觉得哪个方向切得最不放心？"

第三步：综合判断
  ├── 任何"不放心"因素存在 → PORT
  └── 完整切除+包膜完整+神经分离顺利 → 可观察

靶区：
  · 如果手术仅剜除肿瘤 → CTV = 全腮腺床（等同全腮腺切除术后）
  · 如果是浅叶切除 → CTV = 深叶残余+腮腺床
  · 如果有面神经顾虑 → CTV 含垂直段预防
```

## 四、靶区勾画——按腺体

### 4.1 腮腺癌术后 CTV

```
腮腺切除术类型：
├── 浅叶切除（Superficial parotidectomy）
│   → CTV = 腮腺床 + 深叶残余（如未切除）
├── 全腮腺切除（Total parotidectomy）
│   → CTV = 全腮腺床（从外耳道→下颌后静脉→二腹肌后腹）
└── 根治性腮腺切除（Radical parotidectomy，含面神经切除）
    → CTV = 腮腺床 + 面神经径路（茎乳孔→腮腺）
```

#### 腮腺床边界

| 边界 | 结构 |
|------|------|
| **上界** | 颧弓 + 外耳道下缘 |
| **下界** | 下颌角 + 二腹肌后腹 |
| **前界** | 下颌支后缘 + 咬肌后缘 |
| **后界** | 胸锁乳突肌前缘 + 乳突尖 |
| **内侧界** | 茎突 + 茎突咽肌 + 颈内动脉鞘 |
| **外侧界** | 皮下脂肪（手术缺损区） |

#### 面神经径路——何时纳入 CTV

| 情况 | 处理 |
|------|------|
| 面神经保留（浅叶切除） | 不照——保护面神经功能 |
| 面神经切除 + 病理 PNI+ | CTV 含面神经垂直段（茎乳孔→腮腺床）60 Gy |
| 仅 PNI 在终末支，主干未受累 | 终末支径路 54 Gy 预防，主干不照 |

> **腮腺癌面神经规则**：不同于 ACC——ACC 是**V3→卵圆孔**，腮腺其他癌的面神经径路是**茎乳孔→垂直段**。水平段（颞骨内）一般不需照射。

#### 副腮腺——偏前的特殊位置，偏前的不常规淋巴引流

```
解剖背景：
  · 腮腺主体位于咬肌后缘、下颌支后方
  · 副腮腺（accessory parotid）位于咬肌前缘、腮腺导管上方
  · 位置偏前——超出常规腮腺靶区的"前界=咬肌后缘"范围

两个后果：

1. 靶区前界必须前移
   常规腮腺 CTV 前界：下颌支后缘 + 咬肌后缘
   副腮腺 CTV 前界：咬肌前缘（包含副腮腺组织）→ 面部皮下

2. 非标准的淋巴结引流——IX 区→ⅠB 通路
   常规腮腺引流：腮腺内 LN → Ⅱ/Ⅲ
   副腮腺引流：副腮腺 → IX 区（面动脉旁/颊肌外侧淋巴结）
                    → ⅠB → Ⅱ
                   ↑
              这条通路在常规腮腺癌中不存在！

临床意义：
  高级别副腮腺恶性肿瘤 → 必须预防 IX 区 + 同侧ⅠB
  中级别 + 肿块 >2 cm → 考虑预防 IX 区（至少覆盖颊间隙）
  低级别 + 小肿块 → 可不做 IX 区预防

靶区设计：
  · CTV 前界扩至咬肌前缘（含副腮腺+颊脂垫）
  · 如高级别→CTV 扩展包括 IX 区（面动脉旁淋巴结，沿面动脉走行至下颌骨下缘）
  · IX 区与ⅠB 区连续覆盖——它们是串联的
```

> **为什么常规腮腺 Skill 会漏掉**：常规腮腺前界=咬肌后缘——副腮腺在咬肌前面，按常规前界勾画会完全漏掉靶区。IX 区不在 Robbins 标准分区中——年轻医生可能根本不知道这个站的存在。

#### 术前 MRI 阅片——手术记录没写但片子会告诉你

> **手术记录和病理报告是"二维"的——术前 MRI 是"三维"的。有些高危区只有看片子才能发现。**

| MRI 发现 | 手术记录可能没写 | 靶区调整 |
|---------|---------------|---------|
| **腮腺深叶广泛受累** | 手术记录写"全腮腺切除"但深叶可能残留 | CTV 包含深叶至茎突平面 |
| **肿瘤包绕面神经至茎乳孔** | 手术可能未探查到该深度 | CTV 含面神经垂直段至茎乳孔，如 PNI+→60 Gy |
| **肿瘤紧贴颅底（<5 mm）** | 手术无法到达——"看不见的边界" | CTV 上界扩至颅底孔道入口 |
| **咽旁间隙侵犯** | 腮腺深叶→咽旁→直接通路 | CTV 内侧含咽旁间隙+茎突后间隙 |

> **操作步骤**：定位 CT 上融合术前 MRI——逐层比对肿瘤与关键结构的距离。找到"最近点"→标记→该方向 CTV 外放增加 5-10 mm。

#### 耳后切口——美容代价是靶区难题

```
耳后（retroauricular）切口的美容优势：
  · 切口隐藏在耳后沟——正面看不见瘢痕
  · 适用于良性肿瘤或年轻患者

放疗挑战：
  · 乳突区皮包骨头——皮下脂肪仅 2-3 mm
  · 切口走行于耳后沟——不规则曲面
  · 肿瘤种植风险——切口直接穿过手术创面
  · 皮肤表面剂量不足——高能 X 线 build-up 区在此深度

处理方案：
  ① CTV 包含全层皮肤+皮下（皮包骨处全层厚度仅 5-8 mm）
  ② 切口瘢痕两端各外放 2 cm（沿切口走行）
  ③ PTV 需扩至皮肤表面——不允许内收（皮肤是靶区的一部分）
  ④ 加 5 mm Bolus（组织补偿膜）覆盖耳后切口区——确保皮肤表面剂量
  ⑤ 计划评估：皮肤表面 Dmax ≥ 95% 处方剂量
```

> **为什么 Bolus 不能省**：6 MV X 线的最大剂量点在皮下 1.5 cm。耳后皮肤+皮下仅 3-5 mm→处方剂量的 30-50% 在皮肤表面。不加 Bolus = 切口种植区剂量严重不足。

#### 晚期复发——全身治疗选项的储备

> **唾液腺癌晚期复发后的药物选择远少于头颈鳞癌。但手术标本给了我们一张"路线图"。**

| 时代 | 选择 | 证据 |
|------|------|------|
| **过去（无靶向）** | 抗血管 TKI（阿帕替尼/安罗替尼/索拉非尼） | 二线以后，临床可及性高，但 ORR 低（10-15%） |
| **现在（ADC 时代）** | 按靶点匹配 | 见下表 |

**ADC 靶点检测——建议术后常规做（免疫组化±FISH）**：

| 靶点 | 检测方法 | 相关 ADC 药物 | 唾液腺癌阳性率 |
|------|---------|-------------|:--:|
| **HER2** | IHC + FISH | T-DXd（DS-8201）/ T-DM1 | 唾液腺导管癌 30-40% |
| **AR（雄激素受体）** | IHC | 无 ADC，但可用 ADT（比卡鲁胺） | 唾液腺导管癌 70% |
| **EGFR** | IHC | 抗 EGFR ADC（如 MRG003） | 多种亚型 50-80% |
| **Trop-2** | IHC | SG（戈沙妥珠单抗） | 唾液腺癌 50-70% |
| **Nectin-4** | IHC | EV（恩诺单抗） | 部分亚型 30-50% |
| **B7H4** | IHC | 在研 ADC | 探索性 |

> **核心原则**：这些不是一线标准治疗——但手术标本是唯一的检测窗口。**现在不做，将来复发时没有标本可测。** 术后常规留取 IHC 切片→存档→将来复发时直接匹配 ADC 靶点。

### 4.3 舌下腺癌术后 CTV

#### 舌下腺癌——罕见但"八字形"决定了必须照双侧

```
发病率低但恶性程度高：
  · 舌下腺恶性肿瘤占唾液腺癌 <2%
  · 但一旦发生——多为高级别（唾液腺导管癌/高级别 MEC）
  · 低级别（腺泡细胞癌）在舌下腺极为罕见

"八字形"排列——天然的近中线结构：
  · 双侧舌下腺呈 V 形排列于舌腹两侧
  · 内侧紧贴颏舌肌——距中线仅 2-3 mm
  · 舌下腺实际上是一个"中线结构"，不是侧性器官

为什么必须双侧：
  ① 口底淋巴环——舌下腺通过口底淋巴网直接连通双侧ⅠB
  ② 舌下腺 + 同侧 LN+ → 对侧已在高危状态
  ③ 即使 pN0——高级别舌下腺癌也应考虑双侧预防
     （因为"八字形"的解剖位置决定了双侧引流是默认状态）

颈部范围：
  CTV60/54：双侧口底（全层）+ 双侧ⅠA+ⅠB+ⅡA
  如 pN+ → 同侧加Ⅲ
  如 ≥3 LN+ 或 ENE+ → 对侧加Ⅲ
```

| **软腭** | 软腭全层+鼻咽侧壁（如有侵犯） | 口腔口咽 Skill |
| **颊黏膜** | 颊肌全层+颊脂垫 | 口腔口咽 Skill |
| **舌根** | 舌根全层+舌扁桃体沟 | 口腔口咽 Skill |

#### 小唾液腺——级别决定颈部策略

> **大唾液腺（腮腺/颌下腺/舌下腺）有独立的淋巴引流路径。小唾液腺散布于黏膜下——它们的淋巴引流取决于所在解剖位置，一旦中高级别，颈部处理按 SCC 标准进行。**

```
小唾液腺 颈部 ENI 策略：

级别 → 决定颈部是否照
  │
  ├── 低级别（腺泡细胞癌/低级别 MEC）→ 不做 ENI（与腮腺低级别一致）
  │
  └── 中高级别 → 按该部位 SCC 标准做 ENI
                    │
                    ├── 硬腭 → 同侧ⅠB+Ⅱ（口咽 Skill）
                    ├── 软腭 → 双侧 RP+Ⅱ（口咽 Skill）
                    ├── 颊黏膜 → 同侧ⅠB+Ⅱ + 双侧 IX 区（口腔 Skill）
                    ├── 舌根 → 双侧Ⅱ-Ⅲ（口咽 Skill）
                    └── 磨牙后区 → 同侧ⅠB+Ⅱ+Ⅲ（口腔 Skill）

为什么小唾液腺中高级别 = SCC 颈部标准？
  · 小唾液腺位于黏膜下——与 SCC 共享同一淋巴引流网络
  · 大唾液腺有包膜→淋巴引流受限于腺体→转移率低
  · 小唾液腺无包膜→淋巴引流直接进入黏膜下网→与 SCC 通路完全重叠
  · 所以中高级别小唾液腺癌的颈部转移风险 = 同部位 SCC 的风险
```

> **一句话总结**：腮腺看级别——级别越高，照得越广。小唾液腺中高级别→把它当 SCC 处理颈部。

## 五、颈部淋巴结预防

### 5.1 按病理级别的颈部策略

| 病理级别 | 腮腺 | 颌下腺/舌下腺 | 小唾液腺 |
|---------|------|-------------|---------|
| **低级别 + pN0** | 不做 ENI | 不做 ENI | 不做 ENI |
| **中级别 + pN0** | 不做 ENI（腮腺淋巴少） | 同侧 Ib+II | 按部位 |
| **高级别 + pN0** | 同侧 II+III | 同侧 Ib+II+III | 同侧 Ib+II+III |
| **任何级别 + pN+** | 同侧 Ib+II+III+IV（涵盖手术已清扫站） | 同侧 Ib+II+III+IV+Va | 同侧+按部位 |

### 5.2 对侧颈部——何时需要

> 腮腺和颌下腺是侧性器官——但高级别肿瘤可通过淋巴链逆流转移至对侧。**同侧负荷越重，对侧风险越高。**

#### 三条转移到对侧的路径

| 路径 | 机制 | 解剖基础 |
|------|------|---------|
| **路径 1：深部淋巴链逆流** | 同侧负荷过重→**ⅡA→ⅠB→ⅠA→对侧ⅠB→对侧ⅡA** | 颏下（ⅠA）是双侧枢纽——一旦同侧 LN 多到"堵车"，淋巴流逆向涌入对侧 |
| **路径 2：浅表皮下淋巴管网** | 高级别腺癌→皮下淋巴管浸润→**颈前皮下淋巴网直接跨中线到对侧** | 颈前皮下淋巴管网无中线屏障——这是高级别唾液腺癌特有的转移通路 |
| **路径 3：原发灶跨中线** | 舌下腺近中线→口底淋巴环→对侧（口底铁律） | 见 ACC Skill——已覆盖 |

#### 对侧颈部决策表

| 触发条件 | 机制 | 对侧范围 |
|---------|------|---------|
| **高级别 + 同侧 ≥3 LN+** | 路径 1（深部逆流）| **对侧ⅠB+Ⅱ+Ⅲ** |
| **高级别 + 同侧 1-2 LN+ + ENE+** | 路径 1+2（深部+皮下双重通路）| 对侧ⅠB+Ⅱ+Ⅲ |
| **高级别 + 同侧 LN+ + 皮下淋巴管浸润（LVI+）** | 路径 2（皮下网直接跨中线）| 对侧ⅠB+Ⅱ |
| N2（>3 LN 或 ENE+） | AJCC 分期本身提示对侧风险 | 对侧Ⅱ+Ⅲ |
| 舌下腺 + 近中线 + 同侧 LN+ | 路径 3（口底铁律） | 对侧ⅠB+Ⅱ |
| 软腭跨中线 | 原发灶黏膜下跨中线 | 对侧 RP+Ⅱ |

```
决策树：

同侧 LN+ 数
    │
    ├── 1-2 枚，无 ENE → 仅照同侧（对侧风险 <5%）
    │
    ├── ≥3 枚 → 对侧ⅠB+Ⅱ+Ⅲ（深部逆流路径已激活）
    │
    └── 任何数量 + ENE+ → 对侧ⅠB+Ⅱ+Ⅲ（双重通路）
```

> **为什么 ≥3 枚是阈值**：唾液腺癌的淋巴引流路径比口腔 SCC 更"脆弱"——正常引流站少（腮腺→Ⅱ/Ⅲ，颌下腺→ⅠB/Ⅱ）。一旦 3 枚以上阳性→意味着整个引流链已被肿瘤占据→逆流和对侧溢出的数学概率急剧上升。

### 5.3 咽后淋巴结（RP）——腮腺癌何时需要

> **腮腺→RP 不是自然引流路径。** 正常腮腺淋巴引流至Ⅱ/Ⅲ区——RP 需要"翻越"茎突后间隙才能到达。以下四种情况才需要照同侧 RP：

| 触发条件 | 机制 | 范围 |
|---------|------|------|
| **腮腺深叶 + 中高级别** | 深叶肿瘤已跨过茎突下颌韧带→进入茎突后间隙→RP 成为"下一个站" | 同侧 RP（上至 C1 横突） |
| **深叶包膜外侵犯（ECE+）** | 肿瘤突破深叶包膜→直接扩展至咽旁/茎突后→RP 被"地理性"纳入 | 同侧 RP + 颈动脉鞘 |
| **腮腺内巨大肿块（>4 cm）+ 高级别** | 肿瘤体积大→深叶被推挤至咽旁→间接累及 RP 引流区 | 同侧 RP |
| **同侧颈部 LN 负荷大（≥3 枚或 ENE+）+ 颈清扫后** | 颈清后正常引流通道被切断→**逆流至颈鞘内和 RP**（与 HNCUP Skill 颈清后逆流规则一致） | 同侧 RP + 上颈鞘（Ⅱ区后界扩展至颈动脉鞘后方） |

```
决策逻辑：

腮腺肿瘤需要照同侧 RP 吗？
    │
    ├── 浅叶，低级别 → ❌ 不照
    │
    ├── 深叶受累 + 中高级别 → ✅ 照同侧 RP
    │
    ├── 深叶 ECE+ → ✅ 照同侧 RP + 颈动脉鞘
    │
    ├── 同侧 LN ≥3 枚 + 颈清后 → ✅ 照同侧 RP + 上颈鞘（逆流规则）
    │
    └── 颌下腺/舌下腺原发 → ❌ 不照（解剖上不可能到 RP）
```

> **RP 上界**：C1 横突（颅底水平）。**下界**：舌骨上缘。腮腺的 RP 照射范围比下咽癌小——不需要一直照到舌骨下。

> **颌下腺不需要照 RP**——颌下腺的淋巴引流方向是ⅠB→Ⅱ→Ⅲ，完全不走 RP 路线。

> **适应证**：① ACC 沿神经侵犯颅底/海绵窦 ② 年轻患者（减少继发肿瘤风险）③ 双侧颈部均需照射（保护对侧唾液腺）。

### 8.4 面神经径路——何时延伸至内听道

> 法国 SFRO 2025：腮腺癌经证实存在 PNI 时，可讨论将面神经通路**延伸至内听道（IAC）**。

| PNI 程度 | 我们的 Skill（此前） | SFRO 2025 |
|---------|-----------------|-----------|
| 终末支/无主干 PNI | 茎乳孔→腮腺床 | 不扩展到 IAC |
| 主干 PNI+（面神经切除） | 垂直段至茎乳孔 | **讨论延伸至 IAC** |
| 广泛 PNI（ACC 颅底侵犯） | 不照水平段 | **碳离子/质子→全颞骨内段至 IAC** |

> **适用条件**：仅当病理证实面神经主干/近端 PNI+，且手术未能完整切除神经近端时，讨论向 IAC 方向扩展。常规病例仍按茎乳孔→腮腺床勾画即可。

### 8.5 同步化疗——非标准治疗

> ⚠️ SFRO 2025 + RTOG 1008/GORTEC SANTAL 均未证实唾液腺癌同步顺铂的生存获益。**目前同步化疗不是标准治疗。**

| 情况 | 推荐 |
|------|------|
| 常规中高危唾液腺癌 | 单纯 PORT——**不加同步化疗** |
| 高危神经内分泌癌 | 可考虑顺铂±依托泊苷同步化疗（唯一例外） |
| 老年/PS 差 | 单纯 PORT——不加任何同步药物 |

> RTOG 1008 和 GORTEC 2016-02 SANTAL 结果尚未正式发表——在此之前，同步化疗应限于临床试验或高危神经内分泌癌。

### 8.6 碳离子治疗（CIRT）

> 法国 2027 年前需转诊至意大利或德国。中国已有重离子中心（上海质子重离子医院/甘肃武威）。

| 适应证 | 说明 |
|--------|------|
| **ACC + 放射抵抗** | 碳离子 RBE 高于光子/质子——适用于 ACC 这类放射抵抗性肿瘤 |
| **不可手术的局限病灶** | 替代手术的根治性手段 |
| **大体残留（R2）或复发** | 挽救性治疗选项 |
| 禁忌 | 喉部受累、照射野内含金属异物 |

### 8.7 多形性腺瘤复发——PORT 的争议

> 良性肿瘤的 PORT 需经 MDT 讨论。以下情况**可讨论** PORT（SFRO 2025）：

| 条件 | 剂量 |
|------|------|
| >5 cm 或**多灶性** | 56-60 Gy |
| **多次复发**（≥2 次） | 56-60 Gy |
| **面神经受威胁**（再次手术可能牺牲面神经） | 56-60 Gy |
| **R1/R2** | 60-70 Gy（按恶性标准） |

> **反对 PORT 的理由**：良性疾病的放疗相关后遗症（口干/继发肿瘤）可能超过获益。**必须 MDT 评估。**

### 8.8 颈清扫后豁免颈部照射的新规则

> 🔥 SFRO 2025 新规则：如果颈清扫覆盖 **Ib-IV 区** 且术后病理证实 **≥15 枚淋巴结均阴性（pN0）** → **可完全豁免颈部照射**。这个规则不在任何中国指南中——但解剖逻辑非常有力。

```
pN0 + 颈清扫 Ib-IV + ≥15 LN 阴性 → 豁免颈部 ENI
pN0 + 未做颈清扫或不足 15 LN → 按级别预防（见第五节）
pN+ → 必须照同侧
```

### 8.9 随访——ACC/高级别需 15 年

| 肿瘤类型 | 随访时长 | 频率（前 2 年） | 频率（3-5 年） | 检查内容 |
|---------|:--:|------|------|------|
| ACC、MEC、恶性多形性腺瘤 | **15 年** | 每 2-3 月 | 每 6 月 | 头颈 MRI+胸部 CT（每年） |
| 其他中低危 | 5 年 | 每 3-6 月 | 每 6-12 月 | 头颈 CT+胸部 CT |

> 为什么 ACC 要随访 15 年：ACC 的 10-15 年远处转移率仍显著——肺转移可发生在初治后 10 年以上。

## 九、化免新辅助后降级策略

> 唾腺癌缺乏口腔 SCC 那样成熟的化免新辅助后降级证据。以下是基于九院经验的初步框架：

| 新辅助后缓解 | PORT 调整 |
|------------|---------|
| **pCR（ypT0）**——仅见于淋巴上皮癌 | 54 Gy（降 6 Gy），颈部维持原方案 |
| **MPR（ypT1，残留 <10%）** | 60 Gy（不降），颈部不降 |
| **non-MPR** | 60-66 Gy，标准方案 |

> ⚠️ **重要**：除淋巴上皮癌外，唾液腺癌的化免新辅助数据极少——目前不应将此作为标准推荐。这是探索性领域。

## 十、与 ACC Skill 的关系

| 项目 | ACC Skill | 本 Skill |
|------|:--:|:--:|
| ACC 靶区勾画 | ✅ 完整（神经径路、Tier 1-3） | ❌ 不覆盖——引用 ACC Skill |
| 非 ACC 唾液腺癌 | ❌ | ✅ 腮腺/颌下腺/舌下腺/小唾液腺 |
| 淋巴上皮癌根治性 CRT | ❌ | ✅ 独立章节 |
| 侧性肿瘤双侧规则 | ✅ v1.2.0（舌下腺+腭神经） | ✅ 引用 ACC Skill |
| SBRT 补量 | ✅ 引用再程 Skill | 适用（相同 BED 逻辑） |

> **两 Skill 互补但不重叠。** 遇到 ACC→加载 ACC Skill。遇到其他唾腺癌→加载本 Skill。
