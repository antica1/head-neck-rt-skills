# 分期铁律——最容易犯的三个错误

> 2026-07 多次纠正后总结。每次分析口腔癌/口咽癌时必须自检。

---

## 错误 1：DOI 用于 cT 分期 ❌

```
错误示例：cT3（DOI 8 mm）
正确：      pT3（DOI 8 mm）— DOI 是病理测量值，仅用于 pT
```

**原因**：浸润深度需要病理切片测量——手术标本切下来才能测。影像学（CT/MRI）不能精确测量 DOI。

| 分期前缀 | 依据 | DOI？ |
|---------|------|:--:|
| **cT**（临床）| 影像大小 + 侵犯范围 | ❌ |
| **pT**（病理）| 手术标本大小 + DOI | ✅ |
| **ypT**（新辅助后）| 残留肿瘤大小 | ❌（ypT0=无肿瘤=无DOI） |

---

## 错误 2：pT 和 ypT 并列为同一病例的分期 ❌

```
错误示例：pT3N1M0 → ypT0N0
正确：      cT3N1M0（术前）→ ypT0N0（新辅助后病理）
```

**原因**：pT = 无新辅助治疗的直接手术病理分期。ypT = 新辅助治疗后的病理分期。同一病例只有其中一个——有 yp 就没有 p。

---

## 错误 3：ypT0 的病例中仍在讨论 DOI ❌

```
错误示例：ypT0N0，DOI 8 mm → T3
正确：     ypT0 = 无肿瘤残留，不存在 DOI
```

**原因**：DOI 是肿瘤浸润深度的测量值——如果肿瘤已完全缓解（pCR），没有肿瘤可测，DOI 不存在。DOI 数据属于治疗前的评估，用于 cT 分期，与 yp 无关。

---

## 自检清单（每次分析前过一遍）

- [ ] 分期前缀是什么？c / p / yp？
- [ ] 如果用了 pT，DOI 来源是病理报告吗？
- [ ] 如果用了 cT，列出的依据是影像学参数（大小/侵犯）吗？
- [ ] 有没有同时出现 pT 和 ypT？只能二选一。
- [ ] ypT0 的病例里有没有提到 DOI？不应该有。
