## ⚠️ 影像+内镜依赖声明

> **本 Skill 中的 GTV 定义依赖术前 MRI/CT **和**内镜检查所见范围**。AI 无法读片也无法看内镜图像——报告中边界须以"建议 + 依据 + 请确认"格式输出。** 若术前影像未提供肿瘤具体范围→CTV 外放 **+5mm**。若内镜报告中仅提及"可见肿瘤"而无具体边界描述→前连合、声门上/下扩展范围按解剖默认值处理，标注为推断。

## 根治性 RT 与术后 PORT 的根本差异

| | 术后 PORT | 根治性 RT |
|---|---|---|
| **靶区基础** | 手术床 + Stoma + 病理 | **GTV（影像+内镜）** |
| **剂量方案** | 序贯（60/54 Gy + 缩野），**不用 SIB** | **SIB（70/63/56 Gy）** |
| **喉保留** | 已切除 | **T1-T2 声门→RT 首选**（保声优于激光） |
| **GTV 定义** | 依据病理 | **内镜所见范围是必要组成部分——CT/MRI 均低估** |
| **关键风险** | Stoma 遗漏 | **GTV 勾画不足**（尤其前连合、浅表扩散） |

## 一、喉的解剖基础

| 结构 | 临床意义 |
|------|---------|
| **甲状软骨** | 前连合 Broyle 韧带插入——肿瘤→软骨仅 1-2 mm |
| **环状软骨** | 唯一完整软骨环——声门下侵犯前哨 |
| **杓状软骨** | 声带固定=杓状软骨受侵 |
| **声门旁间隙** | 肿瘤上下扩散的"地下通道" |
| **会厌前间隙** | 声门上→舌根→对侧的桥梁——T2 以上必含 |
| **喉室** | 跨喉室=跨声门癌 |
| **前连合** | Broyle 韧带→甲状软骨——T1 可因软骨近而升为 T4 |
| **环甲膜** | 声门下侵犯的前哨 |

### 与下咽的交界

> 声门上喉（尤其会厌/杓会厌皱襞）与下咽（梨状窝内侧壁）解剖相邻——**跨区肿瘤必须同时参考 `hypopharynx-rt-targets` 的梨状窝规则**。会厌谷受累→向舌根/下咽方向 1-1.5 cm 延伸。

## 二、GTV 勾画——根治性 RT 的核心

### 2.0 诱导化疗前定位流程（2025 国家癌症中心指南）

> 🔥 **MDT 决定先诱导化疗时**：
> 1. **诱导化疗前先做放疗定位**（CT 模拟定位）
> 2. 诱导化疗后**重新定位**
> 3. **两次定位图像融合**——评估肿瘤大小和位置改变对靶区确定的影响
> 4. **放疗需在诱导化疗后 3-4 周内开始**

### 2.1 GTV 定义的特殊规则

> ⚠️ **内镜下可见病变但 CT/MRI 不可见（T1 声门癌常见）→ GTV 以内镜描述范围为准。前连合必须基于内镜所见纳入。**

| 模态 | 看什么 | 局限性 |
|------|--------|--------|
| **CT** | 软骨侵犯（骨窗必需） | GTV-CT 平均比手术标本小 15%（Daisne 2004） |
| **MRI** | 软骨侵犯、声门旁间隙 | GTV-MRI 比 CT 大 10%，敏感性 89% |
| **FDG-PET** | 淋巴结、远处转移 | 最准确但**所有模态均漏掉黏膜浅表扩散** |
| **内镜** | **黏膜表面范围** | **不可替代——是 GTV 定义的必要组成部分** |

### 2.2 GTV→CTV 外放（喉）

| 亚部位 | 外放 | 理由 |
|--------|------|------|
| **声门 T1-T2** | 1-1.5 cm | 局限性好，黏膜下扩散少 |
| **声门上 T2+** | 1.5-2 cm | 会厌前间隙和声门旁间隙的黏膜下扩散 |
| **声门下** | 2 cm（各向） | 黏膜下扩散广泛 |
| **软骨侵犯区** | **全层软骨纳入** | 软骨内无真正的外科平面 |

> **DAHANCA 5mm 验证**（Hansen 2024）：过渡至统一 5mm GTV→CTV1 外放后，3 年局部控制率无变化。**5mm 是最低安全外放——但不是所有亚部位都够**（声门下 2cm）。

> **前连合特殊规则**：前连合处 GTV→CTV 不是固定 5mm——是从黏膜表面到甲状软骨内板全厚度。Broyle 韧带处黏膜下扩散沿韧带纤维直达软骨——此处距离仅 1-2 mm。

### 2.3 PTV 外扩（2025 国家癌症中心指南——喉）

- **喉癌**：GTVp 外扩 **5-8mm**；GTVnd 和 CTV 至少外扩 3mm
- 放疗前验证推荐**锥形线束 CT（CBCT）引导**
- PRV：脊髓等串联器官外扩 **3mm**（喉）；晶状体/耳蜗等小结构也建议 PRV
- **T4 PTV 特殊规则**：喉随吞咽上下移动→PTV 上方外扩 **1 cm**、前界外扩 5 mm、其他方向 3 mm。如 PTV 前界超出皮缘，颈前填 5 mm bolus

## 三、根治性 RT——按亚部位

### 3.0 亚部位概览

| 亚部位 | T 分期关键 | 淋巴结风险 | 首选治疗 |
|--------|----------|:--:|------|
| **声门上** | 会厌前间隙→T3 | Ⅱ-Ⅲ（双侧 20-30%） | CRT/RT or 手术 |
| **声门** | 前连合→软骨→T4 | T1 不照；T3+ 同侧 Ⅱ-Ⅲ-Ⅳ | **RT 优先（保声）** |
| **声门下** | 环状软骨→T4 | **Ⅵ 区必照** | 全喉+PORT |
| **跨声门** | 跨喉室 | Ⅱ-Ⅲ-Ⅳ+Ⅵ | CRT/RT or 全喉 |

### 3.1 声门上癌

**GTV→CTV 关键点**：
- 会厌前间隙 T2+→**必须全含**
- 舌根：会厌谷受累→同侧舌根 1-1.5 cm
- 声门旁间隙：肿瘤紧邻→同侧全间隙
- 对侧：跨中线→双侧 Ⅱ-Ⅲ 预防

**SIB 剂量**：
- GTV-P：70 Gy/35 fx
- CTV-H（GTV+5-10 mm）：63 Gy/35 fx
- CTV-I（ENI Ⅱ-Ⅲ，双侧如跨中线）：56 Gy/35 fx

### 3.2 声门癌——RT 首选保声

| T 分期 | GTV→CTV | ENI |
|--------|---------|:--:|
| **T1-T2 N0** | GTV+1-1.5 cm。前连合→含 Broyle 韧带+对侧声带前 1/3 | **不做 ENI** |
| **T3（声带固定）** | 声门旁间隙全含→杓状软骨→环甲膜 | 同侧 Ⅱ-Ⅲ-Ⅳ（50 Gy） |
| **T4（软骨穿透）** | 甲状软骨全层→对侧声门旁间隙→对侧杓状软骨 | 同侧 Ⅱ-Ⅲ-Ⅳ+Ⅵ |

> **T2声门癌高危因素→考虑 ENI**（同侧 II-III, 50 Gy）：广泛声门上侵犯、广泛声门下侵犯、前连合受侵且深层扩展、外生型大体积。

### 3.3 声门下癌

- 环状软骨全层 + 声门下黏膜 1.5 cm 各向
- 向上含声门上喉（逆流通路）
- 向下含气管上段 2-3 cm
- **双侧 Ⅵ 区必照**——50-54 Gy
- T4→上纵隔（胸骨切迹以下 2 cm）

### 3.4 跨声门癌

- 全喉照射——从会厌谷到环状软骨下缘
- 声门旁间隙双侧全含
- ENI：双侧 Ⅱ-Ⅲ-Ⅳ + Ⅵ

## 四、PORT——按术式

### 4.1 气管造口（Stoma）——喉 PORT 的核心

> ⚠️ **口腔癌中气管切开是"种植风险"——喉癌里 Stoma 是手术边界本身。全喉切除术后的 Stoma 必须在 CTV-60 内。**

> **术后GTV勾画铁律**：无论术后病理显示治疗后改变甚至完全缓解，GTV勾画必须参考**化免前/术前**的影像学范围。化免前的原发灶侵犯区域必须纳入CTV1（高危区），不能因术后病理显示「治疗后改变」而缩小靶区。

| Stoma 状态 | CTV 要求 |
|-----------|---------|
| **全喉切除 Stoma** | 全层皮肤+皮下+气管环周 1-2 cm→**CTV-60 必须含 Stoma** |
| **术中冰冻 Stoma 阳性** | CTV-66——R1 区域推量 |
| **气管切开（非全喉）** | 种植风险，纳入 CTV-54 |

### 4.2 全喉切除术后 CTV

```
CTV-60（高危）：
├── 咽吻合口各向 1.5-2 cm
├── Stoma 全层（皮肤+气管环周 1-2 cm）
├── 舌根（若肿瘤曾贴邻→同侧舌根 1 cm）
├── 原发灶术床（按术前 MRI/内镜还原）
└── 原阳性 LN 站+直接下游一站

CTV-54（预防）：
├── 同侧 Ib-II-III-IV（声门上 T3+ 或 N2+）
├── 同侧 VI（声门下/声门下侵犯）
└── 对侧 II-III（仅中线/近中线+N2+）
```

### 4.3 部分喉切除术后

| 术式 | CTV 要点 |
|------|---------|
| **声带切除术** | 残余声带+前连合+对侧声带前 1/3（切缘<5 mm） |
| **声门上喉切除术** | 残余会厌+舌根 1 cm+同侧声门旁间隙 |
| **半喉切除术** | 残余半喉全层+对侧杓状软骨（近中线） |
| **保留的喉软骨** | 即便切缘阴性→保留的软骨仍需全层预防——软骨不是安全边界 |

## 五、PORT 亚部位 CTV

### 5.1 声门上癌 PORT

| CTV 要点 | 范围 |
|---------|------|
| **会厌前间隙** | T2+→**必须全含**——声门上癌通向舌根和对侧的"高速公路" |
| **舌根** | 会厌谷受累→同侧舌根 1-1.5 cm |
| **声门旁间隙** | 肿瘤紧邻→同侧全间隙纳入 |
| **对侧** | T2+ 跨中线→双侧 Ⅱ-Ⅲ 预防 |
| **Ⅵ区** | 一般不照——除非明确声门下侵犯 |

### 5.2 声门癌 PORT

| T 分期 | CTV 要点 | ENI |
|--------|---------|:--:|
| **T1-T2 N0** | GTV+1-1.5 cm。前连合受累→含 Broyle 韧带插入点+对侧声带前 1/3 | **不做 ENI** |
| **T3（声带固定）** | 声门旁间隙全含→同侧杓状软骨→环甲膜 | 同侧 Ⅱ-Ⅲ-Ⅳ（50 Gy） |
| **T4（软骨穿透）** | 甲状软骨全层纳入→对侧声门旁间隙→对侧杓状软骨 | 同侧 Ⅱ-Ⅲ-Ⅳ+Ⅵ |

### 5.3 声门下癌 PORT

| CTV 要点 | 范围 |
|---------|------|
| **原发性 CTV** | 环状软骨全层 + 声门下黏膜 1.5 cm 各向 |
| **向上** | 声门下→声门→声门上逆流通路→含声门上喉 |
| **向下** | 气管上段 2-3 cm |
| **Ⅵ 区（气管旁）** | **双侧必照**——50-54 Gy |
| **上纵隔** | T4→Ⅵ 区延续至胸骨切迹以下 2 cm |
| **颈部** | 同侧 Ⅱ-Ⅲ-Ⅳ-Ⅴ |

### 5.4 跨声门癌 PORT

同时累及声门上、声门、声门下——常为 T3-T4。

| CTV 要点 | 范围 |
|---------|------|
| **全喉照射** | 从会厌谷到环状软骨下缘全层 |
| **声门旁间隙** | 双侧全含 |
| **ENI** | 双侧 Ⅱ-Ⅲ-Ⅳ + Ⅵ |

## 六、淋巴结预防——Ⅵ 区为核心

### 6.1 淋巴结站区对比（喉）

| 分区 | 声门上 | 声门 | 声门下 | 跨声门 |
|:--:|:--:|:--:|:--:|:--:|
| **II/III** | ✅ | T3+ | ✅ | ✅ |
| **IV** | T3+/N2+ | T3+/N2+ | ✅ | ✅ |
| **V** | N2b+ | N2b+ | N2b+ | N2b+ |
| **VI** | ❌(除声门下) | T4/声门下 | ✅ 双侧 | ✅ 双侧 |
| **VII(RP)** | T3+可选 | ❌ | ❌ | T3+可选 |

> **V区豁免循证** — Looman et al. *Radiother Oncol* 2026：390例多中心研究。II/III阴性时V区转移率降至**1%**。V区转移为II/III区受累后的序贯事件（非独立跳跃转移）→ II/III阴性时 V 区可安全豁免。

> **口诀**：口Ⅰ喉不照，声门下Ⅵ必包。

### 6.2 Ⅵ 区（气管旁/气管食管沟）

```
上界：环状软骨下缘
下界：胸骨切迹
外侧界：颈总动脉内侧缘
```

| 条件 | 同侧 Ⅵ | 双侧 Ⅵ |
|------|:--:|:--:|
| 声门下癌 | ✅ | ✅ |
| 声带固定 T3+ | ✅ | 视中线情况 |
| 跨声门癌 | ✅ | ✅ |
| 颈段食管受累 | ✅ | ✅ |

### 6.3 RP（咽后淋巴结）——喉癌一般不需要

> 喉癌 RP 转移罕见。仅**声门上 T3+ 紧邻下咽交界区**时考虑同侧 RP（参考 `hypopharynx-rt-targets` 的 RP 规则）。若声门上癌已明确跨入梨状窝/会厌谷深部→按下咽规则处理 RP。

## 七、剂量策略

### 根治性 RT——SIB

| 剂量层级 | 范围 | 处方 |
|---------|------|------|
| **GTV-P** | 影像+**内镜所见**原发灶 | 70 Gy/35 fx |
| **GTV-N** | 阳性淋巴结 | 70 Gy/35 fx |
| **CTV-H** | GTV-P + 5-10 mm（按亚部位） | 63 Gy/35 fx |
| **CTV-I** | ENI——按亚部位和 N 分期 | 56 Gy/35 fx |
| **CTV-L** | 低危预防区（对侧颈等） | 50.4-54 Gy/28-30 fx |

> **喉根治性 RT 适合 SIB**——GTV 通常在软组织/软骨内，不像口腔癌在骨-软组织界面上有剂量重建误差。

### PORT——序贯（不用 SIB）

| PTV 层级 | 剂量 | 适应证 |
|---------|------|--------|
| **PTV-66-70** | 66-70 Gy/33-35 fx | R1/R2（Stoma 阳性）、ENE+ |
| **PTV-60** | 60 Gy/30 fx | 手术床（Stoma 必含）、原阳性 LN 站+下游一站 |
| **PTV-54** | 54 Gy/30 fx | 预防区（同侧未受累颈、Ⅵ 预防） |
| **PTV-50** | 50 Gy/25-30 fx | 低风险预防（对侧颈Ⅱ-Ⅲ） |

## 八、OAR 约束

| OAR | 限量 | 喉特有挑战 |
|-----|------|----------|
| 脊髓 | Dmax ≤45 Gy | |
| 脑干 | Dmax ≤54 Gy | |
| 咽缩肌 | Dmean ≤54 Gy | 吞咽关键 |
| **喉（保留时）** | Dmean ≤45 Gy | **T1-T2 保声→喉的剂量约束是核心** |
| **气管** | V50 < 50% | 声门下/Ⅵ 照射→晚期气管软化 |
| 甲状腺 | V50 < 50% | 甲减率 40-60% |
| **颈动脉** | Dmax < 50 Gy | 全喉切除后颈动脉裸露于术床 |
| **臂丛** | Dmax ≤60 Gy | 下颈部/上纵隔 |
| 腮腺 | Dmean ≤26 Gy | 双侧颈预防→双侧腮腺挑战 |
| 下颌骨 | Dmax ≤70 Gy | 喉癌通常不紧邻 |

## 九、化免新辅助后降级（参考 `neoadjuvant-deescalation`）

| | 喉癌 |
|---|---|
| **降级优先** | 降范围 > 降剂量 |
| **理由** | 对侧颈/Ⅵ 可缩 |
| **Stoma 豁免** | pCR+切缘≥5mm+声门下阴性+气管阴性→可考虑不照 Stoma |
| **手术降级补偿** | 保留的半喉→CTV-54（pCR）或 CTV-60（MPR），软骨全层——不是仅黏膜 |

> 下咽癌的降级策略（降剂量 > 降范围）见 `hypopharynx-rt-targets`——**两部位降级优先级相反，切勿混用**。

## 十、勾画流程

### 根治性 RT 六步法

| 步 | 操作 |
|----|------|
| 1 | 获取诊断 MRI/CT + **内镜检查报告+图像**（不可替代） |
| 2 | 内镜所见范围定义 GTV——CT/MRI 辅助判断深部边界 |
| 3 | GTV→CTV 外放按亚部位（第三节）+ 软骨侵犯→全层纳入 |
| 4 | 按 N 分期和亚部位决定 ENI（Ⅵ 区、对侧颈，第六节） |
| 5 | SIB 剂量分配（第七节） |
| 6 | 检查 OAR（第八节）——保声病例喉 Dmean ≤45 Gy 优先 |

### PORT 十步法

| 步 | 操作 |
|----|------|
| 1 | 获取术前 MRI/CT + 内镜检查报告 + 内镜图像 |
| 2 | 获取手术记录（术式、Stoma 位置、重建方式） |
| 3 | 获取病理报告（各切缘、软骨侵犯、PNI、ENE、淋巴结） |
| 4 | 融合术前影像到定位 CT → 还原原始 GTV-T 和 GTV-N |
| 5 | 按亚部位规则勾画 CTV-P（第五节） |
| 6 | 处理 Stoma（全喉→CTV-60 含 Stoma；非全喉→种植风险 CTV-54） |
| 7 | 按 N 分期和亚部位决定 ENI 范围（Ⅵ 区、对侧颈，第六节） |
| 8 | 处理软骨侵犯→全层软骨纳入 CTV（不是 5 mm 外放） |
| 9 | PTV 外放 3-5 mm（每日 CBCT） |
| 10 | 检查关键 OAR（Stoma 剂量、颈动脉 Dmax、臂丛、气管） |

## 十一、失败模式

| 失败位置 | 根本原因 | 预防规则 |
|---------|---------|---------|
| 前连合处局部复发 | 仅凭 CT 勾画 GTV——未含 Broyle 韧带全层 | 前连合→黏膜到软骨全厚度 |
| 声门上对侧Ⅱ区复发 | ENI 未覆盖对侧颈 | T2+ 跨中线→双侧Ⅱ-Ⅲ |
| 声门下气管旁复发 | Ⅵ区未纳入 ENI | 声门下→双侧Ⅵ区必照 |
| 软骨边缘复发 | GTV 低估→CTV 外放不足 | 内镜所见+软骨全层 |
| 跨声门对侧喉复发 | 只照同侧半喉 | 跨声门→双侧声门旁间隙 |
| Stoma 复发 | Stoma 未纳入 CTV-60 | 全喉→Stoma 全层必含 |
