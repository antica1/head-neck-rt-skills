# 头颈肿瘤再程放疗方案推荐

## 铁律清单

| # | 铁律 | 触发条件 |
|---|------|---------|
| 1 | Quad-Shot（3.7Gy×4 BID Q4w×3程+Pembro） | 前一程≤54 Gy或间隔>3年，复发/不可切除HNC |
| 2 | 累积BED必算（前一程残余+本程） | 任何再程放疗决策前 |
| 3 | 间隔<6月不修复 / >2年修复70% | 正常组织修复修正 |
| 4 | SBRT >6 Gy/fx BED失真 | SBRT方案BED计算时 |
| 5 | IO增敏 SER 1.1-1.3（安全备份SER=1.0） | 联合IO/ADC时OAR限量收紧 |
| 6 | 累积晚期EQD2 >60 → 仅常规分割 | 高累积剂量场景 |
| 7 | Q3w单次+IO用于中等风险 | 累积晚期EQD2 50-60 Gy区间 |
| 8 | 脊髓Dmax累积 <100 Gy₂ | 任何再程照射 |
| 9 | 骨侵犯区域优先常规分割 | 下颌骨/颅底骨受侵时 |

## 二、内置推理链

### Step 1：算前一程残余

```
前一程 EQD2 = 处方 × (1 + 2/αβ) / (1 + 2/αβ) = 处方
间隔年数 → 修复比例
  <6 月 → 不修正
  6-12 月 → 修复 30%
  1-2 年 → 修复 50%
  >2 年 → 修复 70%

累积晚期 EQD2 = 前一程残余 + 本程 EQD2
累积肿瘤 BED₁₀ = 前一程 BED₁₀（不复修）+ 本程 BED₁₀
```

### Step 2：筛选可行方案

| 方案 | 处方 | 免疫增敏 | 适用条件 |
|------|------|---------|---------|
| **Quad-Shot + IO** | 3.7 Gy × 4 BID，Q4w × 3 程 | PD-1（Pembrolizumab） | 前一程 ≤54 Gy 或间隔 >3 年 |
| **Q3w 单次 + IO** | 3.5 Gy × 1，Q3w × 6 程 | PD-1 或 ADC | 前一程 ≤66 Gy |
| **常规分割** | 2 Gy × 15-20 次 | 不可用增敏 | 所有，最安全 |
| **SBRT 连续** | 5-6 Gy × 5 | PD-1 | 前一程 ≤50 Gy |

### Step 3：裁决

```
累积晚期 EQD2 ≤40 Gy → 方案无限制
累积晚期 EQD2 40-50 Gy → Quad-Shot 可用，SBRT 连续受限
累积晚期 EQD2 50-60 Gy → 仅 Q3w 单次或常规分割
累积晚期 EQD2 >60 Gy → 仅常规分割（且 ≤15 次）
```

## 三、内置证据库

### Quad-Shot 方案（JAMA Otolaryngol 2026）

| 参数 | 值 |
|------|-----|
| 处方 | 3.7 Gy × 4 次（BID，间隔 ≥6h），每 4 周一程，最多 3 程 |
| 联合药物 | Pembrolizumab 200 mg Q3w |
| 总物理剂量 | 14.8 Gy/程 × 3 = 44.4 Gy |
| 适应人群 | 复发/不可切除/转移性 HNC |
| 免疫机制 | 连续 4 次 BID→累积 ICD 跨越免疫激活阈值；Q4w 间隙→T 细胞扩增 |
| 正常组织 | 每程 BED₃=33.1 Gy₃→修复后~20 Gy₃→3 程累积~60 Gy₃→EQD2~36 Gy |

### Q3w 单次 + IO 方案（九院经验）

| 参数 | 值 |
|------|-----|
| 处方 | 3.5 Gy × 1，每 3 周，共 6 程 |
| 联合药物 | PD-1 或 ADC（照射后 24h 内） |
| 总物理剂量 | 21 Gy |
| 机制 | 每次低剂量 RT→周期性抗原释放；3 周间隙→正常组织修复 |
| 局限性 | 单次 3.5 Gy 可能低于 ICD 最佳阈值（6-12 Gy） |
| 正常组织 | 累积晚期 EQD2~18 Gy（3 周修复修正后） |

### 免疫阈值概念

```
单次剂量 < 4 Gy   → ICD 信号可能不足以激活免疫
单次剂量 4-6 Gy   → 弱至中等 ICD
单次剂量 6-12 Gy  → 最佳 ICD 窗口
单次剂量 >12 Gy   → 可能杀伤浸润 T 细胞
```

## 五、SBRT 后常规分割补量（SBRT Boost Consolidation）

> **适用场景**：SBRT 首程照射后（如 5.5 Gy×5fx 或 6-8 Gy×3fx），因各种原因（毒副作用/经济/依从性）中断全身治疗，需用常规分割 RT 补足根治剂量。最常见于 ACC、肉瘤等相对放射抗拒的肿瘤。

### 5.1 BED 计算

```
累积 EQD2₁₀ = EQD2₁₀(SBRT) + EQD2₁₀(常规补量)
EQD2₁₀(SBRT) = 总剂量 × (1 + d/10) / 1.2
EQD2₁₀(常规补量) = 2 Gy × fx 数（如用 2 Gy/fx）
```

### 5.2 常见 SBRT 方案 → 常规补量速查表

| 首程 SBRT | EQD2₁₀ 已有 | 补量至 60 Gy（ACC/鳞癌） | 补量至 50 Gy（淋巴瘤/良性疾病） |
|-----------|:--:|------|------|
| 5.0 Gy × 5 = 25.0 Gy | 31.3 Gy | 34-38 Gy / 17-19 fx | 18-22 Gy / 9-11 fx |
| 6 Gy × 5 = 30 Gy | 40.0 Gy | 20 Gy / 10 fx | 10 Gy / 5 fx |
| 8 Gy × 3 = 24 Gy | 36.0 Gy | 24 Gy / 12 fx | 14 Gy / 7 fx |

### 5.3 间隔时间修正

| 间隔 | 正常组织修复 | 补量调整 |
|------|:--:|------|
| <4 周 | 几乎无修复 | 按累积 BED 严格限量 |
| 4-12 周 | 部分修复（黏膜 60-80%，神经 <30%）| 黏膜限量可放宽 10%，神经/脑干不放松 |
| >12 周 | 显著修复 | 可接近常规限量，但仍需重算累积 BED |

### 5.4 ADC/靶向增敏的残留效应

抗 EGFR ADC 的 SER 约 1.1-1.3——停药后衰减半衰期约 3-4 周。停药 4 个月后增敏效应可忽略不计，但仍需考虑 ADC 引起的正常组织敏感性（如已出现 3 级神经毒性→补量 RT 时需额外警惕神经相关 OAR）。

### 5.5 病例示例——鼻咽 ACC 的 SBRT+补量

```
首程：5 Gy × 5 fx + 抗 EGFR ADC × 4 周期（根治性，无手术）
间隔：4 个月
补量方案：36 Gy / 18 fx（常规分割）
累积 EQD2₁₀：31.3 + 36 = 67.3 Gy → 达到 ACC 根治门槛
靶区：GTV（残留）+ 鼻咽顶略过中线 + 同侧壁
不照：颈部（无 LN+）、颅底孔道（无 PNI）——鼻咽 ACC 不同于 SCC
```
