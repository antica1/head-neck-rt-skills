## 根治性 RT 与术后 PORT 的根本差异

| | 术后 PORT | 根治性 RT |
|---|---|---|
| **靶区基础** | 手术床 + Stoma + 病理 | **GTV（影像+内镜）** |
| **剂量方案** | 序贯（60/54 Gy + 缩野），**不用 SIB** | **SIB（70/63/56 Gy）** |
| **喉保留** | 已切除 | **T1-T2 声门→RT 首选**（保声优于激光） |
| **GTV 定义** | 依据病理 | **内镜所见范围是必要组成部分——CT/MRI 均低估** |
| **关键风险** | Stoma 遗漏 | **GTV 勾画不足**（尤其前连合、浅表扩散） |

## 一、解剖基础

### 1.1 喉的关键结构

| 结构 | 临床意义 |
|------|---------|
| **甲状软骨** | 前连合 Broyle 韧带插入——肿瘤→软骨仅 1-2 mm |
| **环状软骨** | 唯一完整软骨环——声门下侵犯前哨 |
| **杓状软骨** | 声带固定=杓状软骨受侵 |
| **声门旁间隙** | 肿瘤上下扩散的"地下通道" |
| **会厌前间隙** | 声门上→舌根→对侧的桥梁——T2 以上必含 |
| **喉室** | 跨喉室=跨声门癌 |
| **前连合** | Broyle 韧带→甲状软骨——T1 可因软骨近而升为 T4 |

### 1.2 下咽关键结构

| 亚部位 | 边界 | 淋巴引流 |
|--------|------|---------|
| **梨状窝** | 咽侧壁·杓会厌皱襞·环后区 | Ⅱ-Ⅲ-Ⅳ → RP → Ⅵ |
| **环后区** | 杓状软骨→环状软骨后板→食管入口 | 双侧 RP → 双侧 Ⅵ |
| **咽后壁** | 舌骨水平→环咽肌·椎前筋膜 | 双侧 RP |

## 二、GTV 勾画——根治性 RT 的核心

### 2.1 GTV 定义的特殊规则

> ⚠️ **内镜下可见病变但 CT/MRI 不可见（T1 声门癌常见）→ GTV 以内镜描述范围为准。前连合必须基于内镜所见纳入。**

| 模态 | 看什么 | 局限性 |
|------|--------|--------|
| **CT** | 软骨侵犯（骨窗必需） | GTV-CT 平均比手术标本小 15%（Daisne 2004） |
| **MRI** | 软骨侵犯、声门旁间隙 | GTV-MRI 比 CT 大 10%，敏感性 89% |
| **FDG-PET** | 淋巴结、远处转移 | 最准确但**所有模态均漏掉黏膜浅表扩散** |
| **内镜** | **黏膜表面范围** | **不可替代——是 GTV 定义的必要组成部分** |

### 2.2 GTV→CTV 外放

| 亚部位 | 外放 | 理由 |
|--------|------|------|
| **声门 T1-T2** | 1-1.5 cm | 局限性好，黏膜下扩散少 |
| **声门上 T2+** | 1.5-2 cm | 会厌前间隙和声门旁间隙的黏膜下扩散 |
| **声门下** | 2 cm（各向） | 黏膜下扩散广泛 |
| **梨状窝** | 1.5-2 cm | 同声门上 |
| **环后** | 2-3 cm（上下） | 沿食管入口的黏膜下扩散 |
| **咽后壁** | 2-3 cm（纵向） | 沿椎前筋膜的纵向扩散 |
| **软骨侵犯区** | **全层软骨纳入** | 软骨内无真正的外科平面 |

> **DAHANCA 5mm 验证**（Hansen 2024）：过渡至统一 5mm GTV→CTV1 外放后，3 年局部控制率无变化。**5mm 是最低安全外放——但不是所有亚部位都够**（声门下 2cm，环后 2-3cm）。

## 三、喉癌根治性 RT——按亚部位

### 3.0 亚部位概览

| 亚部位 | T 分期关键 | 淋巴结风险 | 首选治疗 |
|--------|----------|:--:|------|
| **声门上** | 会厌前间隙→T3 | Ⅱ-Ⅲ（双侧 20-30%） | CRT/RT or 手术 |
| **声门** | 前连合→软骨→T4 | T1 不照；T3+ 同侧 Ⅱ-Ⅲ-Ⅳ | **RT 优先（保声）** |
| **声门下** | 环状软骨→T4 | **Ⅵ 区必照** | 全喉+PORT |
| **跨声门** | 跨喉室 | Ⅱ-Ⅲ-Ⅳ+Ⅵ | CRT/RT or 全喉 |

### 3.1 声门上癌

**GTV→CTV 关键点**：
- 会厌前间隙 T2+→**必须全含**
- 舌根：会厌谷受累→同侧舌根 1-1.5 cm
- 声门旁间隙：肿瘤紧邻→同侧全间隙
- 对侧：跨中线→双侧 Ⅱ-Ⅲ 预防

**SIB 剂量**：
- GTV-P：70 Gy/35 fx
- CTV-H（GTV+5-10 mm）：63 Gy/35 fx
- CTV-I（ENI Ⅱ-Ⅲ，双侧如跨中线）：56 Gy/35 fx

### 3.2 声门癌——RT 首选保声

| T 分期 | GTV→CTV | ENI |
|--------|---------|:--:|
| **T1-T2 N0** | GTV+1-1.5 cm。前连合→含 Broyle 韧带+对侧声带前 1/3 | **不做 ENI** |
| **T3（声带固定）** | 声门旁间隙全含→杓状软骨→环甲膜 | 同侧 Ⅱ-Ⅲ-Ⅳ（50 Gy） |
| **T4（软骨穿透）** | 甲状软骨全层→对侧声门旁间隙→对侧杓状软骨 | 同侧 Ⅱ-Ⅲ-Ⅳ+Ⅵ |

> **前连合特殊规则**：前连合处 GTV→CTV 不是固定 5mm——是从黏膜表面到甲状软骨内板全厚度。Broyle 韧带处黏膜下扩散沿韧带纤维直达软骨——此处距离仅 1-2 mm。

> **T2声门癌高危因素→考虑 ENI**（同侧 II-III, 50 Gy）：广泛声门上侵犯、广泛声门下侵犯、前连合受侵且深层扩展、外生型大体积。

> **T4 PTV外放特殊规则**：喉随吞咽上下移动→PTV上方外扩 **1 cm**、前界外扩 5 mm、其他方向 3 mm。如PTV前界超出皮缘，颈前填 5 mm bolus。

### 3.3 声门下癌

- 环状软骨全层 + 声门下黏膜 1.5 cm 各向
- 向上含声门上喉（逆流通路）
- 向下含气管上段 2-3 cm
- **双侧 Ⅵ 区必照**——50-54 Gy
- T4→上纵隔（胸骨切迹以下 2 cm）

### 3.4 跨声门癌

- 全喉照射——从会厌谷到环状软骨下缘
- 声门旁间隙双侧全含
- ENI：双侧 Ⅱ-Ⅲ-Ⅳ + Ⅵ

## 四、下咽癌根治性 RT——按亚部位

> **下咽癌 RP 和 Ⅵ 区必照。** ⚠️ 食管第二原发癌概率约 30%→胃镜+碘染色。

### 4.1 梨状窝癌

**SIB 剂量**：
- GTV-P：70 Gy/35 fx
- CTV-H：63 Gy/35 fx
- CTV-I（ENI：同侧 Ⅱ-Ⅲ-Ⅳ-RP ± 同侧 Ⅵ）：56 Gy/35 fx
- 对侧 Ⅱ-Ⅲ（T3+ 或 N2+）：50-54 Gy

**GTV→CTV**：
- 外侧壁→向后至椎前筋膜
- 内侧壁→杓状软骨→声门旁间隙（喉方向）
- 梨状窝尖→颈段食管 1-2 cm
- RP：同侧**必照**（54-60 Gy）
- Ⅵ 区：梨状窝尖受累→同侧

### 4.2 环后癌

- 环状软骨后板全层
- 颈段食管 2-3 cm
- **双侧 RP 必照**
- **双侧 Ⅵ 区必照**
- 气管膜部纳入
- 双侧 Ⅱ-Ⅲ-Ⅳ 预防

### 4.3 咽后壁癌

- 后界：椎前筋膜——穿透=T4
- 纵向 2-3 cm 外放
- **双侧 RP 必照**
- T4 穿透椎前筋膜→椎前肌纳入 CTV

## 五、SIB 剂量方案

| 剂量层级 | 范围 | 处方 |
|---------|------|------|
| **GTV-P** | 影像（CT+MRI+PET 融合）+ **内镜所见**原发灶 | 70 Gy/35 fx |
| **GTV-N** | 阳性淋巴结 | 70 Gy/35 fx |
| **CTV-H** | GTV-P + 5-10 mm（按亚部位和 T 分期） | 63 Gy/35 fx |
| **CTV-I** | ENI——按亚部位和 N 分期 | 56 Gy/35 fx |
| **CTV-L** | 低危预防区（对侧颈预防等） | 50.4-54 Gy/28-30 fx |

> **喉/下咽根治性 RT 适合 SIB**——GTV 通常在软组织/软骨内，不像口腔癌在骨-软组织界面上有剂量重建误差。

## 六、淋巴结预防——Ⅵ 区与 RP

| 分区 | 声门上 | 声门 | 声门下 | 下咽 |
|:--:|:--:|:--:|:--:|:--:|
| **II/III** | ✅ | T3+ | ✅ | ✅ |
| **IV** | T3+/N2+ | T3+/N2+ | ✅ | T3+/N2+ |
| **V** | N2b+ | N2b+ | N2b+ | N2b+ |
| **VI** | ❌(除声门下) | T4/声门下 | ✅ 双侧 | ✅ 同侧/双侧 |
| **VII(RP)** | T3+可选 | ❌ | ❌ | ✅ **必照** |

### Ⅵ 区——何时照

| 条件 | 同侧 Ⅵ | 双侧 Ⅵ |
|------|:--:|:--:|
| 声门下癌 | ✅ | ✅ |
| 梨状窝尖受累 | ✅ | ❌（近中线→双侧） |
| 环后癌 | ✅ | ✅ |
| 颈段食管受累 | ✅ | ✅ |

### RP——下咽癌必照

> **下咽癌 RP 上界至少到 C1 横突水平（颅底）**——不能用"舌骨水平"。
> Looman 2026（390 例）：II/III 区阴性时 V 区转移率仅 1%→可安全豁免 V 区。

> **RP转移与下咽亚部位的关系**：
> - 下咽后壁 / 外侧壁 / 梨状窝外侧壁 → **高RP风险**（必照，上界C1）
> - 环后区 → **低RP风险**（MRI阴性时可考虑豁免同侧RP）

## 七、OAR 约束

| OAR | 限量 | 喉/下咽特有 |
|-----|------|----------|
| 脊髓 | Dmax ≤45 Gy | 下咽→RP→脊髓紧邻→需缩野 |
| 脑干 | Dmax ≤54 Gy | RP 上界近颅底 |
| 咽缩肌 | Dmean ≤54 Gy | 吞咽关键 |
| **喉（保留时）** | Dmean ≤45 Gy | T1-T2 保声→喉的剂量约束是核心 |
| **气管** | V50 < 50% | 声门下/Ⅵ 照射→晚期气管软化 |
| 甲状腺 | V50 < 50% | 甲减率 40-60% |
| **颈动脉** | Dmax < 50 Gy | 下咽癌颈动脉紧邻 |
| **臂丛** | Dmax ≤60 Gy | 下颈部/上纵隔 |
| 腮腺 | Dmean ≤26 Gy | 双侧颈预防→双侧腮腺挑战 |
| **颈段食管** | Dmax < 60 Gy | CTV 含食管但约束需权衡 |

## 八、化免新辅助后降级（参考 `neoadjuvant-deescalation`）

| | 喉癌 | 下咽癌 |
|---|---|---|
| **降级优先** | 降范围 > 降剂量 | **降剂量 > 降范围** |

## 九、根治性 RT 六步法

| 步 | 操作 |
|----|------|
| 1 | 获取诊断 MRI/CT + **内镜检查报告+图像**（不可替代） |
| 2 | 内镜所见范围定义 GTV——CT/MRI 辅助判断深部边界 |
| 3 | GTV→CTV 外放按亚部位（第三节）+ 软骨侵犯→全层纳入 |
| 4 | 按 N 分期和亚部位决定 ENI（Ⅵ、RP、对侧颈，第六节） |
| 5 | SIB 剂量分配（第五节） |
| 6 | 检查 OAR（第七节）——保声病例喉 Dmean ≤45 Gy 优先 |

## 十、失败模式

### 喉癌根治性 RT

| 失败位置 | 原因 | 预防 |
|---------|------|------|
| 前连合局部复发 | 仅凭 CT 勾画 GTV | 内镜所见→含 Broyle 韧带全层+软骨内板 |
| 声门上对侧Ⅱ区 | ENI 未覆盖对侧 | T2+ 跨中线→双侧Ⅱ-Ⅲ |
| 声门下气管旁 | Ⅵ区未纳入 | 声门下→双侧Ⅵ区 |
| 软骨边缘复发 | GTV 低估 | 软骨侵犯→全层纳入（不是 5mm） |

### 下咽癌根治性 RT

| 失败位置 | 原因 | 预防 |
|---------|------|------|
| **RP 复发（最常见）** | RP 未纳入或上界不足 | 同侧 RP 必照，上界至 C1 |
| Ⅵ区/气管旁 | 梨状窝尖→气管旁遗漏 | 梨状窝尖→同侧Ⅵ区 |
| 食管纵向失败 | CTV 食管长度不足 | 环后→颈段食管 2-3 cm |
