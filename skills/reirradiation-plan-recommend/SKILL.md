# 头颈肿瘤再程放疗方案推荐

## 🔴 铁律清单（出报告前逐条核验）

> **模型注意力焦点——以下规则在所有头颈再程放疗方案推荐中自动适用。**

| # | 铁律 | 触发条件 |
|:--:|------|---------|
| 1 | **间隔修复四档**：<6 月不修正；6-12 月修复 30%；1-2 年修复 50%；>2 年修复 70% | 任何再程放疗，计算前一程晚期组织残余 EQD2 |
| 2 | **肿瘤 BED 不复修**：累积肿瘤 BED₁₀ = 前一程 BED₁₀（不复修）+ 本程 BED₁₀，仅晚期 EQD2 按修复比例折减 | 计算累积肿瘤剂量时 |
| 3 | **Quad-Shot 处方锁定**：3.7 Gy×4 次 BID（间隔 ≥6h），每 4 周一程、最多 3 程，联合 Pembrolizumab 200 mg Q3w，总物理剂量 44.4 Gy | 复发/不可切除/转移性 HNC，前一程 ≤54 Gy 或间隔 >3 年 |
| 4 | **Q3w 单次方案**：3.5 Gy×1，每 3 周、共 6 程（总 21 Gy），PD-1 或 ADC 须在照射后 24h 内给药 | 前一程 ≤66 Gy，不适于 Quad-Shot 时 |
| 5 | **ICD 剂量窗口**：单次 6-12 Gy 为最佳 ICD；<4 Gy 不足以激活免疫；>12 Gy 杀伤浸润 T 细胞 | 选 SBRT/低分割 + IO 增敏的单次剂量 |
| 6 | **方案准入门槛**：SBRT 连续需前一程 ≤50 Gy；Quad-Shot+IO 需 ≤54 Gy 或间隔 >3 年；Q3w 单次需 ≤66 Gy | Step 2 筛选可行方案 |
| 7 | **累积晚期 EQD2 裁决线**：≤40 Gy 方案无限制；40-50 Gy Quad-Shot 可用、SBRT 连续受限；50-60 Gy 仅 Q3w 单次或常规分割；>60 Gy 仅常规分割且 ≤15 次 | Step 3 最终裁决 |
| 8 | **SBRT 补量公式**：累积 EQD2₁₀ = EQD2₁₀(SBRT) + EQD2₁₀(常规补量)；EQD2₁₀(SBRT) = 总剂量×(1+d/10)/1.2；补量至 60 Gy（ACC/鳞癌）或 50 Gy（淋巴瘤/良性疾病） | SBRT 首程后常规分割补足根治剂量 |
| 9 | **补量间隔修正**：<4 周按累积 BED 严格限量；4-12 周黏膜限量可放宽 10%、神经/脑干不放松；>12 周接近常规限量仍需重算累积 BED | SBRT 后补量的间隔判定 |
| 10 | **ADC SER 残留**：抗 EGFR ADC SER≈1.1-1.3，衰减半衰期 3-4 周，停药 4 个月后可忽略；不确定时以 SER=1.0 作安全备份 | 首程含 ADC/靶向增敏的补量病例 |
| 11 | **骨寡转移 BED 目标**：BED₁₀ ≥48-60 Gy；外周骨 30 Gy/3fx（BED₁₀=60）；脊柱 30 Gy/5fx（BED₁₀=48）；紧贴脊髓（<3 mm）27 Gy/3fx 或 24 Gy/2fx；颅骨/眼眶 30-35 Gy/5fx | 转移性 ACC 单发骨寡转移 SBRT |
| 12 | **脊髓硬限量**：3fx 方案 Dmax ≤22.5 Gy、<0.35cc ≤15.9 Gy；5fx 方案 Dmax ≤28 Gy、<0.35cc ≤22 Gy；紧贴脊髓时单次 ≤14-15 Gy | 骨寡转移 SBRT 累及脊柱 |
| 13 | **骨转移靶区层级**：GTV=MRI T1/T2 融合骨病灶+骨外软组织；CTV=GTV+3-5 mm（不越骨皮质）；PTV=+3 mm | 骨寡转移 SBRT 计划设计 |
| 14 | **BED₃ 上限警戒**：BED₃ >130 Gy 时 ORN/椎体压缩风险，倾向 30-35 Gy/5fx 而非更高单次量 | 骨寡转移 SBRT 剂量爬升时 |
| 15 | **第三程准入先问替代**：第三程再照前必须已讨论并记录——lenvatinib 再挑战（ACC，Caspani 2025, PMID 40033633）、Ⅰ期临床、观察等待（惰性+无症状+CBS 高危） | 第三程及以上再照 |
| 16 | **灾难风险知情同意**：CBS/脊髓病/脑干损伤/颅神经病等灾难性低频风险须逐项书面告知并记录在案，保守 α/β 假设，写明根治或姑息意图 | 任何再程放疗签知情同意时 |
| 17 | **颈软组织萎缩 = 红灯**：MRI 示颈软组织极度萎缩提示颈动脉/颅神经累积损伤达阈值——显式风险-收益框架 mandatory，慎选再照 | 再照前影像评估 |
| 18 | **累积剂量空间化**：有既往 DICOM → 形变配准剂量叠加（陡峭梯度区慎判）；无配准条件 → 重叠区近最大等效剂量求和作保守最坏近似；颅神经/颈动脉耐受限按 near-maximum 而非体积约束 | 累积剂量计算时 |
| 19 | **颈动脉 CBS 阈值**：累积 EQD2(α/β=2) >120-125 Gy 显著增加 CBS；包绕>180°+既往溃疡者风险更高 | 再照累及颈动脉 |
| 20 | **下颌骨 ORN 阈值**：累积 EQD2 >114-119 Gy ORN 风险显著上升；高危亚体积/牙况参与决策 | 下颌骨再照 |
| 21 | **脊髓/脑干累积目标**：脊髓 D0.1cc ≤50 Gy、脑干 ≤55 Gy；必要时表面 ~60 Gy 个案谨慎；恢复因子 10-25% 无前瞻验证须记录 | 再照累积 OAR 评估 |
| 22 | **第三程 OAR 累积 EQD2 起点值**（Gan）：脑干 81 / 脊髓 67.5 / 同侧视神经 81 / 颞叶 105 / 颈动脉 125 Gy；颈动脉两程后常已超——保靶区优先，尽量缩小 >125 Gy 体积 | 第三程及以上方案设计 |
| 23 | **ACC 再照不做同步细胞毒化疗**（无获益+毒性增加）；ACC 第三程常规分割 66–70 Gy，OAR 重叠区降至 60 Gy；大体积多 OAR 病例不做 SBRT | ACC 第三程 |

## 二、内置推理链

### Step 1：算前一程残余

```
前一程 EQD2 = 处方 × (1 + 2/αβ) / (1 + 2/αβ) = 处方
间隔年数 → 修复比例
  <6 月 → 不修正
  6-12 月 → 修复 30%
  1-2 年 → 修复 50%
  >2 年 → 修复 70%

累积晚期 EQD2 = 前一程残余 + 本程 EQD2
累积肿瘤 BED₁₀ = 前一程 BED₁₀（不复修）+ 本程 BED₁₀
```

### Step 2：筛选可行方案

| 方案 | 处方 | 免疫增敏 | 适用条件 |
|------|------|---------|---------|
| **Quad-Shot + IO** | 3.7 Gy × 4 BID，Q4w × 3 程 | PD-1（Pembrolizumab） | 前一程 ≤54 Gy 或间隔 >3 年 |
| **Q3w 单次 + IO** | 3.5 Gy × 1，Q3w × 6 程 | PD-1 或 ADC | 前一程 ≤66 Gy |
| **常规分割** | 2 Gy × 15-20 次 | 不可用增敏 | 所有，最安全 |
| **SBRT 连续** | 5-6 Gy × 5 | PD-1 | 前一程 ≤50 Gy |

### Step 3：裁决

```
累积晚期 EQD2 ≤40 Gy → 方案无限制
累积晚期 EQD2 40-50 Gy → Quad-Shot 可用，SBRT 连续受限
累积晚期 EQD2 50-60 Gy → 仅 Q3w 单次或常规分割
累积晚期 EQD2 >60 Gy → 仅常规分割（且 ≤15 次）
```

## 三、内置证据库

### Quad-Shot 方案（JAMA Otolaryngol 2026）

| 参数 | 值 |
|------|-----|
| 处方 | 3.7 Gy × 4 次（BID，间隔 ≥6h），每 4 周一程，最多 3 程 |
| 联合药物 | Pembrolizumab 200 mg Q3w |
| 总物理剂量 | 14.8 Gy/程 × 3 = 44.4 Gy |
| 适应人群 | 复发/不可切除/转移性 HNC |
| 免疫机制 | 连续 4 次 BID→累积 ICD 跨越免疫激活阈值；Q4w 间隙→T 细胞扩增 |
| 正常组织 | 每程 BED₃=33.1 Gy₃→修复后~20 Gy₃→3 程累积~60 Gy₃→EQD2~36 Gy |

### Q3w 单次 + IO 方案（九院经验）

| 参数 | 值 |
|------|-----|
| 处方 | 3.5 Gy × 1，每 3 周，共 6 程 |
| 联合药物 | PD-1 或 ADC（照射后 24h 内） |
| 总物理剂量 | 21 Gy |
| 机制 | 每次低剂量 RT→周期性抗原释放；3 周间隙→正常组织修复 |
| 局限性 | 单次 3.5 Gy 可能低于 ICD 最佳阈值（6-12 Gy） |
| 正常组织 | 累积晚期 EQD2~18 Gy（3 周修复修正后） |

### 免疫阈值概念

```
单次剂量 < 4 Gy   → ICD 信号可能不足以激活免疫
单次剂量 4-6 Gy   → 弱至中等 ICD
单次剂量 6-12 Gy  → 最佳 ICD 窗口
单次剂量 >12 Gy   → 可能杀伤浸润 T 细胞
```

## 五、SBRT 后常规分割补量（SBRT Boost Consolidation）

> **适用场景**：SBRT 首程照射后（如 5 Gy×5fx 或 6-8 Gy×3fx），因各种原因（毒副作用/经济/依从性）中断全身治疗，需用常规分割 RT 补足根治剂量。最常见于 ACC、肉瘤等相对放射抗拒的肿瘤。

### 5.1 BED 计算

```
累积 EQD2₁₀ = EQD2₁₀(SBRT) + EQD2₁₀(常规补量)
EQD2₁₀(SBRT) = 总剂量 × (1 + d/10) / 1.2
EQD2₁₀(常规补量) = 2 Gy × fx 数（如用 2 Gy/fx）
```

### 5.2 常见 SBRT 方案 → 常规补量速查表

| 首程 SBRT | EQD2₁₀ 已有 | 补量至 60 Gy（ACC/鳞癌） | 补量至 50 Gy（淋巴瘤/良性疾病） |
|-----------|:--:|------|------|
| 5.0 Gy × 5 = 25.0 Gy | 31.3 Gy | 34-38 Gy / 17-19 fx | 18-22 Gy / 9-11 fx |
| 6 Gy × 5 = 30 Gy | 40.0 Gy | 20 Gy / 10 fx | 10 Gy / 5 fx |
| 8 Gy × 3 = 24 Gy | 36.0 Gy | 24 Gy / 12 fx | 14 Gy / 7 fx |

### 5.3 间隔时间修正

| 间隔 | 正常组织修复 | 补量调整 |
|------|:--:|------|
| <4 周 | 几乎无修复 | 按累积 BED 严格限量 |
| 4-12 周 | 部分修复（黏膜 60-80%，神经 <30%）| 黏膜限量可放宽 10%，神经/脑干不放松 |
| >12 周 | 显著修复 | 可接近常规限量，但仍需重算累积 BED |

### 5.4 ADC/靶向增敏的残留效应

抗 EGFR ADC 的 SER 约 1.1-1.3——停药后衰减半衰期约 3-4 周。停药 4 个月后增敏效应可忽略不计，但仍需考虑 ADC 引起的正常组织敏感性（如已出现 3 级神经毒性→补量 RT 时需额外警惕神经相关 OAR）。

### 5.5 病例示例——鼻咽 ACC 的 SBRT+补量

```
首程：5 Gy × 5 fx + 抗 EGFR ADC × 4 周期（根治性，无手术）
间隔：4 个月
补量方案：36 Gy / 18 fx（常规分割）
累积 EQD2₁₀：31.3 + 36 = 67.3 Gy → 达到 ACC 根治门槛
靶区：GTV（残留）+ 鼻咽顶略过中线 + 同侧壁
不照：颈部（无 LN+）、颅底孔道（无 PNI）——鼻咽 ACC 不同于 SCC
```

### 5.6 骨寡转移 SBRT 剂量（2026-08 飞书经验，窦圣金）

> 转移性 ACC 单发骨寡转移——SBRT 根治性局部处理。BED₁₀ 目标 ≥48-60 Gy。

| 病灶部位 | 推荐方案 | 说明 |
|---------|---------|------|
| 四肢/肋骨/骨盆等外周骨 | **30 Gy/3fx**（10 Gy×3） | BED₁₀=60 Gy |
| 脊柱（椎体/椎旁） | **30 Gy/5fx**（6 Gy×5） | 降低脊髓 Dmax，BED₁₀=48 Gy |
| 脊柱紧贴脊髓（<3mm） | 27 Gy/3fx 或 24 Gy/2fx | 脊髓 Dmax 目标 ≤14-15 Gy/次 |
| 颅骨/眼眶等头颈骨 | **30-35 Gy/5fx** | 视神经、晶状体保护优先 |

- 脊髓限量（3fx）：Dmax≤22.5 Gy、<0.35cc≤15.9 Gy；（5fx）：Dmax≤28 Gy、<0.35cc≤22 Gy
- GTV=MRI T1/T2 融合骨病灶+骨外软组织；CTV=GTV+3-5mm（不越骨皮质）；PTV=+3mm
- ⚠️ BED₃>130 Gy 时 ORN/椎体压缩风险——倾向 30-35 Gy/5fx 而非更高单次量

## 六、患者选择与灾难风险走廊（Green Journal GTV Expert Opinion 2026 + Lancet Oncol 共识）

### 6.1 第三程及以上的决策顺序（Thariat, PMID 42603723）

```
第三程再照前，依序确认已排除：
① 全身治疗替代：lenvatinib 再挑战（ACC 既往有效者，Caspani 2025, PMID 40033633）
   / Ⅰ期临床入组
② 观察等待：惰性病程 + 无症状 + 灾难性风险前两年内高发 → 3/6 个月 MRI/PET
   动力学评估生长速度后再决策
③ 才进入第三程方案设计
```

### 6.2 灾难性并发症走廊（catastrophic risk corridor）

| 要素 | 内容 |
|------|------|
| 高危影像征象 | 颈软组织极度萎缩（提示颈动脉/颅神经累积损伤）、肿瘤包绕颈动脉、溃疡/瘘 |
| 灾难性风险 | CBS（颈动脉爆裂）、脊髓病、脑干损伤、颅神经病——低频但 5 级 |
| 强制动作 | ① 首程剂量热点映射到当前 planning CT（兴趣点级）② 知情同意逐项书面记录（保守 α/β）③ 写明根治 vs 姑息 |
| 颅神经保护实操 | 热点规避 + 陡峭剂量梯度 + 最小化再照神经长度 |

### 6.3 空间累积剂量（Cacicedo, PMID 42603722；ESTRO 共识 Appelt, PMID 41318002）

```
有既往 DICOM → 形变配准剂量叠加（刚性配准多数够用；解剖变化大用形变；
               陡峭剂量梯度区配准不确定性最大，需 MRI 融合标志点校正）
无配准条件   → 重叠区近最大等效剂量求和 = 保守最坏近似
α/β 不确定性 → 双 α/β（3/10）并行计算评估区间
OAR 限量口径 → 颅神经/颈动脉按 near-maximum（Dmax）而非体积约束
历史 CT 重勾 OAR → 保证累积 DVH 提取一致；报告剂量网格/束流模型/算法假设
```

### 6.4 技术选择与体积原则（Cacicedo 2026）

- SBRT 适合小靶（<25 cm³）；大靶用 IMRT/VMAT
- PTV margin 3-5 mm；**不做选择性淋巴结照射**（再照场景以限毒为先）
- VMAT/SBRT 降低 OAR 剂量但不消除风险
- 自适应触发预登记：肿瘤退缩/体重下降/水肿 → 即使小几何偏差也放大毒性
- 脑膜/硬膜病灶：局灶软脑膜表型 vs 弥漫颅脊髓逻辑——局灶者 SIB 推量 + 神经径路高适形 IMRT/VMAT；质子（可能碳离子）为选项；ACC 低 α/β 支持常规-轻度大分割，超分割已式微

### 6.5 ReCOG 国际共识硬数字（Biau, Lancet Oncol 2026, PMID 42372755——31 条声明，一致性 70-100%）

**患者选择（Panel 1）**
- <6 月复发：不建议再照（100% 一致，EV2）——例外仅急症姑息（难控出血）
- 6-12 月复发：仅高度选择病例（小、局限、首程高剂量区外）
- RPA Ⅰ（>2 年+手术）+ 高危特征（R1/ENE）→ 术后再照；RPA Ⅲ（<2 年+造瘘/气切依赖）→ 不建议根治性再照（76%，EV3）
- **首程计划复核是第一步**（100%）：区分 in-field / marginal 复发

**技术（Panel 2）**
- 术后再照 → 常规分割 IMRT 优先（94%，SBRT 数据少）
- 未切除小靶 ≤25 cc（~3cm / cT1-2）→ IMRT 与 SBRT 同效；>25 cc → IMRT 优于 SBRT
- 喉/下咽未切除复发 → SBRT 慎用（毒性）
- 同步化疗：个体化讨论（大肿瘤+体质好）；质子：选择病例降 OAR 剂量；近距离：口/口咽小靶 <25 cc 有效选项

**勾画与剂量（Panel 3）**
- 根治性再照：**CTV = GTV + 5 mm**（94%）；IMRT 常用总量 **66 Gy**（82%）
- 术后再照：高危 CTV 规则同首程（82%）；常用总量 **60 Gy**（94%）
- **不做选择性淋巴结照射**（100%，EV3）
- 超分割可选但未证实获益（76%）

**剂量累积（Panel 4）**
- 首程计划数据（CT/勾画/剂量）能取尽取（100%）；形变配准+严格 QA（88%）
- OAR 累积剂量用 EQD2 表达，晚反应组织 α/β=2-3 Gy（100%）
- 尽量体素级 3D EQD2 求和（88%）；配准不可靠时→关键 OAR（脊髓/脑干/颈动脉）手工点剂量相加（保守）（100%）

**OAR 硬数字（Panel 5）——skill 现有数据的重要补充**
- **颈动脉：累积 EQD2(α/β=2) >120-125 Gy 显著增加 CBS 风险**（94%，EV3）；**包绕>180° + 既往溃疡 → CBS 风险升高**（100%）
- **下颌骨：累积 EQD2 >114-119 Gy，ORN 风险显著上升**（94%）；风险还取决于高剂量亚体积/单次剂量/牙况
- 脊髓/脑干：组织恢复因子（10-25%）在无前瞻验证时慎用并记录（88%）
- **目标值：脊髓累积 EQD2 D0.1cc ≤50 Gy；脑干 ≤55 Gy**（70%）；必要时表面处可谨慎接受 ~60 Gy（个案，依间隔与既往剂量）（94%）

### 6.6 Gan 篇增量（PMID 42603724，2026-09-20 全文精读）

**第三程 OAR 累积 EQD2 起点阈值**（含既往+本次，Gan 专家意见）：

| OAR | 累积 EQD2 起点值 |
|-----|:--:|
| 脑干 | 81 Gy |
| 脊髓 | 67.5 Gy |
| 同侧视神经 | 81 Gy |
| 颞叶 | 105 Gy |
| **颈动脉** | **125 Gy**（两程后大概率已超——优先保靶区覆盖，尽量减少累积 >125 Gy 的颈动脉体积）|

**Gan 其他要点**：
- ACC 第三程：**不做同步细胞毒化疗**（无获益证据+毒性增加）；常规分割光子/质子 66–70 Gy/2 Gy，OAR 重叠区可降至 60 Gy
- 质子降低积分剂量、对侧组织保护更好；但**质子后 ORN 报告率可能更高**（颅底+颅骨大范围受照时）——建议双计划对比选模态
- 超分割（1.2 Gy/fx）在复发鼻咽癌有症状负担与生存获益证据（You, Lancet Oncol 2023），但 BID 依赖机构资源
- **不建议 SBRT/大分割**：大体积+多个关键 OAR
- 脑干/脊髓限量神圣不可侵犯（sacrosanct）；其他 OAR 可按疗程间隔考虑组织恢复（但三位专家对恢复程度无共识）
- CTV/PTV 边距尽量压缩以保护 OAR

**IMRT vs SBRT vs 质子（再照 2 年结局，Gan Table 1）**：

| 指标 | IMRT | SBRT | 质子 |
|------|:--:|:--:|:--:|
| 局控率 | 59–67% | 40–64% | 62–80% |
| 总生存 | 40–58% | 14–58% | 33–60% |
| ≥3 级毒性 | 15–56% | 2–24% | 6–25% |
| 5 级毒性（治疗相关）| 1–11% | 3–21% | 3–15% |

### 6.7 Sharma 篇增量（PMID 42603725，2026-09-20 全文精读）

- **前置条件**：所有既往治疗的 DICOM 剂量+结构集+治疗记录（确认实际交付分次数）
- **DIR 不确定性 = 体素级配准误差 + 剂量梯度**双因素整合；"不确定性感知"在决策依赖保护部分神经血管结构+推量局灶脑膜病灶时尤其关键
- **无 DIR 的替代阶梯**：①整体刚性不够 → **OAR 特异性配准**（某区域的"手动 DIR"）②配准不确定性过高 → 近最大点剂量求和
- **点剂量求和的代价**：部分重叠时会过度保守——整器官被既往局部照射"锁死"，甚至完全排除再照可能。空间感知剂量累积（手工子分区或商用软件）在这类病例是技术前提
- 病例决策依据：局灶脑膜延伸处**既往累积剂量低于治疗量** → 选择高适形 SIB 而非放弃局部治疗或统一降剂量
- **理想流程**：各程完整 3D 剂量网格先整体转 EQD2 再求和——多数 TPS 不原生支持，需 in-house 脚本
- **新文献**：Paradis KC, et al. ReCOG 剂量评估与报告标准共识（Lancet Oncol 2026;27(2):e101-10, PMID **41643699**，AAPM/ACRO/ASTRO/CARO/COMP/CADRA/CPQR/ESTRO/NRG 九组织背书）——与 Biau 临床共识（42372755）互为姊妹篇

### 6.8 Paradis ReCOG 剂量报告共识增量（PMID 41643699，2026-09-20 全文精读）

**剂量评估决策树（Figure 1，三问三分支）**：

```
① 是否担忧累积剂量副作用？
   否 → 评估重叠程度即可，无需深入分析
   是 ↓
② 完整 DICOM-RT 数据可得 + 配准可接受？
   否 → 用累积物理剂量判定重叠；OAR 用点剂量法估算累积等效剂量
   是 ↓
③ 可计算累积等效 3D 剂量分布？
   否 → OAR 点剂量法估算累积等效剂量
   是 → 计算基于配准的累积等效剂量指标
```

**无 DICOM 时的替代策略**：纸质记录（三平面剂量图/DVH/打印的 OAR 指标）；假设 OAR 接受处方剂量或最大计划剂量；在当前数据集上重建既往计划作估计。同一患者可组合使用（部分 OAR 配准可靠、部分用点剂量）。

**TRF（组织恢复因子）精确定义**：0–1 之间的标量，估计 OAR 既往等效剂量在疗程间隔内恢复的比例。影响恢复的因素：临床终点、器官再生能力、疗程间隔、受照体积、总剂量、分次大小、技术（射线质/剂量率/均匀性）、手术或全身治疗、患者因素。共识**不给出通用 TRF 数值**——由各机构内部文件自行约定并记录。

**知情同意特别强调**：「器官耐受」概念在再照中并不成熟（累积剂量估计不确定+生物效应未知）——各科室再照政策应包含知情同意流程、剂量学文档、加强同行评议。

**Figure 2 文档记录标准（有副作用顾虑时，7 项推荐标准）**：
1. 既往+当前治疗部位（含侧别）、处方剂量、技术/模态、日期
2. 应用的放射生物学参数（α/β、RBE、TRF）
3. 影像配准方法
4. 累积剂量计算方法
5. 剂量累积过程的**不确定性评估**
6. OAR DVH 剂量指标（D0.1cc/D0.03cc/mean/V20Gy 等）
7. **再照风险知情同意 + 共同决策记录 + 已考虑的替代策略**

无副作用顾虑时：部位/日期/无顾虑原因（低累积或非重叠）+ 三平面彩色剂量图视觉记录。
研究队列追加：患者级/每计划/累积 3D 剂量与 DVH 数据含不确定性；既往与当前物理剂量、累积等效剂量、含 TRF 累积等效剂量分列报告。

**机构级要求**：每科应有**书面内部文件**定义再照工作流、人员职责、文档要求、机构剂量目标与计划优先级、生物参数取值（组织特异 α/β、TRF）。
