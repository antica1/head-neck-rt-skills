## 一、临床规则积累

### 分期规则

- cT ≠ pT ≠ ypT——三套标准不混用
- DOI 仅用于 pT 分期。口腔癌 cT 不用 DOI
- 先查前缀与参数匹配 → 矛盾时质疑

### 靶区规则

- **口底铁律**：所有口腔癌术后 PORT，同侧口底必须含入 CTV-60
- **气管切开≠口腔癌铁律**：全喉切除=造口必照（手术边界）。口腔癌气管切开=有条件——仅当肿瘤/阳性 LN 紧邻造口（≤2 cm）或间质种植/软组织侵犯累及时才照。仅麻醉通路→不照
- **间室放疗**：照全受累解剖间室，非 mm 扩边。门（眶尖预防）+隔壁（海绵窦根治）
- **淋巴逆流**：颈清后逆流至 VIII/IX/X 过站——手术改变引流地形图
- **四级加量指征**：R1/R2 / PNI+ / 手术不易切净区 / 颈清后逆流
- **鼻腔鼻窦——七窍相通**：CTV 沿黏膜连续通路扩展，不能止于窦口
- **上颌窦引流——打通底壁**：坏死物排出通道，降低 RT 期间感染
- **颌骨坏死预防——软组织覆盖**：骨面无软组织→50 Gy 都可能坏死。有软组织→可耐受 66-70 Gy
- **术前必须与手术医生沟通覆盖方案**——骨膜/黏膜瓣/筋膜瓣覆盖裸露骨面
- **三明治治疗（术前 RT→手术→术后 RT）已弃用**——被诱导化疗/化免取代

### 唾液腺专项

- **副腮腺→IX 区→ⅠB**：副腮腺位置偏前，高恶性度可向前累积 IX 区→通过 IX 区转移至 ⅠB
- **舌下腺=八字形中线结构**：双侧口底预防 + 双侧 ⅠA+ⅡA 颈淋巴结预防
- **小唾液腺中高级别→按该部位 SCC 标准做 ENI**：级别决定颈部策略
- **对侧颈部≥3 LN+ 触发**：深部逆流（ⅡA→ⅠA→对侧）或皮下网直跨中线
- **RP 照射四条件**：腮腺深叶+中高级别 / ECE+ / >4cm / 颈清后逆流
- **非标准 PORT**（九院）：①当良性开的 ②面神经粘连 ③≥2 次复发低级别。流程：MRI→口头问外科→任何不放心→PORT
- **耳后切口加 Bolus**
- **颈清扫后豁免 ENI**（SFRO 2025）：Ib-IV 清扫且 ≥15 LN pN0→可不照颈部
- **面神经径路延伸至内听道**（SFRO 2025）：腮腺癌证实 PNI 时讨论
- **同步化疗非标准**（SFRO 2025）：RTOG 1008/GORTEC SANTAL 结果未出。例外：高危神经内分泌癌

### ACC 专项

- **PNI 分级**：神经内侵犯（intraneural）> 神经周围侵犯（perineural）。神经内侵犯→升级 Tier 1
- **鼻腔鼻窦 ACC** ≠ 唾液腺 ACC——实体型占比更高、PNI 通路更复杂（V2+V3+翼管神经）
- **鼻腔鼻窦 ACC 手术**：内镜复发率可能低于开放（17.8% vs 38.5%，Meccariello 2016）
- **鼻腔鼻窦 ACC 九院数据（朱奕 2016，复旦大学附属眼耳鼻喉科医院）**：切缘阳性对 OS/DFS 无显著影响→更强调 PORT
- **ACC 根治剂量可至 74 Gy**（SFRO 2025，质子优先）
- **CAP 化疗方案**：顺铂+多柔比星+环磷酰胺——用于晚期/复发/转移 ACC
- **ACC 随访 15 年**（SFRO 2025）——肺转移可发生在 10 年后

### 瘢痕疙瘩术后放疗专项（2026-08 定稿常规）

- **标准方案（2026专家共识）**：电子线 20 Gy/4次（5 Gy×4）或 20 Gy/5次（4 Gy×5），每日1次；BED₁₀≥30 Gy 为目标（≥20 Gy 为基线）；总剂量≤20 Gy
- **少分割 18 Gy/2次（9 Gy×2，间隔1周）**：仅高危/难治性病例，必须电子线——九院619例研究（Clin Med 2026，PMID 41903653）此方案复发率2.8%（总6.5%），但属回顾性，不作标准方案
- **时间窗**：术后24 h内（最迟48 h）；2 h内最佳（Peng 2025 meta）；植皮/皮瓣术前1 d或术后7 d
- **射野**：切口+上下左右各1 cm；本院加速器仅6 MeV电子线一档，无浅层X线、无后装机、无熔铅炉→挡块用铅皮裁剪叠层（2 mm×3层≈6 mm），防护用铅橡胶不可当治疗挡块
- **绝对禁忌**：甲状腺/性腺/胸腺；妊娠；<16岁原则上避免；同一部位不重复放疗；不大面积多处同时照射
- **复发风险分层（本院操作工具，待前瞻验证）**：部位张力＞既往治疗史/复发次数＞大小/活动度＞病程＞家族史。高张力部位（前胸壁/肩/耻骨上/下腹）复发风险约为低张力（耳垂/耳廓）3倍——Lin 2026 meta（PMID 42207254）：解剖部位超越BED成为最强预测因子
- **放疗指征**：真性瘢痕疙瘩（超出原伤口边缘、持续生长）术后建议放疗；增生性瘢痕可不放；耳垂≤1–2 cm初发小瘢痕可讨论TAC±5-FU注射替代或观察（Khalid 2018 RCT，PMID 29534885：疗效相当但RT更持久）
- **周末跨期（周五接诊，周末不开机）**：中低危→周五照1次4–5 Gy保窗口，周一续照完成标准方案；高危→顺势9 Gy（18/2第1次），下周五第2次；不拖至周一
- **应急首照→次日正式TPS计划**：拖班当日单野电子线属应急处置；次日必须重新定位+患者本人CT的完整TPS计划（病案与法律举证要求，仅有应急记录的病案法律上不完整）；应急剂量计入总剂量
- **技术选择**：首选电子线单野；3D-CRT/IMRT仅限多灶/大面积剂量分配、再程避让、需量化OAR剂量——不因收费差异改变技术路线（Seth 2026 meta，PMID 41401628：X线18%/近距离14%/电子线16%复发率无差异）
- **定位与摆位**：医生放铅丝/造影标记线标记切口→CT薄层（1–3 mm）勾画（CTV=切口+0.5–1.0 cm，PTV=+0.3–0.5 cm）；Bolus/铅块摆放=技师；首次治疗医生到场确认射野与附件后签字
- **科研接口**：五项评分（部位/既往史/大小/家族史/病程）→四层（低/中/高/极高危）登记——为千例ML风险分层模型与剂量RCT积累数据

### 鼻腔鼻窦癌专项

- **上颌窦 SCC cN0**：N+ 率 20.7%（ICAR 2024 NCDB 6448 例）。即使 cN0 也要照同侧 ⅠB+Ⅱ+Ⅲ
- **鼻腔 SCC cN0**：N+ 率 9.3%。pT1-2 可不做。全程 1/3 出现颈部转移
- **眼眶侵犯边界**：纸样板单独受侵=角膜缘。多壁/眶内=全眶
- **SMARCA4 缺失型**：未分化癌，横纹肌样形态，PD-L1 常高→免疫治疗可能有效
- **SMARCB1(INI1) 缺失型**：EZH2 抑制剂（Tazemetostat）可能有效。RT 是唯一可靠局部治疗
- **SNUC 诱导化疗**：化疗反应决定治疗方向（Amit 2019 JCO）——CR/PR→CRT，SD/PD→手术
- **SNUC cN0 必须照颈**——隐匿转移率 30-40%（Faisal 2020 Meta）
- **黏膜黑色素瘤**：大分割——30 Gy/5 fx 或 36-39 Gy/8-10 fx
- **开放 vs 内镜手术**：上颌窦前外下壁（厚骨）→开放。内侧顶后壁（薄骨）→内镜。互补非竞争
- **Ohngren 线**：内眦→下颌角。线上=预后差（近颅底/眼眶），线下=预后好

### 颈部规则

- PORT 颈靶区链：ⅠB 高危 → ⅠA 必 60Gy → ⅡA/ⅡB/Ⅲ 60Gy → Ⅳ 内侧份 60Gy
- 对侧颈部：仅口底已手术 + 中线原发。口底未动 → 不照对侧
- 54 Gy = 27 fx（非 33 fx）。无 GTV 不全程 SIB
- **⚠️ 推荐对侧颈部照射必须列出理由**——Agent 不能只说"建议照对侧"，必须逐条列出：
  ① 原发灶跨中线情况（具体部位、距中线距离）
  ② 同侧 LN 负荷（枚数/大小/ENE+）→逆流风险评估
  ③ 瘤种特定补充规则（如 ACC 实体型、舌下腺=中线结构等）
  侧性肿瘤无跨中线、同侧负荷低 → 不应对侧。
- **侧性肿瘤对侧照射三层框架**（口腔口咽 Skill v1.2.0）：
  - 第一层：原发灶跨中线→对侧黏膜/神经径路
  - 第二层：同侧淋巴逆流（≥3 LN+ 或 ENE+）→对侧颈
  - 第三层：瘤种特定补充

### 喉/下咽专项

- **V区豁免循证**（Looman 2026, *Radiother Oncol*, 390 例多中心）：同侧 V 区转移 11%，对侧 3%。II/III 区阴性时 V 区降至 **1%**——V 区转移为序贯事件，非独立跳跃转移
- **T2 声门癌高危 ENI 指征**：广泛声门上侵犯 / 广泛声门下侵犯 / 前连合+深层扩展 / 外生型大体积 → 同侧 II-III（50 Gy）
- **T4 喉癌 PTV 外放**：喉随吞咽上下移动→PTV 上方外扩 **1 cm**，前界 5 mm，其他 3 mm。PTV 前界超出皮缘→颈前填 5 mm bolus
- **术后 GTV 铁律**：无论术后病理显示治疗后改变/完全缓解，GTV 必须参考**化免前/术前**影像。化疗前侵犯区域必须纳入 CTV1
- **RP 转移与下咽亚部位**：后壁/外侧壁/梨状窝外侧壁→高 RP 风险（必照，上界 C1）；环后区→低 RP 风险（MRI 阴性可豁免同侧）
- **下咽癌食管第二原发 30%**——内镜务必包含胃镜+碘染色

- **降级三梯度**：pCR→降范围优先。MPR→60 Gy 维持。non-MPR→60-66 Gy 不降
- **手术降级调节因子**：小中心手术/非标准手术→即使 pCR 也不降级
- **手术不易切净区**：上门牙-鼻腔底硬腭 / 颏结节 / 颅底/翼腭窝/翼板根部 / 腮腺深叶-茎乳孔 / 眼眶/脑膜。病理切缘阴性≠手术切净→靶区需补偿

### 三台电脑协作经验

- **GitHub 是唯一真相源**——任何一台电脑修改后 push，其他电脑 pull 即可同步
- **旧Skill清理**：重命名后旧名称文件夹需手动删除，否则 Hermes 加载两个版本
- **NPC Skill 特殊**：v2.0 扁平化版本（79L）是提纲，完整版（496L）在本地 Hermes→推回 GitHub 恢复
- **sync-skills.sh** 在 `head-neck-rt-skills/` 目录——修改 skills/ 下文件后运行即可批量推送 17 个独立仓库
- **Windows 注意**：git-bash 的 `/tmp` 是会话隔离的——后台进程和前台进程的 `/tmp` 是不同目录
- **插件安装**：用 `hermes plugins install` 而非手动复制，否则 Python 包依赖可能断链

### 职称晋升答辩经验（2026-08 蒋雯副高筹备）

- **临床 vs 基础研究定位**：同批申报者可能有人全是基础文章——不点名不贬低，只需把"临床研究价值标准"立起来。核心话术："这正是一个临床医生的研究该有的样子"。四维度：直接改变实践 / 患者受益 / 可验证 / 临床思维闭环。呈现为"临床问题 → 前瞻性研究 → 临床实践改变"闭环（见 promotion-defense-review Skill §8）
