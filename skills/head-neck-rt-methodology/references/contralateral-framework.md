# 侧性肿瘤对侧照射——三层决策框架

> 任何单侧头颈肿瘤需要判断是否照对侧时，按以下三层依次检查。

## 第一层：原发灶跨中线/近中线（黏膜连续扩散）

| 跨中线结构 | 典型肿瘤 | 对侧触发条件 |
|-----------|---------|------------|
| 鼻咽顶 | NPC | 默认双侧 |
| 硬腭/软腭 | 硬腭癌/ACC | 近中线或跨中线 → 对侧腭大孔→翼腭窝 |
| 舌根/口底 | 舌癌/口底癌/舌下腺 | 距中线 ≤1 cm → 双侧口底+对侧颈 |
| 杓会厌皱襞 | 声门上喉癌 | 跨中线 → 对侧Ⅱ-Ⅲ |

## 第二层：淋巴链逆流（已证实同侧转移能力）

| 触发条件 | 机制 | 对侧范围 |
|---------|------|---------|
| 多区 LN+（≥2站）| 引流途径紊乱 → ⅡA→ⅠB→ⅠA→对侧ⅠB | 对侧ⅠB+Ⅱ |
| ENE+ | 淋巴管破裂→皮下淋巴管网→对侧 | 对侧同站+下游 |
| N2c 或 N3 | 分期提示对侧风险 | 对侧全颈 |

## 第三层：手术引流改变

| 手术操作 | 后果 | 对侧补偿 |
|---------|------|---------|
| 单侧颈清扫 | 清扫侧通道切断→对侧唯一通畅 | 对侧ⅠB+Ⅱ |
| 口底未处理 | 口底淋巴环完整→对侧通路 | 对侧口底+ⅠB |

## 瘤种特定扩展

| 瘤种 | 对侧特化规则 |
|------|------------|
| 颊癌 | 近口角/跨中线皮肤 → 对侧颊黏膜+ⅠB |
| 下牙龈（前部）| 跨下颌联合中线 → 对侧ⅠB |
| 下咽后壁癌 | 中线 → 对侧 RP+Ⅱ-Ⅲ |
| 环后癌 | 中线 → 双侧 RP+双侧Ⅵ |
| ACC 腭部 | 近中线+PNI+ → 对侧腭大孔→翼腭窝→圆孔开口 |
| ACC 舌下腺 | 口底+实体型+LN+ → 双侧 Ib+II+III |
