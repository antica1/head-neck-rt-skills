# 放疗研究方案统计自洽核查（II 期探索性设计）

> 本文件聚焦**研究者自起草**的 II 期放疗研究方案在统计判定规则上的内部自洽核查。靶区/剂量/终点内容已在瘤种特异性 Skill 与 reference-verification 里覆盖；这里只看"小样本下规则与数字是不是真对得上"。

## 适用场景

- 用户上传方案草稿（如 v2.4、v0.7），要求审稿/定稿
- 修订前后向全组汇报（PPT/口头）
- 期刊投稿前查"方案统计段落是不是会被审稿人当场挑刺"

## 三类常见系统性错位（2026-09 RESPOND-HN v2.4 实测）

### 1. Clopper-Pearson 上限"往前错一档"

精确二项单侧 95% 上限公式：`scipy.stats.beta.ppf(0.95, x+1, n-x)`。

| 分母 / 分子 | n=26 | n=23 |
|---|---|---|
| 0 例 | 0.109 | 0.122 |
| 1 例 | 0.170 | 0.190 |
| **2 例** | **0.223** | **0.249** |
| **3 例** | **0.272** | **0.304** |
| 4 例 | 0.318 | 0.355 |
| 5 例 | 0.363 | 0.404 |

**典型错位**：方案写"3/26 上限 0.223"——0.223 实为 2/26 的上限。3/26 实际是 0.272，超阈值（20%）幅度更大，意味着按真实规则 n=26 臂 ≥3 例即停的判定严于旧规则写的 ≥3 例即停——**安全底线比方案声称的更严**，方案作者本意是放松（≥3 例才停），但实际数字算下来 2 例就该停。

### 2. 误停概率与修订前规则绑定

`P(误停) = Σ_{k=K}^{n} C(n,k) p^k (1-p)^{n-k}`，其中 p=真实失败率，K=触发阈值。

真实失败率 10% 时的常见误停率：
- n=26、≥2 例即停：**75%**（修订后）
- n=26、≥3 例即停：49%（修订前）
- n=23、≥3 例即停：**41%**（修订后）
- n=23、≥4 例即停：19%（修订前）

方案里写的 "19%–49%" 区间若出自修订前规则，修订后必须改为 "41%–75%"。**修订操作特性数字时不能用区间概括**，要把每条规则对应的误停率列出——同一规则集合里不同 n 误停率差 30 个百分点。

### 3. 把握度与判定性质混淆

小样本 II 期（基础档把握度 70%–73%）的 p 值与 CI 按**估计性质**解读：

- 不能作为确证性结论（"豁免是安全的"这类判断不在本研究能下的范围内）
- 真实失败率与阈值相等时，触发"不通过"的概率就是误停率本身；DSMB 据此结合点估计、CI、失败模式综合裁量
- 样本量与扩展档（35/组、32/组）的把握度差异要写明（35/组 82%、23/组 69%），便于是否启动 III 期的决策

□ 12.x 安全底线判定表：每个精确二项上限用 scipy 重算，与阈值比较

□ 操作特性段落：每条规则的误停率随规则同步更新
  - 真实失败率取方案假设值（通常 8%–10%），
  - 列出"误停率（修订后）：n=26 臂 X%、n=23 臂 Y%"

□ 把握度：每个主要终点按当前样本量 + 当前效应量假设重算
  - 二分类：scipy.stats.norm.cdf(h*sqrt(n/2) - 1.282)
    h = 2*(asin(sqrt(p1))-asin(sqrt(p0)))  # Cohen h
  - 单侧 α=0.10：1.282 是 z 值（不是 1.96）

□ 文献编号：ASCO 摘要是否带 P 后缀（Poster Session 才带，Oral/Rapid Oral 不带）

□ 分母：小样本数字必须写分子/分母

## 汇报课件的结构（10 页样板）

RESPOND-HN v2.4 内部一致性核验汇报课件（10 页）作为本类审稿的输出样板：

1. 封面（放疗中心汇报｜头颈放疗组）
2. 汇报内容（三处发现 + 修订方案）
3. 问题一：12.2 表精确二项上限整体错位
4. 修订对照表（v2.4 旧 vs v2.4 新，每行双行）
5. 内部自洽验证（按修订后规则反推每档与阈值严格对应）
6. 操作特性数字过时
7. 参考文献 [7][9][10] 的作者、年份、PMID 核实
8. 所有关键数字的摘要（BED、3/15 暂停、把握度）
9. 会上请定（误停率是否可接受、SAP 冻结责任人）
10. 请各位提意见（讨论页）

每页对应 ≈30 秒讲解，10 页 ≈ 5 分钟主体，留时间讨论。**汇报与方案文本同步修订**——只报告不改稿，组内会上无法形成决议。

## 与 reference-verification 的边界

- **reference-verification**：核实引文本身的作者/期刊/PMID/数字是否对
- **本文件（protocol-statistical-consistency）**：核实协议内部的统计规则（精确二项上限、误停率、把握度）是否前后自洽、是否对应正确的阈值
- 两类核查经常同时做：发现一条引文错就可能牵出方案里其他统计表述问题（例：[7] 改 Front Immunol 2025→2026 时，可能引出该研究的样本量/对照组重新计算）
