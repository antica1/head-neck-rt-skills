## 一、颅底孔道——精准边界

### 1.1 破裂孔（Foramen Lacerum）

| 边界 | 定义 |
|------|------|
| 位置 | 岩尖、蝶骨大翼、枕骨基底之间 |
| 内容 | 颈内动脉岩段→海绵窦段的转折点 |
| CT 辨识 | 蝶骨和岩骨之间的不规则裂隙 |
| 覆盖规则 | Lancet：**双侧**（即使偏心肿瘤）。IG-2024：偏心时可仅同侧 |

> **勾画要点**：破裂孔在轴位 CT 上位于岩尖内侧、蝶骨体旁。勾画时需包含孔周围 3-5 mm 的骨质边缘——颈内动脉在此处没有骨性管道保护，肿瘤可沿动脉外膜扩散。

### 1.2 卵圆孔（Foramen Ovale）

| 边界 | 定义 |
|------|------|
| 位置 | 蝶骨大翼，破裂孔前外侧 |
| 内容 | 三叉神经下颌支（V3）、副脑膜动脉 |
| CT 辨识 | 蝶骨大翼上的卵圆形骨缺损 |
| 大小 | 约 7×4 mm |
| 覆盖规则 | IG-2024：53%双侧 / 47%偏心仅同侧。**九院：双侧** |

### 1.3 圆孔（Foramen Rotundum）

| 边界 | 定义 |
|------|------|
| 位置 | 蝶骨大翼前内侧，眶上裂下方，卵圆孔前内方 |
| 内容 | 三叉神经上颌支（V2） |
| CT 辨识 | 冠状位上最清晰——蝶骨体内的圆形孔道 |
| 覆盖规则 | IG-2024：53%双侧 / 47%偏心仅同侧。偏心肿瘤→Lancet 可豁免对侧 |

### 1.4 棘孔（Foramen Spinosum）

| 边界 | 定义 |
|------|------|
| 位置 | 卵圆孔后外侧 |
| 内容 | 脑膜中动脉 |
| 覆盖规则 | 常规不单独勾画——在覆盖卵圆孔和破裂孔时被一并包含 |

### 1.5 眶上裂（Superior Orbital Fissure）

| 边界 | 定义 |
|------|------|
| 位置 | 蝶骨小翼和大翼之间 |
| 内容 | CN III, IV, V1, VI，眼上静脉 |
| CT 辨识 | 轴位上蝶骨小翼和大翼之间的空隙 |
| 覆盖规则 | 有海绵窦侵犯时→必须包含。无海绵窦侵犯→视 T 分期 |

### 1.6 视神经管（Optic Canal）

| 边界 | 定义 |
|------|------|
| 位置 | 蝶骨小翼根部 |
| 内容 | 视神经（CN II）、眼动脉 |
| 覆盖规则 | 仅当肿瘤累及眶尖或视交叉时→包含。常规预防不包含 |

### 1.7 舌下神经管（Hypoglossal Canal）

| 边界 | 定义 |
|------|------|
| 位置 | 枕骨髁前上方 |
| 内容 | CN XII |
| 覆盖规则 | 仅当枕骨斜坡下部/枕骨大孔附近受累或 CN XII 受侵时含入 |

## 二、海绵窦——精准边界

### 2.1 解剖边界

| 面 | 边界 |
|----|------|
| **上壁** | 前床突→后床突的硬膜 |
| **外侧壁**（自上而下） | CN III → CN IV → CN V1 → CN V2 |
| **内侧壁** | 蝶窦外侧壁 / 垂体窝外侧壁 |
| **后界** | Meckel 腔（三叉神经节所在） |
| **前界** | 眶上裂 |

### 2.2 勾画要点

```
轴位：
  ┌─ 蝶窦层面 ──── 海绵窦位于蝶窦两侧，呈三角形
  ├─ 垂体层面 ──── 海绵窦包绕颈内动脉
  └─ Meckel腔层面 ── 三叉神经节的硬膜囊

冠状位：
  海绵窦外侧壁从上到下顺序：CN III → IV → V1 → V2
  颈内动脉在海绵窦中央
```

### 2.3 覆盖规则

| 情景 | 动作 |
|------|------|
| T4（海绵窦直接侵犯） | 同侧海绵窦全壁纳入 CTVp_High（70 Gy） |
| T3 颅底广泛侵犯 | 同侧海绵窦纳入 CTVp_Mid（60 Gy）预防 |
| T1-T2，无颅底 | 不覆盖 |

## 三、鼻咽腔及周围——毫米级边界

### 3.1 鼻咽黏膜

| 边界 | 定义 |
|------|------|
| 上界 | 蝶窦底 / 蝶骨体下缘 |
| 下界 | 软腭上缘（腭帆提肌水平） |
| 前界 | 后鼻孔（Choanae） |
| 后界 | 椎前筋膜 / 头长肌前缘 |
| 侧界 | 咽隐窝（Rosenmüller fossa）→ 咽鼓管圆枕→ 腭帆提肌 |

> **勾画要点**：全鼻咽黏膜必须包含在 CTVp_Mid（60 Gy）。从蝶窦底的下缘到软腭的上缘，包括双侧咽隐窝和咽鼓管开口。

### 3.2 咽旁间隙

| 边界 | 定义 |
|------|------|
| 内侧 | 咽缩肌 / 腭帆提肌 |
| 外侧 | 翼内肌 / 腮腺深叶 |
| 后界 | 茎突前间隙→颈动脉鞘（茎突后间隙） |
| 上界 | 颅底（卵圆孔下方） |
| 下界 | 舌骨水平 |

> **NPC 覆盖原则**：咽旁间隙侵犯→同侧含入 CTVp_Mid。无侵犯→偏心肿瘤对侧可豁免。

### 3.3 翼腭窝（Pterygopalatine Fossa）

| 边界 | 定义 |
|------|------|
| 前界 | 上颌窦后壁 |
| 后界 | 翼突根部 / 蝶骨大翼前面 |
| 内侧 | 腭骨垂直板 |
| 外侧 | 颞下窝（通过翼上颌裂相通） |
| 内容 | 上颌动脉终末支、V2、翼腭神经节 |

> **勾画要点**：翼腭窝是 V2 通颅的关键中转站。勾画时在轴位上位于上颌窦后壁和翼突之间。Lancet 强调应覆盖翼腭窝而非上颌窦后壁本身。

#### 翼腭窝受侵后六向扩散（"一人得道，鸡犬升天"）

一旦翼腭窝被肿瘤侵犯，它作为一个中枢枢纽，可向六个方向快速扩散：

| 方向 | 通道 | 目标结构 | T分期/临床影响 |
|:--|:--|:--|:--|
| **快速通道** | 腭鞘管 | 鼻咽↔PPF直达 | 腭鞘管受侵→翼腭窝高危 |
| **向前** | 眶下裂 | 眼眶 | T4（眶尖/眶上裂受累） |
| **向内** | 蝶腭孔 | 鼻腔后部 | 鼻腔后部+蝶腭孔纳入CTV |
| **向外** | 翼上颌裂 | 颞下窝→咀嚼肌 | T2（翼外肌内）→T4（超出外侧缘） |
| **向后下** | 翼管(Vidian管) | 破裂孔→颅内 | 最危险——破裂孔毗邻颈内动脉 |
| **向后上** | 圆孔(V2) | 颅中窝/海绵窦 | 圆孔必须包全 |

> **记忆口诀**：前眶内鼻外颞下，后下翼管后上圆——六个方向一通百通。

### 3.4 翼内肌 / 翼外肌

| 结构 | 作用 |
|------|------|
| 翼内肌 | 起自翼突内侧板→下颌角内面。NPC 常沿此扩散 |
| 翼外肌 | 起自蝶骨大翼和翼突外侧板→下颌颈。**第 9 版 T 分期关键** |

> T2/T4 分界：翼外肌以内→T2；翼外肌以外→T4。

### 3.5 椎前肌 / 斜坡

| 结构 | 覆盖规则 |
|------|---------|
| 头长肌 / 颈长肌 | NPC 常沿椎前筋膜扩散至此处→低危 CTV 含 |
| 斜坡（Clivus） | Lancet：无论 T 分期，不覆盖全斜坡，仅受累段。IG-2024：未受累→前 1/3；受累→全斜坡 |

### 3.6 后鼻腔

| 边界 | 定义 |
|------|------|
| 范围 | 后鼻孔向后 ≥5 mm 的鼻腔黏膜 |
| 覆盖规则 | 所有 NPC 患者的低危 CTV 必须覆盖 |

## 四、淋巴结站区——NPC 修正版

### 4.1 Robbins 标准 vs NPC 修正一览

| 站区 | Robbins 标准边界 | NPC 修正（Lancet/IG） | 修正原因 |
|------|-----------------|---------------------|---------|
| **II 区前界** | 茎突舌骨肌后缘 | Lancet：进一步缩小 | 减少腮腺剂量 |
| **III 区前界** | 胸骨舌骨肌外侧缘 | **胸锁乳突肌后缘** | 减少甲状腺/喉剂量 |
| **IV 区前界** | 胸骨舌骨肌外侧缘 | **舌骨下带状肌后缘** | 减少甲状腺剂量 |
| **Ib 区** | 包含全部颌下腺 | Lancet：缩小，豁免未受累颌下腺 | 保护颌下腺 |
| **Va 区上界** | 舌骨上缘 | **延伸至颅底（颈静脉孔）** | NPC 需覆盖 |
| **Vb 区** | 标准 | Lancet：扩大 | NPC 需覆盖 |
| **RP 内侧组** | 以前全包 | **仅受累时覆盖** | Mao et al. III 期 RCT 证据 |

### 4.2 RP 淋巴结

| 分组 | 覆盖规则 |
|------|---------|
| 外侧组（Rouvière 淋巴结） | **所有 NPC 双侧覆盖** |
| 内侧组 | **仅受累时覆盖**——不常规预防 |

### 4.3 颈部预防规则（Lancet）

| 条件 | 覆盖 |
|------|------|
| 任何 LN+ | 同侧 IV/Vb |
| No LN+ | IV/Vb 不覆盖 |
| Ib LN+ / 颌下腺受累 / 口腔/前鼻腔原发 | 同侧 Ib |
| 所有 NPC | 双侧 II/III/Va + 双侧 RP 外侧 |

## 七、勾画顺序——贴在 TPS 旁

```
1. GTVp：T1+C 增强区（软组织化疗后，骨质/鼻窦/海绵窦化疗前）
2. CTVp_High = GTVp + 0 mm → 70 Gy
3. CTVp_Mid  = CTVp_High + 5 mm → 60 Gy（含全鼻咽黏膜+化疗前GTVp）
4. CTVp_Low  = CTVp_Mid + 5 mm → 54 Gy（核对后鼻腔/翼腭窝/椎前）
5. 偏心？砍对侧（破裂孔除外；岩尖/卵圆孔→九院双侧）
6. GTVn：化疗后残留 LN
7. CTVn_High = GTVn + 0 mm → 70 Gy
8. CTVn_Mid：仅 ENE 时 → +3-5 mm → 60 Gy（含化疗前 GTVn 范围）
9. CTVn_Low：+3 mm → 50 Gy（双侧 RP 外侧+II/III/Va±IV/Vb/Ib）
10. PTV = CTV + 3 mm
```

## 八、2025版国际指南关键更新（基于 Lancet 2025 / IG-2024 / 3100例 NPC 数据）

> **来源**：2025 Lancet Oncology 鼻咽癌原发灶+颈部靶区共识、马骏院士团队 RCT、中山大学肿瘤中心 3100 例 NPC 淋巴结转移数据。本 Skill 基于以上数据，结合九院临床实践，整理了以下 5 项关键更新。

### 8.1 IIa/IIb 废除——统一为完整 II 区

| 维度 | 旧版（2013） | **2025 新版** |
|:--|:------|:------|
| 分区方式 | 以颈内静脉后缘为界分 IIa/IIb | **不再区分 IIa/IIb**，统一为完整 II 区 |
| 原因 | 亚区分割带来操作复杂度 | 简化勾画流程、规避亚区分割带来的漏照风险 |
| 临床影响 | 需分别勾画双亚区 | **整个 II 区统一规划靶区，一次性勾画** |

> 勾画时的"向外拐"原理不变——II 区在上颈层面需要向外扩至颈阔肌，因为腮腺下极消失层面，颌下腺后缘与胸锁乳突肌之间是 NPC 高转移区域（3100 例数据：IIb 转移灶 25.9% 超出 C1 横突）。

### 8.2 Ib 区预防照射新指征（2025 Lancet Oncology 更新）

| 条件 | Ib 区 | 证据 |
|:----|:---:|:----|
| 常规 NPC（无口腔/口咽侵犯） | ❌ 不预防 | 3100 例中 Ib 转移率仅 4.3% |
| **真性口腔侵犯**（硬腭/牙龈/舌体/颊黏膜） | ✅ **必须照同侧 Ib** | **2025 Lancet Oncology 国际共识** |
| 鼻腔前 1/2 受累 | ✅ 照同侧 Ib | 淋巴逆流理论 |
| II 区广泛转移 + 原发灶侵犯口咽 | ⚠️ 考虑照 Ib | 颌下腺尽量保留以减轻口干 |
| Ia 区（颏下） | ❌ 常规不预防 | 3100 例 NPC 中 Ia 转移率 ≈ 0%，仅病理证实时才照 |

> **勾画细节**：
> - 淋巴顺流（前→后）：严格按解剖边界勾画 Ib 区前界
> - 淋巴逆流（后→前）：前界设于颌下腺前缘 1 cm，无需包绕颌下腺
> - 尽量保留颌下腺——减轻放疗后口干

### 8.3 CTVnd 上界——"壁咚"至颅底

| 维度 | 规则 |
|:--|:----|
| CTVnd 上界 | **统一锚定为颈内静脉出颅层面（颅底颈静脉孔）** |
| 底层逻辑 | NPC 通过颈静脉孔→颈内静脉链→咽后淋巴结→II/III/IV 逐级下行 |
| 如果仅凭可见淋巴结设上界 | 会直接遗漏颅底高位隐匿病灶 → 局部复发风险↑ |

> **颈内静脉链定位口诀**：颈内静脉 = 淋巴高速公路（贯穿 II/III/IV）；颈内动脉 = 生命主干线（偏内、偏深）。横断面呈"8"字形态（颈内静脉扁而粗 + 颈内动脉圆而硬）。

### 8.4 VI 区常规豁免（3100 例证据）

| 维度 | 规则 |
|:--|:----|
| NPC 初诊 VI 区转移率 | **0%**（3100 例，中山大学肿瘤中心） |
| 常规 NPC | **不预防性照射 VI 区**——无直接通向颈中央 VI 区的天然淋巴通道 |
| 例外（需照 VI） | ① IVb/Vc 锁骨上淋巴结广泛转移、融合<br>② 复发 NPC 伴下颈多发 LN + VI 区中线软组织侵犯<br>③ 鼻咽癌侵犯下咽（特殊 T4） |
| 保护效益 | 豁免 VI 区 → 减少甲状腺、气管、食管受量 |

### 8.5 口腔侵犯 = T1（非 T3）——咽旁间隙分水岭法则

| 侵犯结构 | T 分期 | 核心逻辑 |
|:--|:--:|:----|
| **口咽黏膜**（软腭/扁桃体/舌根） | T1 | 黏膜表层浸润，无咽旁间隙侵犯 |
| **口腔黏膜**（硬腭/牙龈/舌体/颊黏膜） | T1→照 Ib | 软组织屏障弱，但分期仍为 T1（需照 Ib） |
| 无论口咽/口腔 → 咽旁间隙受侵 | T2 | T1 与 T2 的分水岭永远是**外侧咽旁间隙**（非肿瘤体积/黏膜下坠距离） |
| 硬腭骨质破坏 | T3 | 骨皮质中断/信号异常 |

> **临床高频误区**：不能靠肿瘤体积或口咽累及范围判定 T2。T1/T2 的分界线永远在**茎突前咽旁脂肪间隙是否完整**。

### 8.6 ENE阳性（淋巴结包膜外侵犯）— 2025指南下的分期与CTVn规则

| 概念 | 规则 |
|:--|:----|
| **AJCC 9版分期** | cENE（影像学）或 pENE（病理学）= **N3**（一票升级） |
| **⚠️ 关键例外** | **咽后淋巴结（RP）ENE ≠ N3**——不被列为N3 |
| **影像预判三征** | ① 淋巴结形态不规则（失去正常肾形/椭圆形）<br>② 边缘模糊或有毛刺（脂肪间隙浸润）<br>③ 周边强化环（增强CT/MRI，周围肉芽组织/肿瘤浸润） |

#### CTVn外放规则

| ENE状态 | GTVn→CTVn规则 | 处方 | 共识率 |
|:--|:----|:--:|:--:|
| **无ENE** | GTVn = CTVn_High，**可省略 CTVn_Mid** | 70 Gy | 指南推荐 |
| **ENE (+)** | CTVn_Mid = GTVn + **3-5 mm** | 60 Gy | **80%** |
| 华西实践 | 外扩 4mm | 60 Gy | 进修笔记 |

> **勾画注意**：
> - CTVn_High（70 Gy）：诱导化疗后残留强化灶 = GTVn
> - CTVn_Mid（60 Gy, 仅ENE+时）：GTVn + 3-5 mm，**必须包全诱导化疗前的所有 ENE范围**（"软后硬前"原则）
> - II区 ENE(+) → 考虑同侧 Ib 区预防照射
> - 如影像学高度怀疑 ENE 但病理尚未确认→按 ENE(+) 勾画，MRI 比 CT 更可靠

## 九、3100 例 NPC 各分区淋巴结转移率速查（中山大学肿瘤中心数据）

| 分区 | 转移率 | 勾画要点 | 特殊规则 |
|:--:|:-----:|:--------|:--------|
| **Ia** | ≈0% | 不预防 | 仅病理证实后照 |
| **Ib** | 4.3% | 口腔/口咽侵犯时照 | 尽量保留颌下腺 |
| **II** | 最高发 | **上界至颈静脉孔颅底** | 2025 版统一为完整 II 区 |
| **III** | 中高 | IIIa 前界按 II 区状态调整 | II(+)→前界至胸锁乳突肌前缘 |
| **IV** | 13.1% | IVa/IVb 分界=胸锁关节上 2 cm | **IVb 总是伴随 IVa+多站转移**——无单独 IVb |
| **Va** | **21.5%** | N0 侧→仅 Va | N+侧→Va+Vb |
| **Vb** | 15.6% | N+侧→照 | 3% 在斜方肌-肩胛提肌间隙有转移 |
| **Vc** | 1.8% | 仅晚期广泛转移 | Vc(+)→需排查同侧腋下淋巴结 |
| **VI** | **0%** | **常规不预防** | 例外：IVb/Vc 广泛/复发/侵犯下咽 |
| **VIIa** | **75-82%** | NPC 首站，双侧必照 | Mao et al. BMJ 2023: 内侧组不必常规预防 |
| **VIIb** | 低 | 仅颅底/破裂孔/IIb 融合时 | 其余不需常规包含 |

> **各分区数据细节**：
> - II区：上颈最高发，IIb 转移灶 25.9% 超出 C1 横突，部分直达颅底→上界必须到颅底
> - III区：转移多在颈动脉鞘后/外侧，孤立颈动脉鞘前方转移极少见，前方转移均合并同侧 II 区转移
> - IV区：IVb 转移均合并 IVa 及多区域淋巴结肿大（总数 ≥6），无单独 IVb 转移
> - V区：Va 21.5%，Vb 15.6%，Vc 1.8%（3100 例初治 NPC 数据）

## 十、T3-4 破例逻辑速查表（2025 指南规范）

> **通用原则**：T1-2 按标准勾画；T3-4 部分场景存在破例逻辑——**不是照搬大范围，而是根据侵犯结构和方向精准加减靶区。**

| 侵犯结构 | T 分期 | CTV 破例规则 |
|:--|:--:|:--|
| **鼻腔黏膜**（后鼻孔之后） | T1 | CTVp-low 向前 ≥5 mm；前 1/2 受累 → +Ib 区 |
| **口咽黏膜**（软腭/扁桃体/舌根） | T1 | CTV 下界延伸至舌骨水平（约 C3） |
| **口腔黏膜**（硬腭/牙龈/舌体） | T1 + Ib | 必须照同侧 Ib（2025 Lancet）；硬腭破坏 → T3 |
| **翼内肌** | T2 | CTV 含受累肌腹 + 肌间隙 |
| **翼外肌肌腹内** | T2 | CTV 含全肌腹 + 外侧缘 |
| **翼外肌突破外侧缘** | T4 | CTV 含咬肌/颊脂垫/皮下 → 直接升级 T4 |
| **咽旁间隙（茎突前）** | T2 | 同侧全茎突前间隙含入 |
| **椎前肌** | T2 | 含受累肌群 + 椎前筋膜 |
| **鼻窦（任意组）** | **T3** | "硬骨头原则"：含全窦腔 + 窦口鼻道复合体（OMC）<br>蝶窦 > 筛窦 > 上颌窦 > 额窦（按侵犯频率） |
| **颅底骨质（斜坡/岩尖/蝶骨）** | T3 | CTV 含全受累骨 + 相邻孔裂（破裂孔/卵圆孔/圆孔） |
| **眼眶**（眶上裂/眶下裂/眶尖） | **T4** | 三条路径：海绵窦→眶上裂 / 翼腭窝→眶下裂 / 蝶筛骨→眶内侧壁<br>**眶上裂=通中颅窝海绵窦、眶下裂=通翼腭窝颞下窝、眶尖=T4总开关** |
| **海绵窦** | T4 | 同侧全海绵窦 + Meckel 腔 |
| **动眼神经（CN III）** | T4 | 沿海绵窦外侧壁→眶上裂→总腱环（三段式走行） |
| **V2（圆孔/眶下裂）** | T4 | 沿 V2 通路至翼腭窝→眶下裂 |
| **腮腺** | T4 | **以增强 MRI 为金标准**。GTVp 含全受累腺体（深叶/浅叶） |
| **下咽** | **特殊 T4** | **"向下高危、向上减负"**：CTV 向下全下咽覆盖，但**可豁免海绵窦/斜坡/蝶窦**——不照向上结构 |

> **T3-4 破例逻辑核心**：肿瘤侵犯方向决定 CTV 延伸方向。向下侵犯→向下延但不向上扩；向眼眶侵犯→沿侵袭路径延但保留对侧。**不是 T4 就要照全颅底。**
>
> **补充破例——解剖不连续法则**：T3-4 常规需画全斜坡（T1-2 仅前 1/3），但有例外。如侵犯部位为翼状结构 T3 或下咽 T4，颅底的解剖连续性已被打断 → **不需要勾画整个斜坡**，仅画受累段即可。CT 矢状位上如蝶骨、斜坡、枕骨之间解剖关系不连续 → 参照具体侵犯部位决定靶区范围。

## 十一、马骏院士团队三大精准减毒里程碑证据

| 研究 | 期刊/年 | 样本量 | 核心发现 | 临床意义 |
|:--|:------|:---:|:--------|:--------|
| **豁免下颈部预防照射** | *Lancet Oncol* 2022 (NCT02642107) | 446 例 | N0-N1 期豁免阴性侧下颈部(IV/Vb)，3 年区域无复发生存 97.7% vs 96.3%（非劣效） | 甲状腺功能减退↓9%，吞咽困难↓15%，颈部损伤↓17% |
| **豁免同期化疗** | *JAMA* 2022 | II 期/T3N0 低危 | IMRT alone vs CCRT 非劣效，重度毒性 17% vs 46%（↓29%） | 终结"一刀切"同步化疗，改写国内外指南 |
| **豁免咽后内侧组** | *BMJ* 2023 | — | 豁免 VIIa 咽后内侧组照射，未显著增加复发 | 精准保护吞咽功能，减少咽后间隙照射体积 |

> **三大研究的底层逻辑**：NPC 淋巴转移遵循**逐站引流、极少跳跃转移**的解剖规律。N0-1 患者低位颈（IV/Vb）隐匿转移率极低，无需过度预防。低危 NPC 对放疗高度敏感，同期顺铂的微小生存增益远不足以抵消其重度不良反应。
