## 为什么喉/下咽必须独立于口腔癌——根本差异

| 维度 | 口腔癌 | 喉癌/下咽癌 |
|------|--------|-----------|
| **解剖屏障** | 软组织为主 | **软骨框架**（甲状、环状、杓状） |
| **天然间隙** | 口底、舌下间隙 | **声门旁间隙、会厌前间隙** |
| **淋巴引流** | 口底→ⅠB→Ⅱ→Ⅲ | 声门上→Ⅱ/Ⅲ；声门下→**Ⅵ区**；下咽→**RP+Ⅵ** |
| **手术影响** | 皮瓣、下颌骨重建 | **全喉切除→Stoma**、咽吻合口 |
| **功能保护** | 吞咽、味觉、口干 | **发声、吞咽、误吸** |
| **RP 重要性** | 低（仅后部口腔癌） | **极高**——下咽癌 RP 隐匿转移 30-50% |

## 一、解剖基础

### 1.1 喉的关键结构

| 结构 | 临床意义 |
|------|---------|
| **甲状软骨** | 喉的"外壳"。前连合处 Broyle 韧带插入——此处无软骨膜→肿瘤→软骨仅 1-2 mm |
| **环状软骨** | 唯一完整的软骨环——声门下侵犯的前哨站 |
| **杓状软骨** | 声带后端附着——声带固定=杓状软骨受侵 |
| **会厌软骨** | 会厌前间隙的"天花板" |
| **声门旁间隙** | 声门上/声门癌的"地下通道"——肿瘤沿此间隙上下扩散 |
| **会厌前间隙** | 声门上→会厌前→舌根→对侧的桥梁——T2 以上必含 |
| **喉室** | 声门上和声门的解剖分界——跨喉室=跨声门癌 |
| **前连合** | Broyle 韧带→甲状软骨——T1 可因软骨近而升为 T4 |
| **环甲膜** | 声门下侵犯的前哨 |

### 1.2 下咽的关键结构

| 亚部位 | 边界 | 淋巴引流 |
|--------|------|---------|
| **梨状窝** | 咽侧壁（外）·杓会厌皱襞（内）·环后区（下） | Ⅱ-Ⅲ-Ⅳ → RP → Ⅵ |
| **环后区** | 杓状软骨→环状软骨后板→食管入口 | 双侧 RP → 双侧 Ⅵ |
| **咽后壁** | 舌骨水平（上）→环咽肌（下）·椎前筋膜（后） | 双侧 RP |

## 二、影像学评估

| 模态 | 看什么 | 喉/下咽特有 |
|------|--------|-----------|
| **CT** | 软骨侵犯（骨窗必需）、淋巴结 | 甲状软骨"穿通"→T4（RTOG 0619 标准） |
| **MRI** | 软骨侵犯（T1/T2 信号改变）、声门旁间隙浸润 | 敏感性 89% vs CT 66% |
| **FDG-PET** | 淋巴结、远处转移 | Daisne et al. — PET 最准确但均漏浅表扩散 |
| **内镜** | 黏膜表面范围、前连合暴露程度 | **不可替代**——影像学均低估黏膜范围 |

> ⚠️ **无论 CT、MRI 还是 PET——内镜检查所见范围是 GTV 定义的必要组成部分。** 前连合处必须以内镜所见为准。

### 术后放疗时间窗（2025 国家癌症中心指南）

| 场景 | 时间要求 | 来源 |
|------|---------|------|
| **下咽癌术后** | 术后 3-4 周影像复查 → 术前/术后对比 → **术后 4-6 周内开始放疗** | 易俊林通信（下咽癌指南） |
| **喉癌术后** | **术后 6 周之内开始** | 张烨通信（喉癌指南） |
| **诱导化疗后** | 放疗需在诱导化疗后 **3-4 周内**开始 | 两指南一致 |
| 手术切缘阳性/ENE+ | 术后**同期放化疗**（非单纯 PORT） | 两指南一致 |

## 三、喉癌 PORT 亚部位 CTV

### 3.0 亚部位概览

| 亚部位 | T 分期关键 | 淋巴结风险 |
|--------|----------|:--:|
| **声门上** | 会厌前间隙侵犯→T3 | Ⅱ-Ⅲ（双侧 20-30%） |
| **声门** | 前连合→软骨侵犯→T4 | T1 不照；T3+ 同侧 Ⅱ-Ⅲ-Ⅳ |
| **声门下** | 环状软骨→T4 | **Ⅵ 区必照** |
| **跨声门** | 跨喉室→声门上+声门+声门下 | Ⅱ-Ⅲ-Ⅳ+Ⅵ |

### 3.1 声门上癌 PORT

| CTV 要点 | 范围 |
|---------|------|
| **会厌前间隙** | T2+→**必须全含**——声门上癌通向舌根和对侧的"高速公路" |
| **舌根** | 会厌谷受累→同侧舌根 1-1.5 cm |
| **声门旁间隙** | 肿瘤紧邻→同侧全间隙纳入 |
| **对侧** | T2+ 跨中线→双侧 Ⅱ-Ⅲ 预防 |
| **Ⅵ区** | 一般不照——除非明确声门下侵犯 |

### 3.2 声门癌 PORT

| T 分期 | CTV 要点 | ENI |
|--------|---------|:--:|
| **T1-T2 N0** | GTV+1-1.5 cm。前连合受累→含 Broyle 韧带插入点+对侧声带前 1/3 | **不做 ENI** |
| **T3（声带固定）** | 声门旁间隙全含→同侧杓状软骨→环甲膜 | 同侧 Ⅱ-Ⅲ-Ⅳ（50 Gy） |
| **T4（软骨穿透）** | 甲状软骨全层纳入→对侧声门旁间隙→对侧杓状软骨 | 同侧 Ⅱ-Ⅲ-Ⅳ+Ⅵ |

> **前连合特殊规则**：肿瘤→Broyle 韧带→软骨仅 1-2 mm。软骨穿透=CTV 必须含甲状软骨前联合全厚度。前连合受累时 GTV→CTV 是从黏膜表面到含全层软骨的距离——不是固定数值。

### 3.3 声门下癌 PORT

| CTV 要点 | 范围 |
|---------|------|
| **原发性 CTV** | 环状软骨全层 + 声门下黏膜 1.5 cm 各向 |
| **向上** | 声门下→声门→声门上逆流通路→含声门上喉 |
| **向下** | 气管上段 2-3 cm |
| **Ⅵ 区（气管旁）** | **双侧必照**——50-54 Gy |
| **上纵隔** | T4→Ⅵ 区延续至胸骨切迹以下 2 cm |
| **颈部** | 同侧 Ⅱ-Ⅲ-Ⅳ-Ⅴ |

### 3.4 跨声门癌 PORT

同时累及声门上、声门、声门下——常为 T3-T4。

| CTV 要点 | 范围 |
|---------|------|
| **全喉照射** | 从会厌谷到环状软骨下缘全层 |
| **声门旁间隙** | 双侧全含 |
| **ENI** | 双侧 Ⅱ-Ⅲ-Ⅳ + Ⅵ |

## 四、下咽癌 PORT 亚部位 CTV

> **下咽癌是头颈鳞癌中预后最差的亚区——RP 和 Ⅵ 区是两个"必照区"。**
> ⚠️ 下咽癌合并**食管第二原发癌**概率约 **30%**。内镜务必包含胃镜+碘染色。

### 4.1 梨状窝癌 PORT

| CTV 要点 | 范围 |
|---------|------|
| **咽侧壁** | 梨状窝外侧壁→向后至椎前筋膜 |
| **喉侵犯途径** | 内侧壁→杓状软骨→声门旁间隙 |
| **食管入口** | 梨状窝尖→颈段食管 1-2 cm |
| **RP** | 同侧 RP **必照**（54-60 Gy）——转移率 20-40% |
| **Ⅵ 区** | 梨状窝尖受累→同侧 Ⅵ 区 |
| **对侧** | 对侧 RP+颈→仅近中线或环后受累时照 |

### 4.2 环后癌 PORT

全在中线，双侧引流，与食管入口直接延续。

| CTV 要点 | 范围 |
|---------|------|
| **环状软骨后板** | 全层——环后癌的"地板" |
| **食管入口** | 颈段食管 2-3 cm |
| **双侧 RP** | 中线位置→**双侧 RP 必照** |
| **双侧 Ⅵ 区** | 环后→双侧气管旁 |
| **气管膜部** | 环后→食管前壁→气管后壁→纳入 CTV |
| **对侧颈** | 双侧 Ⅱ-Ⅲ-Ⅳ 预防 |

### 4.3 咽后壁癌 PORT

| CTV 要点 | 范围 |
|---------|------|
| **后界** | 椎前筋膜——是否穿透是分期关键（T2 vs T4） |
| **上下扩展** | 纵向 2-3 cm 外放（比梨状窝更宽） |
| **双侧 RP** | 咽后壁中线→双侧 RP |
| **椎前肌** | T4 穿透椎前筋膜→椎前肌纳入 CTV |

## 五、术后靶区——全喉切除/部分喉切除/咽重建

### 5.1 气管造口（Stoma）——喉 PORT 的核心

> ⚠️ **口腔癌中气管切开是"种植风险"——喉癌里 Stoma 是手术边界本身。全喉切除术后的 Stoma 必须在 CTV-60 内。**

> **术后GTV勾画铁律**：无论术后病理显示治疗后改变甚至完全缓解，GTV勾画必须参考**化免前/术前**的影像学范围。化免前的原发灶侵犯区域必须纳入CTV1（高危区），不能因术后病理显示「治疗后改变」而缩小靶区。

| Stoma 状态 | CTV 要求 |
|-----------|---------|
| **全喉切除 Stoma** | 全层皮肤+皮下+气管环周 1-2 cm→**CTV-60 必须含 Stoma** |
| **术中冰冻 Stoma 阳性** | CTV-66——R1 区域推量 |
| **气管切开（非全喉）** | 种植风险，纳入 CTV-54 |

### 5.2 全喉切除术后 CTV

```
CTV-60（高危）：
├── 咽吻合口各向 1.5-2 cm
├── Stoma 全层（皮肤+气管环周 1-2 cm）
├── 舌根（若肿瘤曾贴邻→同侧舌根 1 cm）
├── 原发灶术床（按术前 MRI/内镜还原）
└── 原阳性 LN 站+直接下游一站

CTV-54（预防）：
├── 同侧 Ib-II-III-IV（声门上/下咽 T3+ 或 N2+）
├── 双侧 RP（下咽癌必照；喉癌仅声门上 T3+ 与下咽交界时同侧 RP）
├── 同侧 VI（声门下/下咽尖/环后）
└── 对侧 II-III（仅中线/近中线/环后+N2+）
```

### 5.3 部分喉切除术后

| 术式 | CTV 要点 |
|------|---------|
| **声带切除术** | 残余声带+前连合+对侧声带前 1/3（切缘<5 mm） |
| **声门上喉切除术** | 残余会厌+舌根 1 cm+同侧声门旁间隙 |
| **半喉切除术** | 残余半喉全层+对侧杓状软骨（近中线） |
| **保留的喉软骨** | 即便切缘阴性→保留的软骨仍需全层预防——软骨不是安全边界 |

### 5.4 下咽切除+重建术后

| 重建方式 | CTV 要点 |
|---------|---------|
| **游离空肠** | 吻合口上下各 2-3 cm。移植物-组织界面全层纳入 |
| **Gastric pull-up** | 胸腔胃上端吻合口→含吻合口上下+各 3 cm。气管后壁纳入 |
| **胸大肌皮瓣** | 组织床全照 |

## 六、淋巴结预防——Ⅵ 区与 RP

### 6.1 淋巴结站区对比

| 分区 | 口腔癌 | 声门上 | 声门 | 声门下 | 下咽 |
|:--:|:--:|:--:|:--:|:--:|:--:|
| **II/III** | ✅ | ✅ | T3+ | ✅ | ✅ |
| **IV** | N2+ | T3+/N2+ | T3+/N2+ | ✅ | T3+/N2+ |
| **I** | ✅ | 可选(T4) | ❌ | ❌ | ❌ |
| **V** | N2b+ | N2b+ | N2b+ | N2b+ | N2b+ |

> **V区豁免循证** — Looman et al. *Radiother Oncol* 2026：390例多中心研究。同侧V区11%，对侧3%。II/III阴性时V区降至**1%**。V区转移为II/III区受累后的序贯事件（非独立跳跃转移）。
| **VI** | ❌ | ❌(除声门下) | T4/声门下 | ✅ 双侧 | ✅ 同侧/双侧 |
| **VII(RP)** | ❌(后部) | T3+可选 | ❌ | ❌ | ✅ 必照 |

> **口诀**：Ⅰ口ⅡⅢⅣ通链，Ⅴ颈后Ⅵ气管Ⅶ咽后。口Ⅰ喉不照，下咽ⅥⅦ必包。

### 6.2 Ⅵ 区（气管旁/气管食管沟）

```
上界：环状软骨下缘
下界：胸骨切迹
外侧界：颈总动脉内侧缘
```

| 条件 | 同侧 Ⅵ | 双侧 Ⅵ |
|------|:--:|:--:|
| 声门下癌 | ✅ | ✅ |
| 梨状窝尖受累 | ✅ | ❌（除非近中线） |
| 环后癌 | ✅ | ✅ |
| 颈段食管受累 | ✅ | ✅ |
| Stoma 切缘阳性/近 | ✅ | ✅ |

### 6.3 RP（咽后淋巴结）

```
上界：颅底（C1 横突水平——下咽癌不能用"舌骨水平"做上界）
```

| 条件 | 同侧 RP | 双侧 RP |
|------|:--:|:--:|
| **所有下咽癌** | ✅ 必照 | 环后/咽后壁/近中线→双侧 |
| 声门上 T3+（紧邻下咽交界区） | 可选 | ❌ |

> **下咽癌 RP 上界至少到 C1 横突水平**——不能用口腔癌的"舌骨水平"。

> **RP转移与下咽亚部位的关系**：
> - 下咽后壁 / 外侧壁 / 梨状窝外侧壁 → **高RP风险**（必照，上界C1）
> - 环后区 → **低RP风险**（MRI阴性时可考虑豁免同侧RP）
> - 咽后壁癌 → 双侧RP必照（中线位置）

## 七、PORT 剂量策略

| PTV 层级 | 剂量 | 适应证 |
|---------|------|--------|
| **PTV-66-70** | 66-70 Gy/33-35 fx | R1/R2（Stoma 阳性、咽吻合口阳性）、ENE+ |
| **PTV-60** | 60 Gy/30 fx | 手术床（Stoma 必含）、原阳性 LN 站+下游一站 |
| **PTV-54** | 54 Gy/30 fx | 预防区（同侧未受累颈、双侧 Ⅵ 预防） |
| **PTV-50** | 50 Gy/25-30 fx | 低风险预防（对侧颈Ⅱ-Ⅲ） |

## 八、OAR 约束

| OAR | 限量 | 喉/下咽特有挑战 |
|-----|------|--------------|
| 脊髓 | Dmax ≤45 Gy | 下咽癌→RP→脊髓紧邻 |
| 脑干 | Dmax ≤54 Gy | 梨状窝尖→RP 上界近颅底 |
| 咽缩肌 | Dmean ≤54 Gy | 吞咽关键功能 |
| **喉（保留时）** | Dmean ≤45 Gy | 部分喉切除后残余喉——比口腔癌更难 |
| **气管** | V50 < 50% | 声门下/Ⅵ 照射→晚期气管软化 |
| 甲状腺 | V50 < 50% | 甲减率 40-60% |
| **颈动脉** | Dmax < 50 Gy | 全喉切除后颈动脉裸露于术床 |
| **臂丛** | Dmax ≤60 Gy | 下颈部/上纵隔照射 |
| 下颌骨 | Dmax ≤70 Gy | 喉/下咽癌通常不紧邻 |
| 腮腺 | Dmean ≤26 Gy | 双侧颈预防→双侧腮腺挑战 |
| **颈段食管** | Dmax < 60 Gy | CTV 必须含食管但约束需权衡 |

## 九、化免新辅助后降级

> 详细降级策略见 `neoadjuvant-deescalation`。以下为喉/下咽特有差异。

| | 喉癌 | 下咽癌 |
|---|---|---|
| **降级优先** | 降范围优于降剂量 | **降剂量优先于降范围** |
| **理由** | 对侧颈/Ⅵ 可缩 | RP+Ⅵ 基线风险太高，不能缩野 |
| **Stoma 豁免** | pCR+切缘≥5mm+声门下阴性+气管阴性→可考虑不照 | — |
| **手术降级补偿** | 保留的半喉→CTV-54（pCR）或 CTV-60（MPR），软骨全层——不是仅黏膜 | — |

## 十、PORT 靶区勾画——十步法

| 步 | 操作 |
|----|------|
| 1 | 获取术前 MRI/CT + 内镜检查报告 + 内镜图像 |
| 2 | 获取手术记录（术式、Stoma 位置、咽吻合方式、重建皮瓣） |
| 3 | 获取病理报告（各切缘、软骨侵犯、PNI、ENE、淋巴结） |
| 4 | 融合术前影像到定位 CT → 还原原始 GTV-T 和 GTV-N |
| 5 | 按亚部位规则勾画 CTV-P（第三、四节） |
| 6 | 处理 Stoma（全喉→CTV-60 含 Stoma；非全喉→种植风险 CTV-54） |
| 7 | 按 N 分期和亚部位决定 ENI 范围（Ⅵ 区、RP、对侧颈，第六节） |
| 8 | 处理软骨侵犯→全层软骨纳入 CTV（不是 5 mm 外放） |
| 9 | PTV 外放 3-5 mm（每日 CBCT） |
| 10 | 检查关键 OAR（Stoma 剂量、颈动脉 Dmax、臂丛、气管） |

## 十一、失败模式

### 喉癌

| 失败位置 | 根本原因 | 预防规则 |
|---------|---------|---------|
| 前连合处局部复发 | 仅凭 CT 勾画 GTV——未含 Broyle 韧带全层 | 前连合→黏膜到软骨全厚度 |
| 声门上对侧Ⅱ区复发 | ENI 未覆盖对侧颈 | T2+ 跨中线→双侧Ⅱ-Ⅲ |
| 声门下气管旁复发 | Ⅵ区未纳入 ENI | 声门下→双侧Ⅵ区必照 |
| 软骨边缘复发 | GTV 低估→CTV 外放不足 | 内镜所见+软骨全层 |
| 跨声门对侧喉复发 | 只照同侧半喉 | 跨声门→双侧声门旁间隙 |

### 下咽癌

| 失败位置 | 根本原因 | 预防规则 |
|---------|---------|---------|
| **RP 复发（最常见地理遗漏）** | RP 未纳入 ENI 或上界不足 | 下咽癌→同侧 RP 必照，上界至 C1 |
| Ⅵ区/气管旁复发 | 梨状窝尖引流→气管旁遗漏 | 梨状窝尖→同侧Ⅵ区 |
| 食管方向纵向失败 | CTV 未含足够颈段食管 | 环后癌→颈段食管 2-3 cm |
| 咽吻合口失败 | CTV-P 边缘不足 | 吻合口各向 1.5-2 cm |
| 对侧颈区域失败 | 仅照同侧→环后双侧引流遗漏 | 环后/近中线→双侧预防 |
