# 鼻腔与鼻窦癌放疗靶区勾画

> **本节为九院团队基于 CSCO 2026、ESMO-EURACAN 2025、ICAR 2024 国际共识及九院临床实践的鼻腔/鼻窦癌放疗靶区勾画体系。** 这是头颈放疗中最复杂的靶区之一——眼眶、视交叉、脑干、颞叶紧邻靶区，毫米级的误差可能导致失明。

---

## 为什么鼻腔鼻窦癌必须独立成 Skill

| 维度 | 口腔/口咽 SCC | 鼻咽癌 | 鼻腔鼻窦癌 |
|------|-------------|--------|-----------|
| **解剖复杂度** | 软组织为主 | 黏膜+颅底 | 🔥 **骨性框架+眼眶+颅底+鼻腔**——四维叠加 |
| **邻近 OAR** | 下颌骨、腮腺 | 脑干、颞叶 | 🔥 **视交叉、视神经、视网膜、泪腺、脑干、额叶**——任何一项超标都不可接受 |
| **病理多样性** | 以 SCC 为主 | 以未分化癌为主 | 🔥 **SCC + SNUC + 嗅神经母细胞瘤 + 黑色素瘤 + 肉瘤 + 神经内分泌癌** |
| **手术方式** | 经口/颌颈 | 不手术 | 🔥 **内镜/Draf/颅面联合切除/上颌骨切除**——缺损重建复杂度极高 |
| **N0 颈部争议** | 按亚部位 | 常规 ENI（NPC） | 🔥 **N0→颈部预防争议极大**——T 分期+位置+病理决定 |
| **诱导化疗** | 正在探索 | 晚期用 | 🔥 **SNUC/ SCC T3-4→诱导化疗指导后续治疗（Amit 2019 JCO）** |
| **靶区勾画难度** | 中等 | 高 | 🔥 **极高**——术后解剖变形+术后填塞物/皮瓣→定位 CT 上几乎无法辨识 |

## 一、解剖与亚部位

### 1.1 鼻腔

| 亚部位 | 边界 | 淋巴引流 |
|--------|------|---------|
| **鼻前庭** | 鼻翼→鼻阈 | 颌下/颊下（ⅠB/ⅠA） |
| **鼻腔外侧壁** | 上中下鼻甲 | Ⅱ→RP |
| **鼻腔顶（筛板）** | 筛板→前颅底 | 直接侵犯颅内——非淋巴途径 |
| **鼻中隔** | 前→后 | 双侧ⅠB+Ⅱ |
| **后鼻孔** | 鼻腔→鼻咽分界 | RP |

### 1.2 鼻窦

| 鼻窦 | 边界 | 关键毗邻 |
|------|------|---------|
| **上颌窦** | 上：眶底。内：鼻腔。后：翼腭窝/颞下窝。外：颧骨 | 眶底→眼球。后壁→V2→圆孔 |
| **筛窦** | 上：前颅底/筛板。外：眼眶内壁（纸板）。内：鼻腔顶 | 🔥 **纸板→眼眶。筛板→脑膜/额叶** |
| **蝶窦** | 上：蝶鞍/视交叉。外：海绵窦。后：脑桥 | 🔥 视交叉紧贴蝶窦顶——误差 >3 mm→失明 |
| **额窦** | 前：额骨。后：前颅底/额叶 | 额叶硬膜 |

### 1.3 关键解剖平面——Ohngren 线

```
Ohngren 线：内眦→下颌角连线
    │
    ├── 线上（后上/ infrastructure）→ 预后差——近颅底/眼眶/翼腭窝
    │
    └── 线下（前下/ suprastructure）→ 预后好——仅累及硬腭/牙槽
```

## 二、AJCC 第 9 版分期

### 2.1 上颌窦

| T | 定义 |
|----|------|
| T1 | 局限于黏膜，无骨质侵蚀 |
| T2 | 骨质侵蚀/破坏（含硬腭/中鼻道），未侵及上颌窦后壁和翼板 |
| T3 | 侵犯上颌窦后壁骨质、皮下组织、眶底/内侧壁、翼腭窝、筛窦 |
| **T4a** | 侵犯眶前部内容物、颊部皮肤、翼板、颞下窝、筛板、蝶窦/额窦 |
| **T4b** | 侵犯眶尖、硬脑膜、脑组织、中颅窝、除 V2 外的颅神经、鼻咽、斜坡 |

### 2.2 鼻腔和筛窦

| T | 定义 |
|----|------|
| T1 | 局限于鼻腔或筛窦一个亚部位，±骨质侵犯 |
| T2 | 侵犯两个亚部位或扩展至鼻筛复合体内邻近部位，±骨质侵犯 |
| T3 | 侵犯眼眶内侧壁/底壁、上颌窦、硬腭、筛板 |
| **T4a** | 侵犯眶前部内容物、鼻/颊部皮肤、轻微前颅窝扩展、翼板、蝶窦/额窦 |
| **T4b** | 侵犯眶尖、硬脑膜、脑组织、中颅窝、除 V2 外的颅神经、鼻咽、斜坡 |

### 2.3 N 分期（AJCC 第 9 版）

AJCC 第 9 版对头颈部肿瘤 N 分期进行了大幅简化，将原第 8 版的 N1/N2a/N2b/N2c/N3a/N3b 六分类合并为两个分类：

| N 分期 | 定义 |
|--------|------|
| **N1** | 1-3 个同侧淋巴结转移，无 ENE（结外侵犯） |
| **N2** | >3 个淋巴结转移，或任何 ENE(+)（不论大小、侧别） |
| *N3* | *已废除——第 9 版不再设 N3 分期* |

> **临床意义**：第 9 版的核心变革：不再以淋巴结大小（3 cm/6 cm）和侧别（同侧/双侧/对侧）区分 N 分期，转而聚焦**淋巴结数量**和 **ENE 状态**这两个预后关键因素。原第 8 版中 >6 cm 无 ENE 的 N3a 和任何 ENE(+) 的 N3b 均归入第 9 版 N2。

## 三、治疗总则（CSCO 2026）

| 分层 | 推荐 |
|------|------|
| **T1-2 N0** 可手术 | 手术 ± 术后 RT |
| **T1-2 N0** 不可手术 | 根治性 RT |
| **T3-4/N+** 可手术（SCC/未分化癌）| 手术 + RT/CRT **或** 诱导化疗→手术+RT/CRT |
| **T3-4/N+** 不可手术（SCC/未分化癌）| RT/CRT **或** 诱导化疗→RT/CRT |
| 远处转移（SCC） | 帕博利珠单抗+白蛋白紫杉醇+顺铂/卡铂（Qian 2025 Phase II） |
| 远处转移（未分化/神经内分泌）| 顺铂/卡铂+依托泊苷 |

---

### 3.1 按亚部位的治疗原则

| 亚部位 | 早期 | 晚期 |
|--------|------|------|
| **鼻腔** | 放疗 ≈ 手术（效果基本相同） | 以**放疗为主**的综合治疗 |
| **筛窦** | 手术 + 术后放疗 | 以**放疗为主**的综合治疗 |
| **上颌窦** | 术前放疗或术后放疗 | 以**放疗为主**的综合治疗 |
| **蝶窦** | ⚠️ **以放疗为主——同鼻咽癌处理** | 以放疗为主（手术极难达到 R0） |

> **蝶窦癌的特殊性**：位置深——紧邻视交叉、海绵窦、脑干。手术几乎无法 R0。治疗策略与 NPC 类似——根治性 RT/CRT 是首选。

## 四、PORT 指征

| 指征 | 证据 |
|------|:--:|
| **高级别病理**（SNUC/高级别 SCC/神经内分泌癌） | 强 |
| **pT3-T4** | 强 |
| **N+** | 强 |
| **R1/R2 切缘** | 强 |
| **PNI+** | 强 |
| **LVI+** | 中等 |
| **ACC**（独立 Skill） | 强——全推荐 |

### cN0 的颈部争议

> **ICAR 2024 数据**（6448 例 NCDB + 1283 例 Meta）：上颌窦 SCC 初诊 N+ = **20.7%**，鼻腔 SCC = **9.3%**。全程随访中 **1/3** 患者最终出现颈部转移——cN0 不等于低风险。

```
鼻腔鼻窦癌 cN0 → 颈部预防照射？
    │
    ├── 上颌窦 SCC cN0 → ✅ 同侧 ⅠB+Ⅱ+Ⅲ（N+ 率 20.7%，不可忽视）
    ├── 鼻腔 SCC cN0 → ⚠️ pT3-4→✅ 同侧 ⅠB+Ⅱ+Ⅲ。pT1-2→❌ 不做（N+ 率仅 9.3%）
    ├── SNUC any T cN0 → ✅ 同侧 ⅠB+Ⅱ+Ⅲ+RP（Faisal 2020 Meta）
    ├── 腺癌/ACC cN0 → ❌ 不做（参照唾液腺 Skill）
    ├── 嗅神经母细胞瘤 cN0 → ❌ 不做（除非 Kadish C）
    └── 黑色素瘤 cN0 → 不做（除非 N+）

N0 患者颈部预防的高危因素（除上述 T+病理外）：
    ├── 鼻底黏膜受侵 → ✅ 同侧 ⅠB
    ├── 牙龈/硬腭黏膜受侵 → ✅ 同侧 ⅠB+Ⅱ
    ├── 鼻咽黏膜受侵 → ✅ 同侧 RP+Ⅱ
    ├── 面部皮肤明显受侵 → ✅ 耳前 LN + 腮腺 LN + 颊 LN（IX区）
    └── 中线结构明显侵犯 → ✅ 双侧颈

N+ 患者颈部范围：
    ├── 同侧淋巴引流区（含阳性站）→ 高危区
    ├── 外放 1 个引流区 → 中危区（预防剂量）
    └── 筛窦/鼻腔后 1/3/鼻咽受侵 → +同侧 RP
```

## 五、靶区勾画——按亚部位

### 5.1 上颌窦癌术后

| 边界 | 结构 |
|------|------|
| **上界** | 眶底（如眶底保留）或眶内容物下缘（如眶内容物切除） |
| **下界** | 硬腭（如保留）或口腔顶（如上颌骨全切） |
| **前界** | 上颌骨前壁/面部皮下 |
| **后界** | **翼腭窝+翼板根部**（必须——V2 的必经之路） |
| **内侧界** | 鼻腔外侧壁（或鼻中隔——如跨中线） |
| **外侧界** | 颧骨/咬肌间隙 |

> **后界关键**：T3-4 上颌窦癌的后界必须包含翼腭窝和翼板——这是 R2 切除最常见的位置。V2→圆孔的神经径路在此通过。

### 5.2 筛窦癌术后

| 边界 | 结构 |
|------|------|
| **上界** | 🔥 **筛板/前颅底**——必须含全层筛板，如硬膜缺损→含额叶硬膜外 5 mm |
| **下界** | 中鼻甲下缘 |
| **前界** | 额窦口/鼻骨 |
| **后界** | 蝶窦前壁 |
| **内侧界** | 鼻中隔上段 |
| **外侧界** | 🔥 **眼眶内壁（纸板）**——必须全层覆盖 |

### 5.3 鼻腔癌——CTV 扩展规则

| 侵犯范围 | CTV 调整 |
|---------|---------|
| **局限于一侧鼻腔** | CTV = 双侧鼻腔 + 筛窦 + 同侧上颌窦 |
| **侵犯翼板/翼内外肌/鼻腔后 1/3/鼻咽** | CTV 扩展至鼻咽腔 |
| **眼眶——仅纸样板受侵** | 照射野外限于**患者角膜缘**（保留眼球）——不照全眼眶 |
| **眼眶——多壁受侵或明显眶内侵犯** | CTV 包含**整个眼眶**（需与眼科沟通眼球保留可能性） |
| **侵犯双侧鼻腔/筛窦/上颌窦/蝶窦/额窦/口腔/颞下窝/颅内** | 相应扩大 CTV 范围至所有受累结构 |

> **眼眶侵犯的边界原则**：纸样板单独受侵 = 角膜缘。多壁/眶内 = 全眶。术前 MRI 冠状位是判断眼眶侵犯的最佳序列。

### 5.4 鼻腔癌术后 CTV（按原发位置）

| 原发位置 | CTV 范围 |
|---------|---------|
| **鼻前庭** | 鼻翼全层+鼻阈+上唇皮下+同侧ⅠB |
| **鼻腔外侧壁** | 全鼻甲+上颌窦内壁+筛窦 |
| **鼻腔顶/筛板** | 筛板全层+前颅底硬膜+额叶硬膜外 5 mm |
| **鼻中隔** | 双侧鼻中隔全层+对侧鼻腔黏膜（距中线 >1 cm 才豁免对侧）|
| **后鼻孔** | 鼻咽侧壁+咽隐窝+同侧 RP |

### 5.5 根治性 RT（不手术）靶区

| CTV | 范围 | 剂量 |
|-----|------|------|
| **GTV-P** | 影像+内镜可见原发灶 | 70 Gy / 35 fx |
| **CTV-HR** | GTV + 5-10 mm + 全受累窦腔 | 63 Gy / 35 fx（SIB） |
| **CTV-ENI** | 同侧 ⅠB+Ⅱ+Ⅲ（按病理+T分期决定） | 56 Gy / 35 fx |

## 六、OAR 约束——鼻腔鼻窦癌特有

> 🔥 **视路保护是第一优先级。** 任何计划如果视交叉/视神经超标→必须退回重优化。

| OAR | 约束 | 鼻腔鼻窦癌特别说明 |
|-----|------|------------------|
| **视交叉** | 🔥 D0.03cc ≤ **54 Gy**（RTOG 0615·近最大等效） | 蝶窦癌/筛窦癌→视交叉紧贴靶区。若靶区距视交叉 <3 mm→考虑质子治疗 |
| **视神经** | 🔥 Dmax ≤ **54 Gy** | 双侧分别限量——不能一侧超标用对侧"平均"混淆 |
| **视网膜** | Dmax ≤ 45 Gy | 上颌窦癌→眶底紧邻视网膜 |
| **泪腺** | Dmean ≤ 25 Gy | 筛窦/上颌窦靶区→泪腺在视野内 |
| **晶状体** | Dmax ≤ 10 Gy（九院保守） | 比 RTOG 0615 的 25 Gy 更严格 |
| **脑干** | Dmax ≤ 54 Gy | 蝶窦后壁→脑桥仅 5-8 mm |
| **颞叶** | Dmax ≤ 60 Gy | 筛板/前颅底→额叶硬膜外→颞叶 |
| **下颌骨** | Dmax ≤ 70 Gy | 上颌骨切除后咬肌间隙照射可能涉及 |

## 七、剂量

### 7.1 术后剂量

| 风险 | 剂量 | 指征 |
|------|------|------|
| **高危** | 66 Gy / 33 fx | R1/R2、PNI+（命名神经）、高级别 |
| **中危** | 60 Gy / 30 fx | pT3-4、N+、切缘近 |
| **预防** | 54 Gy / 27 fx | ENI（包括 RP）|

### 7.2 根治性剂量

| CTV | 剂量 |
|-----|------|
| GTV | 70 Gy / 35 fx |
| CTV-HR | 66 Gy / 33 fx（SIB）或 70 Gy / 35 fx |
| CTV-ENI | 56 Gy / 35 fx |

### 7.3 术前放疗（历史参考——已基本弃用）

> 三明治治疗（术前 RT→手术→术后 RT）已被诱导化疗/化免取代。以下为历史剂量——仅在极特殊情况（如诱导化疗禁忌/无效）下参考：

| 指征 | 剂量 |
|------|------|
| 标准术前 | 50-60 Gy / 25-30 fx |
| 侵犯上颌窦后壁/翼腭窝/眼眶 | 60 Gy / 30 fx 或更高 |

### 7.4 非常规分割（对放射抵抗或不敏感肿瘤）

| 指征 | 可考虑方案 |
|------|----------|
| 晚期/大肿块 | 超分割（1.2 Gy bid 至 74-80 Gy） |
| 黑色素瘤 | 大分割（30-36 Gy / 5-8 fx） |

### 7.5 诱导化疗后放疗

| 诱导后缓解 | 放疗策略 |
|----------|---------|
| **CR/PR（仅SNUC）** | 按化疗后体积勾画 GTV——**仅限 SNUC 可缩小**（Amit 2019 JCO） |
| **CR/PR（SCC/腺癌）** | ⚠ **按化疗前体积勾画 GTV 用于 CTV-IR**——不可随化疗退缩缩小 |
| **SD/PD** | 按化疗前体积勾画 GTV |

> 🔥 **SNUC 的诱导化疗原则**（Amit 2019 JCO）：诱导化疗后→化疗有效的患者→根治性 CRT。化疗无效→直接手术。这个"化疗反应指导治疗"的原则是 SNUC 独有的。

## 八、特殊类型的靶区考虑

### 8.1 嗅神经母细胞瘤（Esthesioneuroblastoma）

| 特殊性 | 处理 |
|--------|------|
| **起源** | 嗅上皮→筛板→前颅底 |
| **CTV 上界** | 必须包含**筛板全层+嗅球+前颅底硬膜**——这是起源处，即使影像上不明确也要照 |
| **颅内扩展** | 如有→含额叶硬膜外 5-10 mm |
| **颈部** | Kadish C（超出鼻腔）→仅同侧 ⅠB+Ⅱ。Kadish A/B → 不做 |
| **剂量** | 术后 60-66 Gy。R2→70 Gy。比 SCC 略敏感 |

### 8.2 SNUC（鼻腔鼻窦未分化癌）

| 特殊性 | 处理 |
|--------|------|
| **侵袭性** | 极高——>50% 初诊时 T4 |
| **诱导化疗** | 🔥 **标准路径**——化疗反应决定后续治疗 |
| **颈部** | **即使 cN0 也要照**（同侧 ⅠB+Ⅱ+Ⅲ+RP）——隐匿转移率 30-40% |
| **剂量** | 术后 66 Gy。R1/R2→70 Gy |

### 8.3 黏膜黑色素瘤

| 特殊性 | 处理 |
|--------|------|
| **放射抵抗** | 常规分割效果差 |
| **剂量方案** | 🔥 **大分割**——30 Gy/5 fx 或 36-39 Gy/8-10 fx（参照 RTOG 0536 黏膜黑色素瘤方案） |
| **⚠️ 视路安全** | 此方案不适用于 PTV 邻近视交叉/视神经（<5mm）的病灶——此时应考虑常规分割或质子/碳离子治疗 |
| **颈部** | pN0→不做 ENI。pN+→同侧 ⅠB+Ⅱ+Ⅲ |

### 8.4 神经内分泌癌

| 特殊性 | 处理 |
|--------|------|
| **化疗敏感** | 顺铂+依托泊苷——类似小细胞肺癌 |
| **放疗** | 术后 60-66 Gy。CRT 可考虑（唯一推荐同步化疗的鼻腔鼻窦类型） |

### 8.5 鼻腔鼻窦腺样囊性癌（Sinonasal ACC）

> 朱奕 104 例鼻腔鼻窦 ACC 临床分析（复旦大学附属眼耳鼻喉科医院，中国癌症杂志 2016）。不同于唾液腺 ACC——鼻腔鼻窦 ACC 实体型占比更高、PNI 通路更复杂、手术更难 R0。

| 特征 | 内容 |
|------|------|
| **发病率** | 鼻腔鼻窦癌中仅次于 SCC，约占头颈肿瘤 1% |
| **病理特征** | 🔥 鼻腔鼻窦 ACC 实体型占比**高于**唾液腺 ACC→侵袭性更强 |
| **PNI 核心通路** | V2（上颌神经）、V3（下颌神经）、翼管神经。**翼腭窝是关键结构**——沟通圆孔、翼管、眶及颅内 |
| **PNI 分级** | 神经内侵犯 > 神经周围侵犯（预后更差） |
| **淋巴结转移** | 不常见→**不常规做选择性颈清扫** |
| **远处转移** | 肺最常见——惰性但不可治愈 |
| **手术方式** | 内镜手术复发率可能低于开放（17.8% vs 38.5%，Meccariello 2016）。文献推荐内镜 |
| **切缘阳性** | 文献数据——切缘阳性对 OS/DFS 无显著影响（可能与跳跃性 PNI 有关）→更强调术后 RT |
| **PORT 剂量** | >60 Gy。多处切缘阳性/软组织受侵→**66 Gy** |
| **术前 vs 术后 RT** | 文献数据——术前/术后对 OS/DFS 无显著影响。临床以术后 RT 为主 |
| **IMRT** | 延长无瘤生存（Askoxylakis 2016） |
| **质子/碳离子** | 高局控率——长期数据有限（Linton 2015; Jensen 2016） |
| **化疗** | CAP 方案（顺铂+多柔比星+环磷酰胺）——用于晚期/复发/转移。同步 CRT 可能提高局控率 |
| **预后不良因素** | 实体型 ≥30%、PNI+、复发、远处转移、蝶窦原发、术后 RT 剂量低 |
| **死亡原因** | 远处转移为首要死因 |

## 十、九院临床经验——教科书之外的规则

### 10.1 七窍相通——黏膜连续性决定靶区边界

```
鼻腔→鼻窦→鼻咽的黏膜在解剖上是连续的。
上颌窦→中鼻道→鼻腔→后鼻孔→鼻咽
筛窦→上鼻道→嗅裂→蝶筛隐窝→蝶窦
额窦→额隐窝→中鼻道

临床意义：
  肿瘤在黏膜下可沿此通路扩散——CTV 不应止于"窦口"而应包含
  相邻窦腔的引流通道黏膜。
  例：上颌窦癌→CTV 必须含中鼻道→后鼻孔黏膜
      筛窦癌→CTV 必须含嗅裂→蝶筛隐窝
```

### 10.2 三明治治疗已成历史

```
术前 RT → 手术 → 术后 RT（三明治）已基本弃用。

原因：
  · 术前药物治疗（诱导化疗/化免）有效性远超术前 RT
  · 术前 RT 增加手术并发症——皮瓣坏死、伤口不愈
  · 术前 RT 后解剖层次紊乱→影响病理评估
  → 若有新辅助需求→用药，不用术前 RT
```

### 10.3 颌骨坏死预防——软组织覆盖是关键

```
鼻腔鼻窦 RT 后颌骨/颅底骨坏死 = 最棘手的晚期并发症

九院经验：
  手术时→ENT/口腔颌面外科需做到：
  · 骨膜完整覆盖所有暴露骨质
  · 游离黏膜瓣/中厚皮片/颞肌筋膜瓣覆盖裸露骨面
  · 鼻中隔黏膜瓣→覆盖筛板/前颅底
  · 下鼻甲黏膜→覆盖上颌窦内侧壁

为什么重要：
  · 骨面无软组织覆盖→RT 后血供断绝→骨坏死→感染→大出血
  · 有软组织覆盖→血供保留→可耐受 66-70 Gy
  · 无软组织覆盖→即使 50 Gy 也可能骨坏死
  → 术前必须与手术医生沟通覆盖方案
```

### 10.4 上颌窦引流——打通底壁

```
上颌窦肿瘤 RT 期间：
  · 肿瘤退缩→产生坏死物
  · 若窦口闭塞→坏死物积存→继发感染→疼痛+发热+中断治疗
  · 若底壁打通（开窗至口腔/鼻腔）→坏死物可排出

操作：
  · 手术时→上颌窦底壁开窗（通口腔）或内侧壁大窗（通鼻腔）
  · 如未手术→RT 前评估窦口通畅性→必要时内镜下扩大
  → 引流畅通=感染风险降低=RT 完成率提高
```

### 10.5 开放手术 vs 内镜手术——九院认知

| 上颌窦壁 | 骨质 | 推荐入路 | 理由 |
|---------|:--:|---------|------|
| **前壁/外侧壁/底壁** | 厚（3-5 mm） | 🏥 **开放手术**（口腔颌面外科） | 骨质坚硬→开放术野暴露好→切得更彻底 |
| **内侧壁/顶壁/后壁** | 薄（<1 mm） | 🔬 **内镜手术**（ENT） | 骨质薄→内镜创伤小→术后恢复快；即便切得不够彻底→RT 可弥补 |

> **核心认知**：开放和内镜**不是竞争关系——是互补关系。** 上颌窦的前外下壁→口腔颌面外科做。内侧顶后壁→ENT 内镜做。残留→RT 补。

### 10.6 SMARCA4/SMARCB1(INI1)-缺失型鼻腔鼻窦癌

> 这是鼻腔鼻窦肿瘤分子分型的最新进展——病理科常规做 IHC 检测即可诊断。

#### SMARCA4 缺失型

| 特征 | 内容 |
|------|------|
| **病理** | 未分化癌，横纹肌样形态（rhabdoid），SMARCA4（BRG1）IHC 表达缺失 |
| **临床** | 中老年男性多见，高度侵袭性，>80% 初诊 T4 |
| **预后** | 极差——比 SNUC 更差，中位 OS <12 个月 |
| **免疫** | PD-L1 常高表达→**免疫检查点抑制剂可能有效**（Case series） |
| **RT 角色** | 🔥 **放疗是唯一有效的局部治疗**——手术往往无法 R0，PORT 必做。根治性剂量 70 Gy |
| **鉴别** | 需与 SNUC、NUT 癌、大细胞神经内分泌癌鉴别——**IHC 是唯一手段**（SMARCA4/SMARCB1/NUT/INSM1） |

#### SMARCB1(INI1) 缺失型

| 特征 | 内容 |
|------|------|
| **病理** | 基底样或横纹肌样形态，INI1 IHC 表达缺失 |
| **临床** | 比 SMARCA4 缺失型略少见，同样高度侵袭性 |
| **特殊** | EZH2 抑制剂（Tazemetostat）可能有效——基于 INI1 缺失的合成致死原理（已批准用于上皮样肉瘤） |
| **RT 角色** | 同 SMARCA4 缺失型——PORT 必做，根治性 70 Gy |

#### 分子检测建议

```
所有鼻腔鼻窦未分化癌/高级别癌→常规 IHC panel：
  □ SMARCA4 (BRG1)
  □ SMARCB1 (INI1)
  □ NUT
  □ INSM1（神经内分泌标记）
  □ p16（HPV 相关）
  □ EBER（EBV 相关）

诊断流程：
  未分化形态
      │
  IHC 四联筛查
      │
  ┌───┼───┬───┐
  ↓   ↓   ↓   ↓
SMARCA4- SMARCB1- NUT+ INSM1+
  │     │     │    │
  │     │  NUT癌  神经内分泌癌
  │  INI1缺失型   
SMARCA4缺失型
```

> **临床意义**：SMARCA4/INI1 缺失型对常规化疗反应差→避免盲目做大剂量化疗。免疫治疗/SMARCA4+ 和 EZH2 抑制剂/INI1- 是更合理的方向。**RT 是唯一可靠的局部治疗——必须做、必须做到位。**
